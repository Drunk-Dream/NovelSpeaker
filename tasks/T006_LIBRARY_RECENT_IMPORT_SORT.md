# T006：增加书库“最近导入”排序

## 目标

在现有轻量书库管理能力上增加一个真正有用的排序维度，不扩张成标签/文件夹/阅读状态管理系统。

## 权威参考

- `docs/00_PRODUCT_AND_SCOPE.md`
- `docs/06_UI_AND_VISUAL_SYSTEM.md`
- `AGENTS.md`

## 必须实现

- 在现有 `RecentReading`、`Title` 基础上增加“最近导入”。
- 使用现有 Book `ImportedAt` / `LastImportedAt` 中与产品语义最匹配的权威字段；先审计直接导入、重复导入/更新行为，再确定排序使用哪个字段，避免新增冗余时间字段。
- 默认排序保持现有行为，除非现有产品已有更明确的默认选择。
- 搜索继续覆盖书名与作者。
- 排序变化保持现有响应式布局、virtualization 和滚动 anchor 原则。

## 不要做

- 不增加“全部/阅读中/未读”等状态筛选。
- 不增加标签、文件夹、收藏、评分。
- 不新增数据库字段，除非现有时间字段确实无法表达需求；若需要持久化变更必须先按 `AGENTS.md` 取得授权。

## 测试

使用现有 Library/Catalog 测试保护“最近导入”的稳定排序与现有两种排序不回归即可；不要为 ComboBox 文案或像素布局新增永久测试。

阶段完成前执行完整质量门禁。
