# T016：为章节规则正则设置执行时限

## 目标

让章节规则保存校验与导入切章使用有界 Regex 策略，避免复杂规则在单次同步匹配中长期占用 worker。章节规则超时应投影为稳定、可理解的规则或导入失败。

审计依据：`CODEBASE_AUDIT_REPORT.md` F01。相关合同：`docs/specs/BOOK_IMPORT.md`、`docs/08_QUALITY_AND_TESTING.md`。

## 范围与约束

- 检查章节规则的校验、保存、导入及 `ChapterSplitter` 所有执行路径。
- 复用仓库已有的 Regex timeout 策略；选择与受支持导入文本兼容的有界时限，不增加第二套策略或保留无时限生产 overload。
- 超时不得被误当作“未匹配”并静默跳过章节。
- 不改变规则语法、分组优先级或切章语义；不把 Regex 执行改成无界后台任务。

## 验收

- 静态确认全部生产章节规则匹配都有时限。
- 覆盖超时的用户可观察失败路径，以及普通规则匹配行为；仅在其满足核心测试准入标准时保留永久用例。
- 执行相关 focused tests、format 和 Release build；记录未执行的检查。

## 交付

清理不再使用的无 timeout 路径/重复逻辑，按 Backlog 完成规则更新并删除本规格。
