# 项目简报

## 产品定义

NovelSpeaker 是面向 Windows 10/11 的轻量本地小说听书应用。用户导入 TXT 小说后，可以通过可配置的 HTTP TTS 规则连续收听、恢复进度、缓存音频，并以桌面播放器的方式控制播放。

它不是完整电子书阅读器，也不是在线书源聚合器。产品重点是把“本地文本 → 可控语音生成 → 连续播放 → 本地缓存”做得稳定、简洁并适合长期使用。

## 核心用户故事

> 作为用户，我希望导入一本 TXT 小说，选择一个在线 TTS 规则后像使用音乐播放器一样持续收听；应用能够记住进度、复用缓存，并让我在需要时提前缓存或导出指定章节音频。

## 核心链路

```text
TXT 导入
  → 编码识别与规范化
  → 章节识别与动态分段
  → 展示/朗读文本处理
  → HTTP TTS 规则编译与限流
  → 缓存命中或音频生成
  → 本地播放与预取
  → 进度持久化
```

主动缓存和章节音频导出复用同一套文本、TTS、缓存键与限流语义，不建立另一条音频生成链路。

## 设计目标

- 安装简单，自包含发布，主流程不依赖自建服务器。
- 不绑定特定 TTS 服务商，规则可导入、编辑和试听。
- 播放、预取和主动缓存共享一致的缓存键、限流和错误恢复。
- 章节切换、页面切换、迷你播放器或托盘状态不会破坏播放会话。
- 网络、文件、SQLite、音频生成与导出均不阻塞 UI 线程。
- 已生成音频能够稳定复用；缓存清理不破坏书籍和阅读进度。
- UI 保持桌面应用的高信息效率，同时减少按钮堆叠和不必要的视觉边框。

## 产品边界

当前产品围绕本地 TXT 和 HTTP TTS 展开。EPUB、在线书源、云同步、账号体系、插件市场、跨平台和专业音频后期不是当前阶段目标。

对外部规则只实现产品所需的 HTTP/TTS 行为子集；未实现的外部运行时能力必须安全失败，不能为了兼容而扩大脚本或系统访问权限。

## 支持平台

- Windows 10 22H2+
- Windows 11
- x64

## 性能与体验目标

- 普通 TXT 导入、章节加载和缓存统计不得冻结 UI；缓存完整度查询使用持久化的当前章节朗读清单和 SQLite 聚合，不逐段重新处理正文或解码音频。
- 未缓存段落开始播放时有明确的生成状态；缓存命中应快速开始。
- 当前播放请求优先于播放预取，播放预取优先于主动缓存。
- 后台主动缓存可以跨页面继续，并持续提供可查看、可取消的进度。
- 大章节列表使用虚拟化；定位当前章节和当前段落不依赖线性手工寻找。
- 应用关闭、崩溃恢复和数据迁移不修改用户的外部源文件。
