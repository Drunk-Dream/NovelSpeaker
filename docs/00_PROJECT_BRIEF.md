# 项目简报

## 项目名称

`NovelSpeaker`

## 产品定义

NovelSpeaker 是一个面向 Windows 的轻量小说听书应用。

它不是完整电子书阅读器，也不是网络小说聚合器。其主要职责是把用户导入的本地小说转换为可连续播放、可暂停恢复、可缓存的在线语音。

## 核心用户故事

> 作为用户，我希望导入一本 TXT 小说，选择一个在线 TTS 规则和音色配置，然后像使用音频播放器一样连续收听，并在下一次启动时从原位置继续。

## 核心链路

```text
TXT 文件
  ↓
编码识别和文本规范化
  ↓
章节识别
  ↓
朗读段落切分
  ↓
HTTP TTS 规则解析
  ↓
在线请求和音频下载
  ↓
本地缓存
  ↓
连续播放和预取
  ↓
进度保存
```

## 设计目标

- 安装和运行简单。
- 主流程不依赖自建服务器。
- 不绑定特定 TTS 服务商。
- 必须兼容目标 HTTP TTS 后端接口语义，并尽量复用常见 Legado 风格 HTTP TTS 规则。
- 不引入额外 Java 桥接服务或本地代理进程。
- 单次请求失败不会破坏整本书的播放状态。
- 跳转章节后不会继续播放旧请求结果。
- 已生成音频能够复用，减少延迟和调用成本。
- 用户不需要理解播放队列、缓存键等技术细节。

## 非目标

- 替代完整的 Legado。
- 提供在线书源。
- 成为电子书编辑器。
- 提供专业音频后期制作。
- 第一版兼容所有 Legado 规则和 JavaScript 扩展。
- 第一版支持所有 Windows 版本和所有 CPU 架构。

## 支持平台

支持平台：

- Windows 10 22H2 或更高版本。
- Windows 11。
- x64。

ARM64 可在主链路稳定后评估。

## 性能目标

这些目标用于指导实现，不是严格 SLA：

- 普通 TXT 导入应在可接受时间内完成，UI 不得冻结。
- 点击播放后，若当前段落未缓存，应清晰显示“正在生成语音”。
- 当前段播放期间应尽量完成下一段预取。
- 已缓存段落应几乎立即开始播放。
- 内存中不长期保存整本书的全部段落音频。
- 所有网络、文件和数据库操作均不得阻塞 UI 线程。
