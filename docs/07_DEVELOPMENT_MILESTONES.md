# 开发里程碑

## 总体策略

按可运行的纵向切片推进，而不是先实现所有基础设施。

每个里程碑都应包含：

- 可运行程序。
- 自动测试。
- 手动验收步骤。
- 已知限制。
- 必要的文档更新。

---

## M0：仓库和工程骨架

### 目标

建立可持续开发的最小工程。

### 工作项

- 创建解决方案和项目。
- 配置 .NET 10。
- 配置 WPF。
- 配置依赖注入。
- 配置 CommunityToolkit.Mvvm。
- 配置 xUnit。
- 配置日志。
- 建立应用数据目录服务。
- 加入 `AGENTS.md` 和文档。

### 验收

- 应用可以启动。
- 测试项目可以运行。
- Release 构建成功。
- 主窗口使用 ViewModel，而不是把逻辑写入 code-behind。

---

## M1：音频播放纵向切片

### 目标

验证 NAudio 和播放状态模型。

### 工作项

- 实现 `IAudioPlayer`。
- 播放一个内置或测试 WAV/MP3。
- 支持播放、暂停、停止。
- 支持完成和失败事件。
- 展示状态。

### 验收

- 能连续播放本地测试音频。
- 暂停后继续位置正确。
- 停止后状态正确。
- 损坏文件产生可处理错误。

---

## M2：TXT 导入和章节解析

### 目标

完成小说进入系统的链路。

### 工作项

- 文件选择和拖放。
- 编码检测。
- 文本规范化。
- SHA-256 去重。
- 章节切分。
- SQLite Books/Chapters。
- 书库页。
- 章节目录。

### 验收

- 至少三本不同编码和章节格式的 TXT 导入成功。
- 无章节小说也可以导入。
- 重复文件不会重复创建。
- 导入过程不冻结 UI。

---

## M3：文本分段与播放位置

### 目标

建立稳定的朗读单元和进度模型。

### 工作项

- `ITextSegmenter`。
- 自然段和标点切分。
- 长段强制切分。
- 当前段高亮。
- 上一段、下一段。
- 进度保存和恢复。

### 验收

- 章节可生成稳定段落序列。
- 当前段落能够在 UI 中定位。
- 重启后恢复到最近段落。
- 分段测试覆盖中文标点、空行和超长段落。

---

## M4：最小 HTTP TTS

### 目标

使用简单 GET 规则生成并播放在线音频。

### 工作项

- `HttpTtsRule`。
- 规则存储。
- `speakText` 和 `speakSpeed` 替换。
- HttpClient 请求。
- Content-Type 检查。
- 下载临时文件。
- 播放结果。
- 基础错误显示。

### 验收

- 至少一个 GET TTS 规则可试听。
- 能朗读小说当前段。
- JSON/Text 错误不会被当成音频。
- 网络超时可取消。

---

## M5：完整常用 HTTP 规则

### 目标

覆盖常见 Legado 风格规则。

### 工作项

- POST JSON。
- POST Form。
- 自定义 Header。
- Body 模板。
- Jint 表达式。
- 基础 `java` 辅助函数。
- LoginInfo。
- Cookie。
- 请求预览和规则测试。

### 验收

- 至少三个结构不同的规则工作正常。
- 敏感 Header 在 UI 和日志中脱敏。
- 恶意或无限循环脚本受到限制。
- 不支持字段有明确提示。

---

## M6：缓存和预取

### 目标

降低等待和重复调用。

### 工作项

- 缓存键。
- 原子写入。
- 缓存数据库。
- 缓存命中。
- 下一段和下下段预取。
- LRU 清理。
- 缓存管理界面。

### 验收

- 第二次播放相同段落不发起网络请求。
- 跳章后旧预取不会改变当前播放。
- 缓存上限生效。
- 损坏缓存能够被删除和重新生成。

---

## M7：连续播放状态机

### 目标

稳定完成长时间听书。

### 工作项

- `PlaybackCoordinator`。
- `PlaybackSession`。
- 自动跨段。
- 自动跨章。
- 会话取消。
- 旧结果隔离。
- 暂停、继续、停止。
- 错误恢复。
- 连续失败保护。

### 验收

- 连续播放至少三十分钟无错乱。
- 快速切章不会播放旧音频。
- 切换规则后使用新缓存键。
- 401、429、5xx 和断网行为符合设计。

---

## M8：规则管理和产品化 UI

### 目标

让普通用户能够完成规则导入和故障处理。

### 工作项

- JSON 对象和数组导入。
- 剪贴板导入。
- 导出。
- 编辑。
- 测试和试听。
- 兼容性提示。
- 设置页。
- 错误对话框或信息栏。
- 界面细节整理。

### 验收

- 新用户无需修改配置文件即可完成主流程。
- 规则错误能定位到请求、鉴权、限流或响应问题。
- 所有主操作可从 UI 完成。

---

## M9：质量、打包和发布候选

### 目标

生成可分发的第一版。

### 工作项

- 完善集成测试。
- 日志脱敏审核。
- 数据迁移测试。
- 崩溃恢复。
- 便携版或安装包。
- 第三方许可证清单。
- 用户文档。
- 已知限制。

### 验收

- Release 构建和测试通过。
- 新机器可安装或解压运行。
- 卸载不误删用户外部文件。
- 日志不含凭据和小说正文。
- 所有第三方依赖许可证已记录。
