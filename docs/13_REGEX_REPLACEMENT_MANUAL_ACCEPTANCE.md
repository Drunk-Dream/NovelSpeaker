# 正则替换手动验收清单

本文用于 Epic AB 的最终人工端到端验收。自动化覆盖见 `tests/NovelSpeaker.UnitTests`；以下项目需要在 Windows 10/11 桌面环境中，以真实 TXT 和 HTTP TTS 规则确认。

## 准备

- 导入一部包含广告行、标点符号和多个章节的 TXT。
- 配置一条可用 HTTP TTS 规则，并从播放页开始播放。
- 进入“设置 → 导入与文本 → 正则替换”。

## 验收矩阵

| 场景 | 规则与操作 | 预期结果 |
| --- | --- | --- |
| 广告过滤 | `^广告.*$` 替换为空，范围选“两者” | 广告不显示、不朗读；连续广告后仍能继续播放。 |
| 符号朗读 | 将 `…` 替换为“，”，范围选“仅朗读” | 正文保持原符号；重新进入当前段后 TTS 使用规范化文本。 |
| 展示隐藏 | 将括号内注释替换为空，范围选“仅显示” | 空展示段不出现在正文列表；当前音频不断开。 |
| 语音跳过 | 将某段替换为空，范围选“仅朗读” | 该段仍显示，但不发起 TTS；播放自动前进且不循环。 |
| 顺序与启用 | 调整两条相互依赖规则的顺序，并启用/禁用 | 左侧操作即时生效、失败会回滚；右侧未保存字段不覆盖启用或顺序。 |
| 当前章节刷新 | 播放中和暂停中分别修改 Replacement 或 Scope | SpeechText 改变时从映射段开头重建，分别保持播放/暂停；只改 DisplayText 时不中断音频。 |
| 映射与缓存 | 过滤当前段，切换相同位置的仅显示/仅朗读规则 | 优先定位后续可消费段、无后续时回退；仅 SpeechText 改变生成新缓存键。 |
| 稳定性 | 长章节快速切段、连续编辑规则、关闭并重启 | 无旧异步结果覆盖、无卡死；规则及排序可恢复；错误状态不泄露正文。 |
