# 设置页规划

## 1. 文档定位

本文件专门维护 NovelSpeaker 设置页的信息架构、页面布局、设置项归属、保存策略和扩展预留。`06_UI_AND_USER_FLOWS.md` 只保留设置页总览；涉及设置首页或设置二级页的变更，应优先更新本文。

设置页遵循以下原则：

- 一级设置页只提供入口，不直接放置开关、输入框、保存按钮或危险操作。
- 所有设置项都进入二级页面。
- 设置首页使用分组列表，不使用卡片。
- 设置首页入口采用接近主导航侧栏的整行按钮样式：左侧图标，中间标题，右侧进入箭头，占满内容宽度。
- 设置首页入口使用无边框整行按钮，不单独绘制边框或分隔线，依靠更宽松的上下内距以及悬停、按下、聚焦背景形成点击层级。
- 设置首页列表项不显示一行摘要，也不显示当前值。
- 常规二级页面使用统一的扁平设置列表：设置名称在上，当前值或控件在下，左对齐，项与项之间使用浅色横线分隔。
- 简单偏好自动保存；复杂编辑使用保存/取消；危险操作必须二次确认。

---

## 2. 设置首页

设置首页是 `SettingsPage`，只负责导航。

页面布局：

```text
设置

常用
  播放设置                                      >
  TTS 规则                                     >

文本处理
  导入与文本                                    >
  章节规则                                     >

应用
  缓存与数据                                    >
  外观                                         >
  诊断与关于                                    >
```

列表项要求：

- 左侧可以显示图标。
- 中间只显示标题。
- 右侧显示进入箭头。
- 按钮占满内容区宽度，点击热区覆盖整行。
- 同组入口之间不使用分隔线，分组之间使用浅色分割线。
- 不显示固定说明。
- 不显示当前关键值。
- 点击整行进入对应二级页。
- 键盘聚焦时整行可按 Enter 进入。

设置首页不包含：

- 默认语速、主题、缓存上限等具体设置项。
- 统一“保存设置”按钮。
- 清理缓存、清除凭据、重置设置等危险操作。
- TTS 规则、章节规则或缓存列表的内嵌内容。

## 3. 页面导航和通用布局

所有设置二级页使用统一结构：

```text
< 返回  页面标题

[页面内容]
```

通用要求：

- 左上角统一使用无边框返回图标按钮；默认背景透明且无常驻描边，悬停、按下和键盘聚焦时显示 Fluent 状态层。
- 鼠标位于设置内容区任意元素时，滚轮均应驱动当前可滚动区域；分栏页面的内部滚动区域优先，滚到底后再交给外层区域。
- 常规设置项使用“标题在上、值在下”的单列布局，控件与只读值左对齐。
- 设置项之间使用浅色横线分隔，不再使用双列表单对齐。
- `Alt+Left` 和 `Esc` 在无弹窗、无文本编辑冲突时执行返回。
- 简单设置保存成功默认静默。
- 保存失败使用 Snackbar，不丢失用户输入。
- 有未保存修改的复杂编辑页面离开时，使用“保存 / 放弃 / 取消”确认；离开包括返回按钮、一级导航、快捷键、正在播放入口、其它功能跳转和窗口关闭。
- 每个二级/三级 Page 是 activation 边界，进入时创建页面取消源，离开时取消加载、试听、导入和自动保存并注销导航守卫。
- 危险操作使用 ContentDialog 二次确认，并明确影响范围。
- 设置页中的规则列表、书籍列表、章节列表和弹出菜单项统一使用无边框整行按钮；外层工作台、卡片或 Popup 负责提供 surface 边界。

## 4. 播放设置

页面职责：配置听书过程中的全局播放偏好。

页面布局：

```text
< 返回  播放设置

默认语速                         [步进器/数字输入]
预取段落数量                     [步进器/数字输入]
当前 TTS 规则                    [前往 TTS 规则]
定时停止                         [后续]
```

第一版设置项：

- 默认语速。
- 预取段落数量。
- 当前 TTS 规则入口。

行为规则：

- 默认语速是全局设置。
- 播放页修改语速时，也写回全局默认语速。
- 无论从播放页还是播放设置页修改语速，都先写入同一全局设置；存在播放会话时，随后按新语速重新生成当前段音频，而不是保留会话内独立语速。
- 修改语速后，当前段从头重新生成；旧语速缓存保留给 LRU 清理。
- 预取段落数量修改后只影响新调度的预取任务，不强制取消当前正在播放的音频。
- 当前 TTS 规则不在播放设置页直接选择，只提供“前往 TTS 规则”。
- TTS 规则页是正式规则管理入口。
- 播放页仍允许快速切换规则；播放页切换规则会写入同一持久化当前规则。

后续预留：

- 定时停止。
- 单本书语速或单本书播放偏好。
- 播放失败后的自动处理策略。
- 后台播放策略。

保存策略：

- 自动保存。
- 数字输入使用防抖、失焦或回车提交。
- 输入值必须先在 ViewModel 中规范化和校验，不能把无效值写入设置文件。

## 5. TTS 规则

页面职责：管理 HTTP TTS 规则，完成规则新建、导入、编辑、试听、导出、删除，并设置当前使用规则。

整体布局采用左右分栏工作台，而不是“列表 + 弹窗”管理器。左侧只负责规则选择和基础状态，右侧负责当前选中规则的编辑与操作。

页面布局：

```text
< 返回  TTS 规则                      [新建图标] [导入文件图标] [剪贴板图标] [?]

┌──────────────────────────────┬──────────────────────────────────────────────┐
│ 规则列表                     │ 规则编辑                                     │
│                              │                                              │
│ 共 x 条规则                  │ 名称                         [文本输入]     │
│ [规则项]                     │ 启用                         [开关]         │
│   名称                       │ 请求 URL / 模板               [多行输入]     │
│   [当前] [已启用]            │ 请求方法                     [GET/POST]     │
│                              │ Content-Type                 [输入/选择]    │
│ [规则项]                     │ Header                       [可增删键值行] │
│   名称                       │ 并发限制                     [输入]         │
│   [已禁用]                   │ 请求体（仅 POST）            [多行输入]     │
│                              │                                              │
│                              │ [设为当前] [试听]                           │
│                              │ [导出] [删除] [取消] [保存]                 │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

分栏要求：

- 左侧规则列表和右侧规则编辑区域分别使用内部滚动条，参考播放页的目录与正文区域。
- 页面整体不再使用单个长滚动容器承载全部内容。
- 左侧宽度建议固定在 280～360 px 或使用 `Grid` 星级布局，不因右侧表单内容过长而被挤压。
- 左侧列表切换选中规则，右侧随选中项加载编辑副本。
- 无选中规则时，右侧显示空状态：提示选择一条规则，或使用“新建规则 / 导入文件 / 从剪贴板”开始。
- 窗口宽度不足时，优先保持左侧列表可用；右侧表单可以横向压缩或进入单列滚动，不使用 `DataGrid`。

顶部操作：

- “新建规则”：在右侧打开一条空白编辑副本，不弹出新窗口。
- “导入文件”：选择 JSON 文件后直接导入。
- “从剪贴板”：读取剪贴板 JSON 后直接导入。
- 以上三个入口使用纯图标按钮，并分别提供“新建规则”“导入文件”“从剪贴板”的 Tooltip 与无障碍名称。
- 帮助入口使用无边框图标按钮；打开规则编写帮助后，浮层关闭操作同样使用无边框图标按钮。帮助使用页内右侧覆盖浮层，不影响当前编辑副本。

左侧规则列表项：

```text
规则名称                         [当前]
已启用 / 已禁用
```

列表项要求：

- 列表项主体使用无边框整行按钮，点击后切换选中规则；按钮自身不绘制常驻边框，由悬停背景、选中背景和当前规则标记表达层级。
- 当前规则只在列表项中标记，不再在顶部单独显示“当前规则状态区”。
- 列表项不显示兼容性状态或未支持字段摘要。
- 列表项可显示一行 URL 摘要作为辅助识别信息，但第一版不是必须。
- 启用状态可以只读展示；启用开关放在右侧编辑区域，避免左侧列表承担过多编辑职责。
- 选中项、当前规则、禁用规则必须有可区分的视觉状态，并提供可访问名称。

右侧编辑区域：

- 规则编辑不使用悬浮弹窗，也不使用三级编辑页。
- 所有编辑字段都在右侧区域完成。
- 使用编辑副本，保存前不修改持久化对象。
- Header 不使用数据库式表格，使用可增删键值行或小卡片。
- 不展示原始 JSON 折叠编辑区；导出保留为显式操作。
- 不再展示“兼容性状态”和“不支持字段”。
- 多余字段在导入或保存规范化时直接丢弃，不进入 UI 展示。
- 缺少必需字段或字段类型不合法时，不允许导入或保存，并在右侧编辑区或 Snackbar 中给出可执行错误说明。
- 当前不支持 Cookie/LoginInfo；依赖这些字段或表达式的规则必须显示不兼容错误，不能被静默保存为可用规则。

试听：

- 试听按钮放在右侧编辑区域，仅保留一个“试听”按钮。
- 试听不再打开独立弹窗。
- 第一版不要求用户在试听前额外输入试听文本或语速。
- 试听文本使用应用内固定短文本，例如“你好，欢迎试听。”。
- 试听语速使用当前全局默认语速。
- 点击试听前应先校验当前编辑副本；存在未保存修改时，可以使用编辑副本直接试听，但不得自动保存。
- 试听过程中再次点击试听应取消旧试听并开始新试听，切换规则或离开页面必须取消旧试听。
- 试听失败时显示简短错误摘要，不再提供独立的请求预览区域。
- 所有错误摘要和日志必须脱敏 Header、Token、密钥和正文敏感片段。

字段说明：

- 并发限制输入格式为 `次数/毫秒`，例如 `2/1000`。

导入规则：

- 文件导入和剪贴板导入均直接导入，不提供导入预览。
- 支持单个 JSON 对象和 JSON 数组。
- 导入时先解析为来源模型，再转换为 NovelSpeaker 自有规则模型。
- 多余字段直接丢弃，不作为兼容性信息保留或展示。
- 缺少必需字段、字段类型错误、请求模板无法解析或无法转换为内部模型时，该条规则不允许导入。
- JSON 数组中部分规则失败时，可以导入有效规则，并在结果 Snackbar 或结果摘要中提示成功、失败和跳过数量。
- 导入完成后刷新左侧列表。若至少导入一条规则，默认选中新导入的第一条规则。
- 若当前没有当前规则，导入的第一条已启用规则可自动设为当前规则。
- 同名但内容不同的规则允许导入，自动改名为“规则名 (2)”、“规则名 (3)”等稳定后缀。
- 完全重复的规则可以跳过，并在结果摘要中计入跳过数量。

新建规则：

- 点击“新建规则”后，右侧进入新建编辑状态。
- 新建规则默认未持久化，必须点击保存后才进入左侧列表。
- 默认名称可以是“新建规则”，若保存时重名则按同名导入规则处理自动改名。
- 新建规则必须至少填写名称和请求 URL / 模板，并通过请求模型验证后才能保存。
- 新建保存成功后自动选中该规则；若当前没有当前规则且规则启用，可自动设为当前规则。

当前规则保护：

- 当前规则不能在无处理的情况下直接禁用或删除。
- 若用户在右侧禁用当前规则，保存时必须使用一次危险确认；确认后直接清除当前规则并进入无可用规则状态。
- 若用户删除当前规则，删除确认后直接清除当前规则并继续删除，不再要求选择替代规则。
- 不再弹出替代规则选择，也不提示候选规则。

未保存修改保护：

- 切换左侧规则、点击返回、新建、导入、删除或关闭页面前，如果右侧存在未保存修改，显示保存、放弃、取消三选项。
- “保存”成功后继续原操作。
- “放弃”丢弃编辑副本并继续原操作。
- “取消”停留在当前编辑状态。
- 保存失败时保留编辑内容，并阻止继续切换。

保存策略：

- 规则编辑、新建、删除、导入和当前规则变更使用明确操作保存。
- 右侧编辑区使用保存/取消，不自动保存每个字段。
- 设为当前规则即时保存。
- 导入完成即时写入。
- 删除必须二次确认。
- 危险操作必须二次确认。

## 6. 导入与文本

页面职责：配置导入、书籍元信息解析和正文进入消费链路前的文本处理策略。

页面布局：

```text
< 返回  导入与文本

文件名模板                       [文本输入]
模板说明                         {{name}} / {{author}}
启用超长段落拆分                 [开关]
长段拆分阈值                     [数字输入]
正则替换                         [进入规则管理]
编码识别策略                     [后续]
重复书籍处理                     [后续]
```

当前主线设置项：

- 文件名模板。
- 启用超长段落拆分。
- 长段拆分阈值。
- 正则替换入口。

文件名模板：

- 默认值为 `{{name}} 作者：{{author}}`。
- 留空则禁用模板解析，回退为文件名书名。
- 模板只影响导入时的书名和作者解析，不改变正文内容。

超长段落拆分：

- 用于避免单段过长导致 UI、TTS 请求或缓存粒度异常。
- 阈值必须有上下限校验。
- 修改后影响后续动态分段，不要求重新导入。

正则替换入口：

- 正则替换已经进入当前主线。
- 点击入口进入三级 `RegexReplacementRulesPage`。
- 当前只支持全局规则，所有书籍共用一套启用规则。
- 规则在动态段落切分完成后逐段执行，不重新划分章节或段落。
- 修改规则不需要重新导入书籍。
- 详细技术设计见 `12_REGEX_REPLACEMENT_PIPELINE.md`。

### 6.1 正则替换三级页

页面职责：管理全局正则替换规则，并将规则分别应用于正文展示和 TTS 语音文本。

页面布局：

```text
< 返回  正则替换                                      [新建规则]

┌──────────────────────────────┬──────────────────────────────────────────────┐
│ 规则列表                     │ 规则编辑                                     │
│ [启用] 规则名称              │ 名称                                         │
│        错误状态              │ 正则表达式                                   │
│ [拖动] [上移] [下移]         │ 替换文本                                     │
│                              │ 作用范围 [展示 / 语音 / 两者]                │
│                              │ 校验或运行时错误提示                         │
│                              │                         [删除] [取消] [保存] │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

左侧规则列表：

- 切换当前编辑规则。
- 启用/禁用即时保存。
- 拖动排序、上移和下移即时保存。
- 拖动手柄和上移/下移使用无边框图标按钮。
- 显示校验错误或运行时超时状态，状态不能只依赖颜色。
- 不显示“内置/自定义”类型。

右侧编辑区：

- 字段为名称、正则表达式、替换文本和作用范围。
- 不显示启用开关或排序字段。
- 不提供正则选项。
- 不提供示例文本或替换预览。
- 不提供导入、导出或默认规则操作。
- 无效 Pattern 不允许保存。
- 删除必须二次确认。

保存和刷新：

- 左侧启用与排序即时保存，失败时仅回滚对应操作。
- 右侧使用保存/取消，字段级保存不得覆盖左侧状态。
- 切换、返回、新建或删除前存在未保存修改时，显示保存、放弃、取消。
- Pattern、Replacement、Scope、启用状态、排序或删除发生变化后，立即重建当前章节的运行时段落并取消受影响的旧预取。
- 当前映射段 SpeechText 变化或被过滤时，停止当前音频并从映射后的段首重建；仅 DisplayText 变化时不中断当前音频。
- 修改前正在播放时保持播放，修改前暂停时保持暂停。
- 仅修改名称不要求重建当前章节。

导入与文本基础设置保存策略：

- 文件名模板、超长段落拆分和阈值使用自动保存。
- 文本和数字输入使用防抖、失焦或回车提交。
- 保存失败使用 Snackbar，并保留用户输入。
- 正则替换规则使用 6.1 节定义的独立保存策略。

## 7. 章节规则

页面职责：管理章节识别规则，完成规则新建、编辑、启用、排序、默认规则导入和默认规则恢复。章节规则只负责章节识别，不负责正文正则替换。

整体布局对齐 TTS 规则页，采用左右分栏工作台。左侧负责章节规则选择、启用和排序，右侧负责当前选中章节规则的名称与正则表达式编辑。

页面布局：

```text
< 返回  章节规则                         [新建规则] [导入默认] [恢复默认] [?]

┌──────────────────────────────┬──────────────────────────────────────────────┐
│ 章节规则列表                 │ 规则编辑                                     │
│                              │                                              │
│ 共 x 条规则                  │ 名称                         [文本输入]     │
│ [规则项]                     │ 正则表达式                   [文本输入]     │
│   规则名称                   │ 正则校验错误                 [字段内提示]   │
│   正则摘要                   │                                              │
│   [启用开关] [拖动手柄]      │ [删除] [取消] [保存]                         │
│   [上移] [下移]              │                                              │
│                              │                                              │
│ [规则项]                     │                                              │
│   规则名称                   │                                              │
│   正则摘要                   │                                              │
│   [启用开关] [拖动手柄]      │                                              │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

分栏要求：

- 左侧章节规则列表和右侧规则编辑区域分别使用内部滚动条，参考播放页目录与正文区域，也与 TTS 规则页保持一致。
- 页面整体不使用单个长滚动容器承载全部内容。
- 左侧宽度建议固定在 280～360 px 或使用 `Grid` 星级布局，不因右侧正则表达式过长而被挤压。
- 左侧列表切换选中章节规则，右侧随选中项加载名称和正则表达式编辑副本。
- 无选中规则时，右侧显示空状态：提示选择一条规则，或使用“新建规则 / 导入默认”开始。
- 窗口宽度不足时，优先保持左侧规则列表、启用开关和排序操作可用；右侧表单进入单列内部滚动，不使用 `DataGrid`。

顶部操作：

- “新建规则”：在右侧打开一条空白编辑副本，不弹出新窗口，不进入三级编辑页。
- “导入默认”：直接执行默认规则导入，不提供预览；完成后通过 Snackbar 或结果摘要提示新增、更新和保持不变的数量。
- “恢复默认”：重置内置规则但不删除用户自建规则，必须二次确认；完成后通过 Snackbar 或结果摘要提示结果。
- 帮助入口使用无边框图标按钮；打开章节规则帮助后，浮层关闭操作同样使用无边框图标按钮。帮助使用页内右侧覆盖浮层，不影响当前编辑副本。

左侧章节规则列表项：

```text
规则名称                         [启用开关]
正则表达式摘要                   [拖动手柄]
[上移] [下移]
```

列表项要求：

- 列表项主体使用无边框整行按钮，点击后切换右侧编辑副本；悬停、选中、禁用和拖拽目标状态由整行背景或指示元素表达。
- 列表项显示规则名称、正则表达式摘要、启用开关和排序操作。
- 列表项不显示“内置 / 自定义”状态。
- 启用开关只放在左侧列表，切换后即时保存；保存失败时恢复原开关状态并显示 Snackbar。
- 当前正在右侧编辑的规则也允许直接在左侧启用 / 禁用。
- 排序支持拖拽；拖动手柄、上移和下移均使用无边框纯图标按钮，同时提供完整的键盘等价操作和可访问名称。
- 排序即时保存；失败时回滚 UI 顺序或重新加载。
- 选中项、禁用规则和拖拽目标必须有可区分的视觉状态，并提供可访问名称。

右侧编辑区域：

- 规则编辑不使用悬浮弹窗，也不使用三级编辑页。
- 所有名称和正则表达式编辑都在右侧区域完成。
- 使用编辑副本，保存前不修改持久化对象。
- 编辑字段只包含：名称、正则表达式、正则校验提示、删除、取消、保存。
- 右侧不显示启用开关，也不显示只读启用状态。
- 正则表达式输入框必须进行即时校验；校验结果使用字段内错误提示或字段下方短提示，不额外扩展成测试区。
- 第一版不提供完整小说章节测试调试器，也不提供单行标题测试区。

启用、排序与编辑解耦：

- 左侧启用 / 禁用直接更新持久化对象的启用字段，并即时保存。
- 左侧排序直接更新持久化顺序，并即时保存。
- 右侧名称和正则表达式使用编辑副本，点击保存后才持久化。
- 右侧保存时必须基于最新持久化对象做字段级更新，只写入名称和正则表达式，不覆盖左侧已保存的启用状态和排序。
- 左侧即时保存失败时回滚对应 UI 状态，不影响右侧正在编辑的名称和正则表达式副本。
- 右侧取消只丢弃名称和正则表达式修改，不回滚左侧已经保存的启用状态或排序。

新建规则：

- 点击“新建规则”后，右侧进入新建编辑状态。
- 新建规则默认未持久化，必须点击保存后才进入左侧列表。
- 默认名称可以是“新建规则”，若保存时重名则自动追加“(2)”、“(3)”等稳定后缀。
- 新建规则必须至少填写名称和正则表达式，并通过正则校验后才能保存。
- 新建规则保存时默认启用；保存后自动选中该规则。用户可再通过左侧启用开关关闭。

删除规则：

- 用户自建规则可以删除，删除前必须二次确认。
- 内置规则不可删除，只能禁用；左侧不显示“内置 / 自定义”标签，但右侧删除按钮应根据规则能力禁用或隐藏，并给出简短说明。
- 删除成功后刷新左侧列表，并选择相邻规则；若没有规则，右侧进入空状态。

默认规则：

- 导入默认规则：补充缺失的内置规则，按稳定标识更新已有内置规则，保留用户自建规则。
- 恢复默认规则：重置内置规则，但不删除用户自建规则，必须二次确认。
- 默认规则操作开始前如右侧存在未保存名称或正则表达式修改，必须先触发未保存修改保护。

帮助浮层：

- 帮助入口与 TTS 规则页一致，使用页内右侧覆盖浮层。
- 帮助内容包括章节规则作用范围、正则表达式基本写法、常见章节标题示例、规则排序优先级、内置规则不可删除说明和误识别处理建议。
- 帮助浮层的关闭按钮使用无边框关闭图标；关闭后恢复右侧编辑区，不丢失编辑副本。

未保存修改保护：

- 切换左侧规则、点击返回、新建、导入默认、恢复默认、删除或关闭页面前，如果右侧存在未保存名称或正则表达式修改，显示保存、放弃、取消三选项。
- “保存”成功后继续原操作。
- “放弃”丢弃编辑副本并继续原操作。
- “取消”停留在当前编辑状态。
- 左侧启用 / 禁用和排序属于独立即时操作，不因右侧存在未保存修改而被阻止。
- 保存失败时保留编辑内容，并阻止继续切换。

保存策略：

- 规则名称和正则表达式使用保存/取消。
- 左侧启用开关和排序操作即时保存。
- 新建、删除、导入默认和恢复默认使用明确操作保存。
- 删除和恢复默认必须二次确认。

## 8. 缓存与数据

页面职责：提供全局缓存总览、缓存上限设置、应用数据目录入口，以及进入缓存管理三级页的入口。按书籍和按章节清理缓存统一放入缓存管理三级页。

### 8.1 缓存与数据二级页

页面布局：

```text
< 返回  缓存与数据

当前缓存总占用                   328 MB
缓存上限                         [2] [GB]
使用率                           [进度条]
LRU 清理说明                     [只读说明]

缓存管理                         [进入缓存管理]
打开应用数据目录                 [按钮]
```

第一版设置和操作：

- 显示当前缓存总占用。
- 编辑缓存上限。
- 显示使用率。
- 显示 LRU 清理说明。
- 提供缓存管理入口，进入三级缓存管理页。
- 提供打开应用数据目录。
- 二级页不直接显示按书籍缓存列表。
- 二级页不提供“清理全部缓存”；清理全部缓存只放在三级缓存管理页。

缓存上限：

- 默认 `2 GB`。
- 最小 `256 MB`。
- 可使用 MB / GB 单位输入。
- 修改后自动保存。
- 如果新上限低于当前占用，必须二次确认。
- 确认后立即按 LRU 清理旧缓存。

### 8.2 缓存管理三级页

页面职责：按书籍和章节管理音频缓存，支持清理全部缓存、清理当前书全部缓存和清理单章缓存。

整体布局对齐 TTS 规则页和章节规则页，采用左右分栏工作台。左侧选择书籍，右侧显示所选书籍的章节缓存管理。

页面布局：

```text
< 返回  缓存管理                                      [清理全部缓存]

┌──────────────────────────────┬──────────────────────────────────────────────┐
│ 书籍缓存列表                 │ 章节缓存管理                                 │
│                              │                                              │
│ 共 x 本书籍                  │ 当前书：书名 / 作者                          │
│ [书籍项]                     │ 本书缓存占用                 128 MB          │
│   书名                       │ 已缓存章节                   32 / 120        │
│   作者                       │ [清理本书全部缓存]                           │
│   缓存占用                   │                                              │
│   已缓存章节数               │ [章节项]                                      │
│                              │   第 1 章 章节标题                            │
│ [书籍项]                     │   缓存占用 4 MB                               │
│   书名                       │   完整度 12/45 段（27%）                      │
│   作者                       │   [删除图标]                                  │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

分栏要求：

- 左侧书籍列表和右侧章节缓存列表分别使用内部滚动条，参考播放页目录与正文区域。
- 页面整体不使用单个长滚动容器承载全部内容。
- 左侧宽度建议固定在 280～360 px 或使用 `Grid` 星级布局，不因右侧章节列表过长而被挤压。
- 左侧列表切换选中书籍，右侧随选中书籍加载章节缓存摘要。
- 未选择书籍时，右侧显示空状态“请选择左侧书籍”。
- 选择书籍后若该书没有章节缓存，右侧显示空状态“该书暂无缓存”。
- 第一版不提供书籍搜索和章节搜索。

左侧书籍列表项：

```text
书名
作者
缓存占用                         已缓存章节 x 章
```

左侧要求：

- 书籍列表项主体使用无边框整行按钮，显示书名、作者、缓存占用、已缓存章节数；选中书籍通过整行选中背景或指示条表达，不为每项绘制普通按钮边框。
- 如果当前缓存索引摘要只有 `BookId`、`ChapterCount`、`EntryCount`、`TotalSizeBytes`，应用服务必须联合书籍元数据补齐书名和作者，不应由 ViewModel 直接查询数据库。
- 已缓存章节数表示至少存在一条音频缓存记录的章节数量。
- 列表仅展示存在缓存的书籍；全部缓存为空时显示空状态。

右侧章节缓存管理：

```text
章节序号 / 章节标题
缓存占用 / 缓存条目数 / 章节缓存完整度
[删除图标]
```

右侧要求：

- 章节列表项主体使用无边框整行样式，显示章节序号、章节标题、缓存占用、缓存条目数和章节缓存完整度；清理本章缓存使用带 Tooltip 与无障碍名称的删除图标按钮。
- 如果当前缓存索引摘要只有 `ChapterIndex`、`EntryCount`、`TotalSizeBytes`，应用服务必须联合章节元数据补齐章节标题，不应由 ViewModel 直接查询数据库。
- 章节缓存完整度定义为“已缓存语音段数 / 当前章节可播放语音段总数”。UI 展示为 `12/45 段（27%）`；无法计算总段数时展示 `已缓存 12 段`，不显示虚假的百分比。
- 当章节切分、超长段落拆分或正则替换影响语音段数量时，完整度应按当前消费链路重新计算或标记为未知。
- 右侧顶部提供“清理本书全部缓存”，清理当前选中书籍的全部音频缓存，必须二次确认。
- 每个章节项提供“清理本章缓存”，清理该章节的全部音频缓存，必须二次确认。

清理全部缓存：

- “清理全部缓存”只放在缓存管理三级页顶部，作为危险操作。
- 清理全部缓存必须二次确认，并明确说明不会删除书籍、章节、阅读进度、TTS 规则或章节规则。
- 当前播放文件、正在生成和正在写入的缓存文件受保护。
- 清理过程异步执行，不能冻结 UI。
- 清理完成后刷新二级页总览、左侧书籍列表和右侧章节列表。
- 部分失败时显示失败摘要，不得显示为完全成功。

上下文入口：

- 书籍详情页仍保留“清理本书缓存”，作为当前书的快捷操作。
- 书籍详情页的清理行为与缓存管理三级页的“清理本书全部缓存”复用同一应用服务和保护策略。

不包含：

- 日志级别。
- 打开日志目录。
- 清除全部凭据。
- 重置所有设置。
- 缓存搜索或筛选。

后续预留：

- 清除全部凭据。
- 重置所有设置。
- 清除全部应用数据。
- 缓存搜索和高级筛选。

保存策略：

- 缓存上限自动保存。
- 触发缓存清理前必须二次确认。
- 保存或清理失败使用 Snackbar 或结果摘要。

## 11. 保存策略汇总

| 页面 | 策略 |
|---|---|
| 播放设置 | 自动保存；数字输入防抖、失焦或回车提交 |
| TTS 规则 | 右侧编辑区保存/取消；设为当前、导入和删除为明确操作保存 |
| 导入与文本 | 基础设置自动保存；正则替换左侧启用/排序即时保存，右侧字段保存/取消 |
| 章节规则 | 左侧启用和排序即时保存；右侧名称和正则表达式保存/取消，且字段级保存不覆盖左侧状态 |
| 缓存与数据 | 二级页缓存上限自动保存；三级页触发清理前二次确认 |
| 外观 | 主题立即应用并保存；窗口行为后续自动保存 |
| 诊断与关于 | 日志级别自动保存；只读信息无需保存 |

通用要求：

- 成功保存默认静默。
- 失败显示 Snackbar。
- 保存请求串行化，旧请求不得覆盖新值。
- 输入必须先规范化和校验。
- 危险操作必须二次确认。
- 复杂编辑必须支持未保存修改保护。
