# 设置页

## 1. 设置首页

设置首页只负责导航，不直接承载具体业务设置。

建议分组：

```text
常用
  播放设置
  TTS 规则
  常规

文本处理
  导入与文本
  章节规则

应用
  缓存与数据
  外观
  诊断与关于
```

所有入口使用 `icon + 标题 + Chevron` 的无边框导航行；整行 hover 使用圆角状态层。

## 2. 通用布局

- 所有正式设置页从 Page 根区域开始完整使用 `App.Brush.Canvas`；`App.Brush.Window.Background` 只属于 Window/Shell，不得在页面 Padding 周围露出一圈更深或更浅的壳层背景。
- 页面 Padding 是 Canvas 上的布局留白，不通过带 Margin 的内部 Canvas 面板模拟页面背景。
- 二级页面本身不再分过多视觉小组；相关设置用轻量分组面板组织。
- 设置分组默认依靠 Primary Surface、圆角和留白形成边界，不绘制完整外框；特殊描边只能作为有真实调用点的显式变体。
- 分组 Header 保留，但视觉权重低于设置行标题，并与设置行标题保持左侧基线对齐。
- 设置行左侧为标题和必要说明，右侧为 Switch、ComboBox、NumberBox 等控件。
- 设置行自身拥有纵向 Padding；分组 ItemContainer 不再叠加额外上下 Padding，避免单行分组过高。
- Group 负责主要横向内容 Padding，Row 不再重复同等横向缩进。
- 设置改变后按字段语义即时保存或显式保存，不让多个页面各自实现不同防抖逻辑。
- 三级页面使用明确返回入口，并继续经过统一导航 guard。

## 3. 播放设置

持久设置：

- 默认语速。
- 播放预取数量。
- 朗读标题：开启后每章正文前先朗读章节标题。

定时停止不是持久设置，只在播放页的计时器 Flyout 中提供。

播放设置修改即时保存；影响正文段落内容的设置会使对应章节当前朗读清单按需重算，语速和朗读标题等设置只改变后续播放或当前合成配置投影。已经启动的主动缓存批次继续使用创建时快照。

## 4. TTS 规则

页面采用规则工作台。

左侧卡片：

- 名称、URL/请求摘要。
- 启用开关。
- 当前规则标识与“设为当前”入口。
- `⋮` 更多：导出、删除。

右侧：

- 名称、URL、请求方式、Header/Body、Content-Type、并发/限流等现有可编辑字段。
- “试听”“取消”“保存”。

状态：

- 未修改时取消/保存禁用。
- 切换列表项、返回或退出时，有修改才触发保存/放弃/取消保护。
- “试听”针对当前编辑副本，不要求先保存。
- 导入直接执行；缺少必需字段拒绝，多余不支持字段按兼容规范处理。

## 5. 导入与文本

设置项：

- 长段落切分开关。
- 长段落阈值。
- 从文件名提取书名/作者的模板或现有导入设置。

三级入口：

- `正则替换 >`

入口使用统一导航行，不显示传统大按钮。

## 6. 正则替换三级页

采用规则工作台：

- 左侧：名称、正则摘要、启用状态、拖动排序、`⋮`。
- `⋮`：删除、上移、下移。
- 右侧：名称、正则、替换文本、作用目标等字段。
- 底部：取消、保存；无修改时禁用。
- 页面提供帮助入口，说明语法和 Display/Speech 作用范围。

## 7. 章节规则

采用相同工作台：

- 左侧：名称、正则摘要、启用、排序、`⋮`。
- 右侧：章节规则字段、取消、保存。
- 支持默认规则导入/恢复和帮助。
- 内置规则是否可删除由能力字段决定，不在列表额外显示“内置/自定义”标签。
- 排序以拖拽为主，更多菜单中的上移/下移提供键盘和备用等价操作。

## 8. 缓存与数据

二级页显示：

- 当前缓存总占用。
- 缓存容量上限和使用率。
- LRU 简要说明。
- 应用数据目录入口。
- `清理全部缓存` 危险操作。
- `缓存管理 >` 三级入口，放在本页最后。

缓存上限默认 2 GB，最小 256 MB；若调低到当前占用以下，确认后按 LRU 清理可清理条目。

“清理全部缓存”不删除书籍、阅读进度或规则，并遵守缓存保护 registry。删除某章最后一条缓存索引时，朗读清单在同一 SQLite 事务中同步回收；仍有其它缓存或受保护条目时保留清单。

## 9. 缓存管理三级页

左侧一次只选择一本书；右侧章节支持文件管理器式多选。

顶部动作：

- 清理
- 导出

0 项选择时两者禁用。

选择至少一章时“导出”启用。若选择中包含当前 TTS、语速和文本配置下不可导出的章节，点击后先确认
是否跳过；确认后只提交完整章节，取消则不选择目录、不开始导出。全部不可导出时不打开目录选择器。
导出期间页面显示状态、取消和完成后的“打开目录”入口；重复启动被拒绝，页面离开取消该页面拥有的导出操作。

缓存管理页按缓存索引显示全部有缓存章节，并查询当前文本配置下的朗读清单完整度。清单过期时首轮显示“计划更新中”；清单缺失时保留章节行并后台补建，首轮显示“计划计算中”。当前规则不可用或无可播放内容时显示明确状态。缓存写入、清理、后台计划补建和健康维护完成后，页面订阅变化通知并合并刷新。

不提供：

- 逐章节删除按钮。
- “清理本书”按钮。
- 跨书籍章节多选。

导出规则见 `05_DATA_AND_PERSISTENCE.md`。

## 10. 常规

设置：

### 关闭主窗口时

- 最小化到托盘
- 退出应用
- 每次询问

### 启动

- 启动后最小化到托盘（ToggleSwitch 布尔设置，即时持久化）

托盘本身是进程级平台能力；设置页只保存用户偏好。

迷你播放器位置/置顶由迷你窗口直接更新，不需要在常规页暴露数值设置。

## 11. 外观

- 跟随系统 / 浅色 / 深色。
- 主题切换即时生效并持久化。
- 页面根背景使用 Canvas，不在 24 px 页面 Padding 外露出 Window Background。
- “主题”分组使用优化后的 SettingsGroup/SettingsRow：无默认完整描边、中等密度、Group Header 弱于 Row Title，并保持统一左侧基线。
- 页面当前横向宽度策略保持不变，不新增统一 `MaxWidth`。
- 不为每个页面提供独立颜色配置。

全局视觉组件应引用 Design Token/semantic style，避免页面内复制 hover、圆角或 disabled 样式。

## 12. 诊断与关于

提供：

- 应用版本。
- 数据目录/日志目录打开入口。
- 数据库 schema 等安全诊断摘要。
- 第三方许可证。
- 可复制的脱敏诊断信息。

不在该页面显示或复制规则凭据、小说正文、完整请求/响应内容。

## 13. 保存策略

| 内容 | 策略 |
|---|---|
| 普通 Switch/ComboBox/数值设置 | 校验后即时持久化 |
| TTS/章节/正则规则字段 | 编辑副本 + 显式保存 |
| 规则排序/启用 | 成功后即时持久化，失败回滚 UI |
| 当前 TTS 规则 | 立即更新并通知播放层 |
| 关闭/托盘/主题 | 即时持久化 |
| 迷你窗口位置/置顶 | 窗口级节流保存 |
| 定时停止 | 不持久化 |
| 主动缓存任务 | 不作为设置持久化 |

设置页不得同步阻塞异步存储，也不得让页面自行读取/写入 `settings.json`。
