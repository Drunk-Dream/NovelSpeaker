# 设置页

## 1. 设置首页

设置首页只负责导航，不直接承载具体业务设置。

建议分组：

```text
常用
  播放设置
  TTS 规则
  常规

文本处理
  导入与文本
  章节规则

应用
  缓存与数据
  外观
  诊断与关于
```

所有入口使用 `icon + 标题 + Chevron` 的无边框导航行；整行 hover 使用圆角状态层。

设置首页是设置体系中保留视觉分组的页面：使用 `AppSettingsGroup` 按“常用 / 文本处理 / 应用”等导航类别组织入口。该分组只服务于首页的信息架构，不下放到具体设置子页面。

## 2. 通用布局

- 所有正式设置页根节点保持透明；`App.Brush.Canvas` 由 Shell 的 `NavigationView` 内容宿主统一提供，`App.Brush.Window.Background` 只属于 Window/Shell。页面不得重新绘制不透明根背景，从而避免 Padding 周围出现壳层色环或遮挡 Shell 左上圆角。
- 页面 Padding 是 Shell Canvas 上的布局留白，不通过带 Margin 的内部 Canvas 面板模拟页面背景。
- **设置首页保留分组，设置子页面不再分组。** `SettingsPage` 可使用 `AppSettingsGroup` 组织导航类别；Appearance、General、Playback、Import/Text、Cache/Data、Diagnostics/About 等具体设置子页面不得再用 Group Header、分组卡片或多个 Section Surface 划分普通设置项。
- 设置子页面在 `AppPageHeader` 下使用单一 `AppSettingsList` 展示全部设置项。该容器没有组标题，但保留与首页列表相同来源的 Primary Surface、圆角、20 px 内容 Padding 和相邻行分隔线。普通设置使用 `AppSettingsRow`，需要进入三级页面的项目可在同一列表中使用 `AppSettingsNavigationRow`；顺序本身表达逻辑关系，不再增加“主题”“启动”等重复分组标题。
- 设置行左侧为标题和必要说明，右侧为 Switch、ComboBox、NumberBox 等控件。`AppSettingsRow` 作为 `AppSettingsList`/`AppSettingsGroup` 的行内容，不自行绘制外层 Surface。
- `AppSettingsList` 与 `AppSettingsGroup` 共享列表 Surface、圆角、Padding、ItemContainer 和 Divider 规则；子页面不得为了视觉效果重新套 `AppSettingsGroup`，也不得把每一行做成独立卡片。单设置项页面同样保留一个 `AppSettingsList` Surface。
- 危险操作仍通过危险按钮样式、说明文案和确认流程表达风险，不通过恢复分组卡片来表达。
- 设置改变后按字段语义即时保存或显式保存，不让多个页面各自实现不同防抖逻辑。
- 三级页面使用明确返回入口，并继续经过统一导航 guard。

## 3. 播放设置

持久设置：

- 默认语速。
- 播放预取数量。
- 朗读标题：开启后每章正文前先朗读章节标题。

定时停止不是持久设置，只在播放页的计时器 Flyout 中提供。

播放设置修改即时保存；影响正文段落内容的设置会使对应章节当前朗读清单按需重算，语速和朗读标题等设置只改变后续播放或当前合成配置投影。已经启动的主动缓存批次继续使用创建时快照。

## 4. TTS 规则

页面采用规则工作台。

PageHeader：

- 新建。
- 从文件导入。
- 从剪切板导入。
- 帮助。
- 不提供页面级导出。

左侧卡片：

- 左右布局：左侧名称、URL/请求摘要，右侧 ToggleSwitch。
- ToggleSwitch 独立即时控制启用状态，不属于右侧编辑草稿，也不参与 Dirty State。
- 不显示当前规则标识、“设为当前”、拖动手柄或“更多”按钮。
- 右键菜单：`导出到文件`、`复制到剪切板`、删除。右键不切换当前编辑对象。

右侧：

- 名称、URL、请求方式、Header/Body、Content-Type、并发/限流等现有可编辑字段。
- “试听”“取消”“保存”。

状态：

- 页面进入时默认不打开任何规则；用户单击卡片后才打开编辑器。导入完成后只刷新列表，不自动打开导入项。
- 编辑器打开后“取消”始终可用并直接丢弃草稿、清除选择、关闭编辑器；“保存”只在草稿修改且校验通过时可用。
- 切换列表项、返回或退出时，有修改才触发统一保存/放弃/取消保护；显式点击“取消”不再额外询问。
- “试听”针对当前编辑副本，不要求先保存。
- 导入采用合并策略：完全重复跳过，同名不同内容作为新规则，不覆盖现有规则；缺少必需字段拒绝，多余不支持字段按兼容规范处理。
- 单规则导出完整保留 `IsEnabled` 等可移植状态。
- 本页不再修改当前 TTS 规则。播放页只显示已启用规则并负责切换；当前规则在本页被禁用或删除时直接清空，不自动切换其它规则。

## 5. 导入与文本

设置项：

- 长段落切分开关。
- 长段落阈值。
- 从文件名提取书名/作者的模板或现有导入设置。

三级入口：

- `正则替换 >`

入口使用统一导航行，不显示传统大按钮。

## 6. 正则替换三级页

采用规则工作台：

- PageHeader 提供新建、从文件导入、从剪切板导入和帮助，不提供页面级导出。
- 左侧卡片采用左右布局：左侧名称、正则摘要，右侧 ToggleSwitch；启用状态即时持久化且不参与 Dirty State。
- 不显示拖动手柄或“更多”按钮；右键菜单提供 `导出到文件`、`复制到剪切板`、上移、下移、删除，且右键不切换当前编辑对象。
- 排序以整卡长按约 `300 ms` 后拖动为主，使用插入线和边缘自动滚动，不实现相邻卡片位移动画；Drop 后才持久化顺序。
- 右侧：名称、正则、替换文本、作用目标等字段。
- 页面进入时默认不打开规则；单击卡片后才打开。编辑器打开后“取消”始终可用并关闭编辑器，“保存”只在草稿修改且校验通过时可用。
- 从文件/剪切板导入采用合并策略，完全重复跳过，同名不同内容作为新规则并按源顺序追加到列表末尾；导入后不自动打开规则。
- 页面提供帮助入口，说明语法和 Display/Speech 作用范围。

## 7. 章节规则

采用相同工作台：

- PageHeader 提供新建、从文件导入、从剪切板导入、默认规则导入/恢复和帮助，不提供页面级导出。
- 左侧卡片采用左右布局：左侧名称、正则摘要，右侧 ToggleSwitch；启用状态即时持久化且不参与 Dirty State。
- 不显示拖动手柄或“更多”按钮；右键菜单提供 `导出到文件`、`复制到剪切板`、上移、下移、删除，且右键不切换当前编辑对象。
- 右侧：章节规则字段、取消、保存。
- 页面进入时默认不打开规则；单击卡片后才打开。编辑器打开后“取消”始终可用并关闭编辑器，“保存”只在草稿修改且校验通过时可用。
- 从文件/剪切板导入采用合并策略，完全重复跳过，同名不同内容作为新规则并按源顺序追加到列表末尾；导入后不自动打开规则。
- 支持默认规则导入/恢复和帮助；默认规则入口与通用文件/剪切板导入并存，保持各自既有语义。
- 内置规则是否可删除由能力字段决定，不在列表额外显示“内置/自定义”标签。
- 排序以整卡长按约 `300 ms` 后拖动为主，使用插入线和边缘自动滚动，不实现相邻卡片位移动画；Drop 后才持久化，右键菜单中的上移/下移提供键盘和备用等价操作。

## 8. 缓存与数据

二级页显示：

- 当前缓存总占用。
- 缓存容量上限和使用率；LRU 简要说明随容量上限显示，不另设“缓存策略”条目。
- 应用数据目录入口。
- `清理全部缓存` 危险图标操作，使用删除图标、Tooltip 和可访问名称。
- `缓存管理 >` 三级入口，放在本页最后。

缓存上限默认 2 GB，最小 256 MB；若调低到当前占用以下，确认后按 LRU 清理可清理条目。

“清理全部缓存”不删除书籍、阅读进度或规则，并遵守缓存保护 registry。删除某章最后一条缓存索引时，朗读清单在同一 SQLite 事务中同步回收；仍有其它缓存或受保护条目时保留清单。

## 9. 缓存管理三级页

左侧一次只选择一本书；右侧章节支持文件管理器式多选。

顶部动作：

- 清理
- 导出

0 项选择时两者禁用。

选择至少一章时“导出”启用。若选择中包含当前 TTS、语速和文本配置下不可导出的章节，点击后先确认
是否跳过；确认后只提交完整章节，取消则不选择目录、不开始导出。全部不可导出时不打开目录选择器。
导出期间页面显示状态、取消和完成后的“打开目录”入口；重复启动被拒绝，页面离开取消该页面拥有的导出操作。

缓存管理页按缓存索引显示全部有缓存章节，并查询当前文本配置下的朗读清单完整度。清单过期时首轮显示“计划更新中”；清单缺失时保留章节行并后台补建，首轮显示“计划计算中”。当前规则不可用或无可播放内容时显示明确状态。缓存写入、清理、后台计划补建和健康维护完成后，页面订阅变化通知并合并刷新。

不提供：

- 逐章节删除按钮。
- “清理本书”按钮。
- 跨书籍章节多选。

导出规则见 `05_DATA_AND_PERSISTENCE.md`。

## 10. 常规

设置：

### 关闭主窗口时

- 最小化到托盘
- 退出应用
- 每次询问

### 启动

- 启动后最小化到托盘（ToggleSwitch 布尔设置，即时持久化）

托盘本身是进程级平台能力；设置页只保存用户偏好。

迷你播放器位置/置顶由迷你窗口直接更新，不需要在常规页暴露数值设置。

## 11. 外观

- 跟随系统 / 浅色 / 深色。
- 主题切换即时生效并持久化。
- 页面根节点保持透明，由 Shell 内容宿主提供 Canvas；24 px 页面 Padding 周围不得露出 Window Background，也不得遮挡 Shell 左上圆角。
- 页面只展示“应用主题”这一设置行，不再显示“主题”分组标题；该单项仍置于无 Header 的 `AppSettingsList` Surface 中，主题 ComboBox 位于行右侧。
- 页面当前横向宽度策略保持不变，不新增统一 `MaxWidth`。
- 不为每个页面提供独立颜色配置。

全局视觉组件应引用 Design Token/semantic style，避免页面内复制 hover、圆角或 disabled 样式。

## 12. 诊断与关于

提供：

- 应用版本。
- 数据目录/日志目录打开入口。
- 数据库 schema 等安全诊断摘要。
- 第三方许可证。
- 可复制的脱敏诊断信息。

不在该页面显示或复制规则凭据、小说正文、完整请求/响应内容。

## 13. 保存策略

| 内容 | 策略 |
|---|---|
| 普通 Switch/ComboBox/数值设置 | 校验后即时持久化 |
| TTS/章节/正则规则字段 | 编辑副本 + 显式保存 |
| 规则排序/启用 | 成功后即时持久化，失败回滚 UI |
| 当前 TTS 规则 | 仅播放页切换；选中规则被禁用/删除时立即清空并通知播放层 |
| 关闭/托盘/主题 | 即时持久化 |
| 迷你窗口位置/置顶 | 窗口级节流保存 |
| 定时停止 | 不持久化 |
| 主动缓存任务 | 不作为设置持久化 |

设置页不得同步阻塞异步存储，也不得让页面自行读取/写入 `settings.json`。
