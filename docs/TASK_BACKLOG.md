## 2. 已确认行为

- 播放、预取、主动缓存、导出发现清单缺失或过期时，等待重建完成后继续。
- 完整度读取发现清单过期时，首轮立即返回非正常状态，并在后台重建；完成后按章节刷新。
- 普通目录发现清单缺失时不建立清单。
- 缓存管理页发现“有缓存但清单缺失”时，保留章节行并后台补建。
- 普通目录只显示有效清单下 1%–100% 的百分比；0% 和其它非正常状态不显示。
- 缓存管理页显示全部有缓存章节，包括当前配置 0% 的章节。
- 删除某章最后一条缓存索引时，在同一 SQLite 事务中删除该章朗读清单；仍有任意缓存或受保护条目时保留清单。
- 每章仍只保存一份当前朗读清单，不保存历史 `TextProfile`，不实现全局音频去重或旧缓存迁移。

## [x] 1（P0）：在完整度查询中识别过期朗读清单

实现：

- 请求携带当前 `TextProfileFingerprint`。
- SQLite 聚合区分 `PlanMissing`、`PlanStale`、`PlanUnavailable`、有效 0% 和正常百分比。
- 过期清单不得继续参与当前配置完整度计算。

验收：

- 文本配置指纹变化后，旧 100% 不再错误显示为当前 100%。
- 前台批量查询不读取正文、不执行正则、不探测或解码音频文件。

## [x] 2（P0）：完整度读取异步重建策略

实现：

- 目录和缓存管理页读取到过期清单后，立即返回空白/更新中状态并登记后台重建。
- 普通目录不补建缺失清单。
- 缓存管理页对有缓存但缺失清单的章节自动补建。
- 同一书籍/章节的并发重建合并，任务有进程级 owner、取消源和异常处理。
- 重建完成后发布按书籍/章节定位的变化通知。

验收：

- 首轮 UI 查询不等待正文读取完成。
- 连续查询不会重复处理同一章节。
- 页面离开后不会产生迟到 UI 写入，共享任务生命周期仍由进程级 owner 管理。

## [x] 3（P0）：最后一条缓存删除时同步回收朗读清单

实现：

- 所有缓存删除路径统一经过缓存索引删除事务。
- 删除条目后，如果该 `ChapterId` 不再存在任何缓存索引，则同事务删除 `ChapterSpeechPlans`。
- `ChapterSpeechPlanSegments` 通过外键级联删除。
- 用户清理、失效修复、健康维护和 LRU 使用相同语义。

验收：

- 删除两条缓存中的第一条时保留清单，删除最后一条时删除清单和段记录。
- 受保护条目未删除时清单保留。
- 事务失败时缓存索引和清单均保持原状态。

## [x] 4（P1）：统一目录与缓存管理页状态投影

实现：

- 播放页和书籍详情目录只显示有效清单下 1%–100% 的整数百分比。
- 目录中的 0%、缺失、过期、不可用和无可播放内容继续为空白。
- 缓存管理页按缓存索引显示全部有缓存章节。
- 缓存管理页明确显示 `0/N 段 · 0%`，过期和缺失计划显示更新中状态。

验收：

- 两类页面的 0% 投影回归测试。
- 后台重建完成后章节原位刷新，不需要重新进入页面。
