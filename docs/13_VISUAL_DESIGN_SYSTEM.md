# NovelSpeaker 视觉设计系统

## 1. 设计定位

NovelSpeaker 的界面定位为轻量、专注、适合长期驻留桌面的 Windows 听书工具。整体视觉采用“柔和表面层级、克制强调色、轻量悬浮质感”的统一语言。

界面不模拟纸质书籍，不使用大面积装饰插画，也不采用音乐软件式的强烈封面视觉。书籍内容、当前播放状态和用户正在执行的操作始终是视觉中心。

所有窗口共享同一套语义颜色、尺寸和交互状态。主窗口、功能页、对话框、迷你播放器和通知不得各自建立独立风格。

## 2. 核心原则

### 2.1 内容优先

- 阅读正文、章节信息和当前播放状态优先于装饰。
- 页面只保留完成任务所需的信息，不通过更多卡片、标签或颜色增加“丰富感”。
- 主操作明确，次操作克制，低频操作放入菜单、Flyout 或次级区域。

### 2.2 单一强调色

强调色只用于：

- 当前选中或激活状态。
- 页面唯一主操作。
- 播放/暂停等核心媒体操作。
- 当前进度。
- 键盘焦点。
- 需要用户立即识别的活动状态。

普通文本、普通图标和结构边界使用中性色。一个视图中不同时出现多种竞争性的品牌色。

### 2.3 表面层级代替边框堆叠

视觉分组优先通过背景表面差异、间距和留白实现。边框只用于：

- 窗口外轮廓。
- 输入控件边界。
- 必须识别的选中或焦点状态。
- 深浅表面无法可靠区分的场景。

页面不得出现多层嵌套卡片均带完整边框的情况。

### 2.4 统一主题结构

浅色和深色模式使用相同布局、间距、圆角和组件结构，仅切换语义资源。页面 XAML 不根据主题复制两套控件树。

### 2.5 工具感而非展示感

- 阴影、渐变和动画只用于建立层级或反馈。
- 不使用持续呼吸、旋转封面、动态波形等无功能价值的效果。
- 不使用明显拟物纹理、玻璃高光或大面积彩色渐变。
- 视觉效果必须能够由 WPF 稳定实现，并在普通 Windows 桌面环境下保持清晰。

## 3. 窗口与页面层级

### 3.1 主窗口

主窗口是应用唯一的完整工作区，包含：

- 自定义标题栏。
- 一级侧边导航。
- 页面标题与上下文操作。
- 内容工作区。
- 全局后台状态入口和 Snackbar 层。

推荐默认尺寸为 `1120 × 760`，最小尺寸不低于 `960 × 640`。窗口缩小时优先压缩页面空白和次级信息，不隐藏核心操作。

主窗口外层只使用一个窗口表面。内容区内部根据页面需要使用基础表面、次级表面和抬升表面，不在整个页面外再包一层大卡片。

### 3.2 功能页

书库、播放、书籍详情、设置、规则工作台和缓存管理均作为主窗口中的页面，不创建独立顶级窗口。

页面统一结构：

```text
Page
├─ Header：标题、可选说明、页面级操作
├─ Context：筛选、选择状态或当前对象信息
├─ Content：列表、正文、表单或工作台
└─ Overlay：Flyout、Snackbar、加载与错误投影
```

### 3.3 对话框

导入确认、删除确认、目录选择前确认、未保存修改确认等短操作使用模态对话框。

对话框只承载单一决策，不复制完整页面。默认宽度按内容在 `360–520 px` 范围内，正文超过合理长度时改用页面或 Flyout。

### 3.4 辅助浮窗

迷你播放器是独立辅助浮窗。它只提供媒体控制和必要播放上下文，不承担书籍管理、缓存管理或设置功能。

迷你播放器使用比主窗口更清晰的外轮廓、阴影和抬升表面，但颜色仍来自全局主题。

## 4. 语义颜色系统

颜色只能通过语义资源引用。页面和控件模板不得直接写入业务无关的十六进制颜色。

### 4.1 基础语义

| 语义 | 浅色主题建议值 | 深色主题建议值 | 用途 |
|---|---|---|---|
| `AppBackground` | `#F4F5F9` | `#101218` | 窗口外层和页面基础背景 |
| `CanvasSurface` | `#F8F9FC` | `#15181F` | 主内容画布 |
| `PrimarySurface` | `#FFFFFF` | `#1B1F27` | 卡片、工具区、输入区域 |
| `SecondarySurface` | `#F1F3F8` | `#232832` | 次级分组和控制条 |
| `RaisedSurface` | `#FFFFFF` | `#272C36` | Flyout、对话框、浮窗 |
| `PrimaryText` | `#20242C` | `#F2F4F8` | 标题和正文 |
| `SecondaryText` | `#626A77` | `#AEB5C1` | 说明、元数据和弱信息 |
| `TertiaryText` | `#8A919D` | `#7F8794` | 占位、禁用前的弱提示 |
| `SubtleBorder` | `#1A20242C` | `#24FFFFFF` | 轻描边 |
| `StrongBorder` | `#3320242C` | `#3DFFFFFF` | 输入、选中和高对比边界 |
| `Accent` | `#5B6FD8` | `#7C8CFF` | 主操作和当前状态 |
| `AccentForeground` | `#FFFFFF` | `#101218` | 强调色表面上的内容 |
| `Danger` | `#C83C4A` | `#FF7A86` | 删除和不可逆操作 |
| `Warning` | `#A66A00` | `#F2B84B` | 可恢复风险和注意状态 |
| `Success` | `#2E7D5B` | `#66C99A` | 完成和健康状态 |

建议值是默认主题基线。若应用允许用户选择强调色，只替换 Accent 族资源，表面色和状态语义保持不变。

### 4.2 Accent 色阶

Accent 至少提供：

- `Accent`
- `AccentHover`
- `AccentPressed`
- `AccentSubtle`
- `AccentSubtleHover`
- `AccentFocusRing`

浅色主题的 `AccentSubtle` 使用 Accent 约 `10%–14%` 透明叠加。深色主题使用约 `16%–20%`，保证可辨识但不形成高饱和色块。

### 4.3 状态层

无边框按钮和列表项通过状态层表达交互：

| 状态 | 中性控件 | 强调控件 |
|---|---|---|
| Default | 透明 | Accent |
| Hover | 前景色 6%–8% | AccentHover |
| Pressed | 前景色 10%–12% | AccentPressed |
| Selected | AccentSubtle | Accent |
| Disabled | 前景和背景整体弱化 | 同左 |
| Focus | 独立 FocusRing | 独立 FocusRing |

Hover 与 Selected 必须可以同时表达。选中项 Hover 时不能丢失选中状态。

### 4.4 状态颜色使用限制

- 成功、警告和错误色不用于普通装饰。
- 缓存百分比、普通完成状态不默认涂成绿色。
- 危险色只出现在危险操作、错误内容和相关确认中。
- 信息状态优先使用 Accent 或中性资源，不新增蓝色信息色族。

## 5. 表面、描边与阴影

### 5.1 表面层级

应用只使用四级表面：

1. `AppBackground`
2. `CanvasSurface`
3. `PrimarySurface` / `SecondarySurface`
4. `RaisedSurface`

同一区域最多出现三级可见层级。避免 `RaisedSurface` 内继续堆叠多个带阴影卡片。

### 5.2 描边

- 窗口、对话框、Flyout 和迷你播放器使用 `1 px` 轻描边。
- 卡片默认无边框；与背景区分不足时才使用 `SubtleBorder`。
- 输入控件默认使用 `StrongBorder` 或等效高对比边界。
- Focus 边界独立于普通 Border，不通过替换 Border 导致布局抖动。

### 5.3 阴影

定义三个固定抬升等级：

| 等级 | 用途 | 建议效果 |
|---|---|---|
| `ElevationLow` | Hover 卡片、轻量悬浮按钮 | 偏移 1–2，模糊 8–12，低透明度 |
| `ElevationMedium` | Flyout、下拉菜单、工具浮层 | 偏移 3–4，模糊 16–20 |
| `ElevationHigh` | 对话框、迷你播放器 | 偏移 5–6，模糊 22–28 |

深色主题降低纯黑阴影强度，并通过浅色低透明度描边补充边缘识别。

页面中的静态普通卡片不默认带阴影。

## 6. 尺寸、间距与圆角

### 6.1 间距标尺

只使用以下基础间距：

```text
4, 8, 12, 16, 20, 24, 32, 40, 48
```

默认页面使用紧凑密度，推荐语义：

- 图标与文字：`8`
- 图标与文字在紧凑工具条中：`4–8`
- 同组字段：`8`
- 字段标签与控件：`4`
- 编辑输入控件内部：`8` 水平、`2` 垂直
- 卡片内部：`12–16`
- 页面区块：`16`
- 页面边距：`16`

编辑器、设置和列表使用以下密度边界：

- 设置行内边距为 `8,4`，最小高度为 `48`；右侧设置控件宽度默认为 `220`。
- 文本框、密码框和下拉框使用 `8,2` 内边距；多行编辑框只通过最小高度扩大编辑区域，不恢复额外垂直留白。
- 普通列表行内边距为 `8,4`，相邻行间距为 `4`。
- 对话框和抬升浮层内容边距默认为 `16`；只有迷你播放器等独立浮窗可按表面尺寸使用更大的专属布局。
- 规则工作台左侧列表宽度为 `300`，左右栏间距为 `12`；右侧编辑器不得再叠加 `20/24` 的页面局部边距。

紧凑密度不降低交互可达性：可点击区域仍不小于 `32 × 32`，正文阅读区和对话框的内容宽度按内容需要独立处理。

不得为局部页面随意引入 `13`、`17`、`19` 等无语义尺寸。

### 6.2 圆角

| 语义 | 圆角 |
|---|---:|
| 小型状态层、输入控件 | `6–8` |
| 列表行、普通卡片 | `10` |
| 分组工具条、对话框 | `12` |
| 主窗口内容卡片、迷你播放器 | `14–16` |
| 圆形媒体按钮 | `50%` |

同一控件族必须使用相同圆角。外层圆角应大于内部表面圆角。

### 6.3 控件高度

| 控件 | 推荐高度 |
|---|---:|
| 紧凑图标按钮 | `30–32` |
| 普通图标按钮 | `36` |
| 文本按钮、输入框、下拉框 | `36–40` |
| 主媒体按钮 | `44–48` |
| 列表行 | `48–56` |
| 设置导航行 | `52–60` |

任何可点击区域不小于 `32 × 32`。高频媒体按钮不小于 `36 × 36`。

## 7. 字体与排版

默认字体栈：

```text
Segoe UI Variable Text
Microsoft YaHei UI
Segoe UI
sans-serif
```

推荐层级：

| 语义 | 字号 | 字重 |
|---|---:|---|
| Window/Page Title | `24` | SemiBold |
| Section Title | `18` | SemiBold |
| Card/Item Title | `15–16` | SemiBold |
| Body | `14` | Regular |
| Secondary | `12–13` | Regular |
| Caption | `11–12` | Regular |
| Reading Text | 用户可配置 | Regular |

规则：

- 不通过全大写表达层级。
- 中文标题不增加字间距。
- 数字和百分比使用等宽数字特性时，不改变中文字体。
- 章节名、书名和路径允许省略号，Tooltip 提供完整内容。
- 正文阅读区行距、段间距和字体大小由阅读设置控制，不与通用表单字号绑定。

## 8. 图标系统

- 使用同一套线性或简洁填充图标，不混用明显不同笔画风格。
- 默认图标尺寸为 `16`、`18`、`20`、`24` 四档。
- 普通工具按钮优先使用 `18–20`。
- 媒体主按钮使用 `20–24`。
- 图标跟随语义前景色，不写固定黑白颜色。
- 含义明确的低频工具操作可使用纯图标，并必须提供 Tooltip 与 AutomationName。
- 危险操作、提交操作和容易歧义的动作保留文字。
- 上一章/下一章与上一段/下一段必须使用可明确区分的图形，不能只依靠按钮尺寸。

## 9. 动效

只定义三档时长：

| 时长 | 用途 |
|---|---|
| `80–100 ms` | Pressed、图标切换 |
| `140–180 ms` | Hover、展开、状态层 |
| `200–240 ms` | 页面局部进入、Flyout、对话框 |

规则：

- 动效使用标准缓出曲线。
- 页面切换只做轻微淡入或小距离位移，不做大幅横向滑动。
- 播放/暂停图标使用淡入淡出或轻微缩放。
- 加载动画只在确有异步等待时显示。
- 尊重系统减少动画设置；减少动画时保留状态变化但移除位移和缩放。
- 不使用持续装饰动画。

## 10. 通用组件

### 10.1 按钮

#### Primary Button

- 页面或对话框中只允许一个主要 Primary 动作。
- Accent 实色背景，AccentForeground 前景。
- Hover 提高亮度，Pressed 降低亮度并可缩放至 `0.98`。
- 禁用状态保持结构可辨识，不仅降低透明度到几乎不可见。

#### Secondary Button

- 使用 PrimarySurface 或透明背景。
- 可使用轻描边，但同一操作区不得所有按钮都带描边。
- 用于取消、返回和非主提交操作。

#### Subtle Button

- 默认透明，无边框。
- Hover/Pressed 使用中性状态层。
- 用于工具栏和低频操作。

#### Danger Button

- 普通页面中的删除入口优先使用中性按钮。
- 只有最终确认和明确不可逆动作使用 Danger 实色或 Danger 文字。
- Danger 与 Primary 不同时竞争视觉中心。

### 10.2 Icon Button

- 默认无边框。
- Hover 使用圆角矩形或圆形状态层。
- 媒体控制使用圆形状态层。
- Window action 使用紧凑圆角矩形状态层。
- Close 按钮只在 Hover/Pressed 使用 DangerSubtle，不在默认状态显示红色。

### 10.3 卡片与列表行

- 卡片用于承载完整对象或独立任务，不用于每个字段。
- 列表行用于连续对象，保持统一行高和对齐。
- Hover 只改变表面。
- Selected 使用 AccentSubtle、强调边缘或选中指示，不使用饱和 Accent 填满大面积。
- 多选页面不依赖 CheckBox 作为唯一选择表达，保留统一 Selected Visual State。
- 当前播放章节可在选中状态之外增加小型播放状态图标。

### 10.4 输入控件

输入框、下拉框、数字输入、开关和滑块共享：

- 相同高度、字体和焦点环。
- 标签在控件上方，不使用输入框内部 Placeholder 代替字段名称。
- 错误说明放在字段下方，不通过红色边框单独传达。
- 禁用与只读具有不同视觉。
- 表单密集页面使用固定标签列或统一垂直节奏。

### 10.5 Slider 与 Progress

- 进度轨道高度 `3–4 px`。
- 默认 Thumb 可隐藏；Hover、Focus 或拖动时显示。
- 已完成部分使用 Accent，未完成部分使用中性低透明度。
- 不使用渐变进度条和轨道阴影。
- 媒体进度使用段落语义时，Tooltip 显示“第 x / y 段”，不伪造时间。
- 不可交互的进度使用 ProgressBar，不使用 Slider 外观。

### 10.6 Menu、Flyout 与 Tooltip

- Menu/Flyout 使用 RaisedSurface、轻描边和 ElevationMedium。
- 菜单项高度不低于 `36`。
- 危险项与普通项分组，并使用 Danger 前景而非整行红色背景。
- Tooltip 简短说明行为，不重复按钮文字。
- 复杂解释使用帮助 Flyout 或页面说明，不塞入超长 Tooltip。

### 10.7 Dialog

- 标题明确说明决策对象。
- 正文说明影响和不可逆后果。
- 操作顺序与 Windows 桌面习惯一致。
- 主确认在右侧，取消在其左侧。
- 删除确认的最终按钮使用 Danger。
- 不允许通过关闭按钮绕开必须明确处理的未保存修改语义。

### 10.8 Snackbar 与状态视图

- Snackbar 用于操作结果和可恢复提示，不用于要求用户立即决策的错误。
- 同一时间只显示一个主要 Snackbar，其余排队。
- 空状态包含标题、简短说明和至多一个主操作。
- 加载状态优先保留页面骨架和尺寸，避免布局跳动。
- 错误状态提供重试或返回路径，不显示内部异常详情。

## 11. 主窗口设计

### 11.1 自定义标题栏

标题栏包含：

- 应用图标与名称。
- 可拖动空白区域。
- 最小化、最大化/恢复、关闭按钮。
- 必要时显示当前页面上下文，但不重复页面大标题。

标题栏与侧边导航共享 AppBackground 或统一壳层表面。关闭按钮默认中性，Hover 使用 DangerSubtle。

### 11.2 侧边导航

- 建议宽度 `216–232 px`。
- 一级入口仅包含图标和标题。
- 当前项使用 AccentSubtle 背景、Accent 图标或细强调条。
- Hover 与 Selected 可同时表达。
- 设置固定在导航底部或与主要工作入口分组。
- 不在一级导航中显示冗长说明或状态数字。
- 窄窗口可收缩为图标栏，但不得自动隐藏当前页标题和主要操作。

### 11.3 页面标题区

- 页面标题位于内容区顶部。
- 页面级主操作与标题同行靠右。
- 次级说明最多两行，非必要不显示。
- 选择模式下，标题区可切换为选择数量与批量操作，但保持原有页面宽度和布局稳定。

## 12. 页面最终形态

### 12.1 书库

- 使用自适应书籍卡片网格。
- 无封面时不生成伪封面插画，可使用简洁书本符号或文字识别块。
- 卡片重点显示书名、作者、当前章节和剩余章节。
- 低频操作放入 `⋮` 菜单。
- 当前书籍、Hover 和键盘焦点均有独立状态。
- 空书库使用单一导入入口。

### 12.2 书籍详情与目录

- 顶部显示书名、作者和阅读进度摘要。
- 章节目录为虚拟化列表。
- 当前章节使用 AccentSubtle 和播放/定位状态。
- 缓存百分比作为弱信息，遵循缓存设计文档中的显示规则。
- “定位到当前章节”使用悬浮图标按钮，只在当前章节离开可见区域时出现。
- 多选或批量操作使用统一选择模式，不在每行常驻多个操作按钮。

### 12.3 播放页

- 正文阅读区占据主要空间，背景保持低干扰。
- 章节标题、当前段和播放状态形成清晰层级。
- 底部或固定区域使用 SecondarySurface 媒体控制条。
- 播放/暂停是唯一强调色主媒体按钮。
- 上一段/下一段高于上一章/下一章的视觉权重。
- 语速、定时停止、缓存等低频控制使用 Flyout。
- 当前朗读段可通过轻微 AccentSubtle 高亮，不使用大面积饱和色。
- 章节侧栏与正文区使用表面差异和分隔，不使用重阴影。

### 12.4 TTS、章节与正则规则工作台

统一双栏布局：

```text
左侧：规则列表、搜索/新增、当前与启用状态、低频菜单
右侧：字段编辑、帮助、试听、取消、保存
```

- 左栏使用列表行或轻卡片，不让每条规则都出现多个常驻文字按钮。
- 当前规则与选中编辑项可分别表达。
- 右栏表单使用一致字段间距。
- 保存和取消固定在稳定位置。
- Dirty 状态通过按钮启用、标题提示和导航守卫表达，不使用持续醒目警告色。
- 试听是次级动作，保存是主动作。

### 12.5 设置

- 设置首页使用 `图标 + 标题 + Chevron` 整行导航。
- 二级页按主题分组，使用轻量 Setting Group。
- 普通布尔项使用 Switch。
- 枚举项使用 ComboBox 或明确的分段选择。
- 说明文字只在影响不直观时出现。
- 危险数据操作单独置于页面底部的危险区域，不与常规设置混排。

### 12.6 缓存管理

- 左侧为单书选择，右侧为章节列表。
- 章节列表采用文件管理器式多选和统一 Selected 状态。
- 页面级工具栏只保留作用于选中项的“清理”“导出”等动作。
- 物理缓存大小、条目数和当前配置完整度使用中性文本层级，不用多色仪表盘。
- 后台主动缓存状态使用全局入口和 Flyout，不在每个章节卡片重复复杂进度。
- 空状态、不可导出和未计算状态使用明确文字与 Tooltip。

### 12.7 迷你播放器

迷你播放器定位为中等尺寸横向媒体控制面板，不显示封面。

推荐范围：

- 宽度 `440–500 px`
- 高度 `130–160 px`
- 外层圆角 `14–16 px`
- RaisedSurface 背景
- `1 px` 轻描边
- ElevationHigh 阴影

结构：

```text
顶部：章节标题 + 置顶/恢复主窗口/关闭
次行：书名 · 第 x / y 段
中部：章节段落进度
底部：SecondarySurface 控制条
      上一章 / 上一段 / 播放暂停 / 下一段 / 下一章
```

规则：

- 播放/暂停为 `44–48 px` Accent 圆形主按钮。
- 上一段/下一段为 `36 px` 中性媒体按钮。
- 上一章/下一章为 `32–34 px`，视觉权重略低。
- 普通媒体按钮默认透明或极弱表面，Hover 使用状态层。
- 置顶激活使用 AccentSubtle 背景和 Accent 图标。
- 关闭窗口等价于恢复主窗口时，Tooltip 必须写明行为。
- 标题一行省略，书名和段落信息使用 SecondaryText。
- 不显示作者、缓存、规则、语速等非核心信息。

### 12.8 对话框与操作进度

- 导入、删除、清理和导出确认统一使用同一 Dialog Shell。
- 长操作使用页面内进度或轻量进度对话框，支持取消时必须有明确取消入口。
- 进度文案说明当前对象和完成数量，不只显示百分比。
- 成功完成后通过 Snackbar 提供摘要和可选“打开目录”等后续动作。

## 13. 浅色主题

浅色主题以柔和冷灰背景和白色表面建立层级：

- AppBackground 与 CanvasSurface 保持轻微差异。
- PrimarySurface 不使用纯白大面积高亮以外的强反差。
- 阴影负责浮窗层级，普通卡片主要依靠表面差异。
- PrimaryText 使用深灰而非纯黑。
- 未播放轨道和边框使用低透明度深色。
- Accent 只出现在关键状态，不为每张卡片增加彩色顶部条。

## 14. 深色主题

深色主题使用多级深灰，不使用纯黑底加纯白文字：

- AppBackground 最深。
- CanvasSurface、PrimarySurface、SecondarySurface 逐级提高亮度。
- PrimaryText 使用近白，SecondaryText 使用柔和灰。
- 普通图标避免纯白满强度。
- 阴影减弱，边框和表面亮度差承担更多层级。
- Accent 可适当提高亮度和降低饱和度，保证长时间使用舒适。
- 大面积 AccentSubtle 必须控制透明度，避免产生发光感。

## 15. 响应式与窗口缩放

- 主窗口以桌面布局为主，不设计手机式单列页面。
- 页面使用 Grid 星号列、合理 MinWidth 和虚拟化，不依赖固定像素定位。
- 双栏工作台在宽度不足时优先压缩左栏至最小宽度，再允许用户调整分隔。
- 书库网格按可用宽度改变列数。
- 缓存管理和目录列表保持关键列可见，次级列可缩短或折叠到详情。
- 迷你播放器保持固定结构，只允许有限宽度伸缩。
- 文本放大到 `125%–150%` 时不得遮挡主操作或切断焦点环。

## 16. 可访问性

- 所有交互控件具有 AutomationName。
- 纯图标按钮具有 Tooltip。
- 键盘焦点清晰，不能仅依赖颜色变化。
- 文本和背景满足合理对比度；正文和主要操作目标遵循 WCAG AA 的对比目标。
- 不以颜色单独表达错误、选中、成功或禁用。
- 列表、多选、对话框和 Flyout 支持完整键盘操作。
- 动效尊重系统减少动画偏好。
- 高对比模式下允许系统颜色覆盖，不能因固定图片或渐变导致内容不可读。

## 17. WPF 资源组织

建议资源结构：

```text
Resources/
├─ Themes/
│  ├─ Palette.Light.xaml
│  ├─ Palette.Dark.xaml
│  └─ ThemeResources.xaml
├─ DesignTokens.xaml
├─ SemanticStyles.xaml
├─ Components/
│  ├─ Buttons.xaml
│  ├─ Inputs.xaml
│  ├─ ListsAndCards.xaml
│  ├─ Navigation.xaml
│  ├─ MediaControls.xaml
│  ├─ DialogsAndFlyouts.xaml
│  └─ StatusViews.xaml
└─ Windows/
   ├─ WindowChrome.xaml
   └─ MiniPlayer.xaml
```

职责：

- `Palette.*` 只定义主题颜色值。
- `DesignTokens.xaml` 定义间距、圆角、尺寸、字体和动画时长。
- `SemanticStyles.xaml` 将基础令牌映射为通用语义。
- `Components/` 定义可复用控件模板和状态。
- 页面只组合语义资源，不定义全局颜色和重复模板。
- 窗口局部资源只能表达该窗口独有布局，不复制公共 Button、TextBox、Slider 或 ListItem 模板。

主题切换通过替换主题资源字典完成。已有窗口、已打开 Flyout 和迷你播放器必须同步更新，不需要重新启动应用。

## 18. 资源与代码约束

- 禁止在页面中直接写入可复用颜色、圆角、阴影和动画时长。
- 禁止通过代码隐藏动态设置常规视觉属性。
- 禁止每个页面复制相同 ControlTemplate。
- 禁止以 `Opacity` 同时弱化整个复杂容器导致文本对比度不足。
- 图标按钮不得使用固定方形 Stroke 作为 Hover。
- 不为视觉改造复制播放状态、选择状态或业务状态。
- 视觉 ViewModel 投影只提供语义状态，不返回 Brush、CornerRadius、Thickness 等 WPF 类型。
- 主题资源加载失败时回退到内置浅色或系统主题，不能导致窗口不可用。

## 19. 视觉验收标准

最终界面必须满足：

- 浅色和深色主题的所有窗口共享同一语义资源。
- Accent 只用于主操作、当前状态、进度和焦点。
- 主窗口、功能页、对话框和迷你播放器具有一致的圆角、描边和状态层。
- 页面不存在明显的边框套边框、按钮堆叠或各自定义 Hover 风格。
- 所有关键图标按钮具有 Tooltip 和 AutomationName。
- 键盘焦点、选中、Hover、Pressed、Disabled 可分别辨认。
- 主题切换后已打开窗口和浮层立即更新。
- 125% 和 150% DPI/文本缩放下布局保持可用。
- 列表虚拟化、多选、播放、缓存和规则编辑行为不因样式替换而改变。
- 完整质量门禁和 WPF 资源/模板契约测试通过。
