# 决策、风险与待定问题

## 已确定决策

### 平台和 UI

- Windows 10/11。
- C#、.NET 10、WPF。
- 使用 Wpf.Ui 4.x 提供 FluentWindow、NavigationView、图标、对话框、Snackbar 和主题能力。
- Windows 11 可使用 Mica；Windows 10 自动降级为普通主题背景。
- 第一版 x64。
- CommunityToolkit.Mvvm。
- 一级导航仅保留书库和设置；播放页与管理页均为上下文页或二级页。
- 删除底部全局播放器条，返回书库后播放可继续，并通过导航栏底部“正在播放”入口返回。
- 书库、TTS 规则和章节规则不使用 DataGrid；TTS 规则和章节规则均使用左侧列表与右侧编辑区域，缓存管理三级页使用左侧书籍列表与右侧章节缓存管理。
- 主题支持跟随系统、浅色和深色。

### 文件格式

- 第一版只支持 TXT。
- EPUB 等格式推迟。

### 在线 TTS

- 核心为 Legado 风格 HTTP TTS 规则。
- 不绑定固定云服务商。
- 第一版不需要自建后端。
- 第一版直接调用规则声明的 HTTP TTS 后端，不额外引入本地 Java 中转服务或代理层。
- 第一版以后端接口兼容为优先约束，不承诺所有规则都能零改动导入。
- 用户自行提供可用规则及其凭据。
- 完整段落音频下载后再播放。
- 不实现 WebSocket 和真正流式播放。
- 第一版承诺的是“常见 HTTP TTS 规则兼容子集”，而不是兼容所有社区规则。
- 当前版本不提供 Cookie 容器、Cookie 持久化或 `cookie.*` 兼容对象；HTTP handler 明确禁用自动 Cookie。
- 当前版本没有 LoginInfo 结构化模型、持久化字段或求值入口；包含这些依赖的规则必须明确判定为不兼容。
- 第一版不包含 Windows 本地 TTS 回退。

### 播放和缓存

- NAudio。
- 默认预取后续两个段落。
- 缓存默认上限 2 GB。
- 音频缓存保持现有位置相关键：`bookId + chapterIndex + segmentIndex + ruleId + speakSpeed + finalSpeechText`；正则替换使用最终 `SpeechText`，但不实现跨位置内容复用。
- 跳转和配置变化创建新播放会话。

### 数据

- SQLite 保存书籍、章节、进度、规则和缓存索引。
- JSON 保存非敏感设置。
- 当前主线不实现 SecretStore；TTS 规则结构化字段继续保存在 SQLite，敏感值未静态加密属于已知限制，日志、请求预览和诊断摘要必须脱敏。

### 代码架构

- 保持 Domain、Application、Infrastructure、App 四个产品项目，不为重组引入通用框架或大量细粒度程序集。
- Application 拥有导入、规则管理、播放、缓存管理和设置等用例；Infrastructure 只实现 SQLite、文件、HTTP、Jint、NAudio、JSON 和日志适配。
- Application 最终不引用 SQLite 包，也不暴露连接、命令或事务类型。
- 各层内部按 Books、Speech、Playback、Settings 等功能切片组织；共享目录只接纳两个以上稳定消费者。
- App 使用 feature slice；Page 是导航、激活、取消和未保存保护边界，Wpf.Ui 映射集中在 Shell。
- ViewModel 不引用具体 Page、Window、Dispatcher 或 WPF/Wpf.Ui 视觉类型。
- 测试拆为 Domain、Application、Infrastructure、Presentation 和 WPF 层；纯测试不依赖 STA，也不全局禁用并行。
- 架构重组采用特征测试保护的增量迁移，禁止一次性重写和长期保留 New/V2/Compat 并行实现。

## 主要风险

### 1. Legado 规则兼容度不明确

风险：

- 社区规则可能依赖复杂 `java`、`source`、Cookie 或登录脚本。
- 一些规则可能依赖 Rhino 特性。
- 不同规则的 URL 附加配置格式可能存在边缘情况。

缓解：

- 明确发布兼容矩阵。
- 第一版只承诺常见 GET/POST 规则。
- 导入时直接丢弃多余字段；缺少必需字段或无法转换时拒绝导入并显示明确错误。
- 建立真实规则样本测试集。
- 解析和脚本层独立封装。

### 2. 不可信 JavaScript

风险：

- 无限循环。
- 资源消耗。
- 访问系统能力。
- 凭据泄露。

缓解：

- Jint 白名单环境。
- 禁止 CLR。
- 设置执行限制。
- 每条规则隔离。
- 日志脱敏。
- 不提供通用网络和文件 API。

### 3. 在线服务差异

风险：

- Content-Type 不准确。
- 返回 JSON 但状态为 200。
- 音频格式不统一。
- 限流语义不同。
- Token 频繁过期。

缓解：

- 响应验证。
- 音频解码验证。
- 可配置 Content-Type。
- 规则级限流。
- 清晰错误分类。
- 登录信息独立更新。

### 4. 播放状态竞争

风险：

- 用户快速切章。
- 旧请求晚到。
- 预取和当前段重复请求。
- 多个完成事件同时推进。

缓解：

- `PlaybackSessionId`。
- CancellationToken。
- 单一协调器。
- 状态变更串行化。
- In-flight 请求去重。
- 大量状态机测试。

### 5. TXT 格式混乱

风险：

- 编码误判。
- 章节规则误判。
- 超大文件。
- 无换行文本。

缓解：

- 编码预览。
- 多级回退。
- 无章节回退。
- 长段强制切分。
- 导入过程后台执行。
- 保留原始文件。

### 6. 正则表达式性能与运行时映射

风险：

- 灾难性回溯阻塞章节加载或播放推进。
- 规则把连续多个段落处理为空，导致推进循环或进度漂移。
- 规则保存后旧章节加载、预取或播放结果晚到，覆盖新规则结果。

缓解：

- Pattern 保存前校验，运行时固定使用每条规则每段 `100 ms` 超时。
- 超时或异常只跳过当前规则，不中断章节和播放链路。
- 始终保留原始字符偏移，并基于原始偏移映射刷新后的当前段。
- 规则变化时取消旧章节加载、预取和播放会话，并隔离旧结果。

### 7. 规则敏感值未静态加密

风险：

- URL、Header 或 Body 中的敏感值以结构化字段保存在本地 SQLite；未来若加入 LoginInfo，也属于同一风险范围。
- 获得当前 Windows 用户本地数据目录访问权的进程可能读取这些值。

缓解：

- 当前主线不宣称提供静态凭据保护，并在快速入门和已知限制中明确说明。
- 日志、请求预览、异常、Snackbar 和诊断摘要必须统一脱敏。
- 不在 `settings.json`、缓存文件名或第三方许可证文件中复制凭据。
- SecretStore 作为未来安全增强单独规划，不阻塞当前发布。

### 8. GPL 许可证

参考项目使用 GPL 类许可证。直接复制其代码可能带来开源义务。

缓解：

- 只参考公开行为、字段和交互思想。
- 独立编写 C# 实现。
- 不直接翻译或复制 Kotlin 源文件。
- 保存设计决策记录。
- 发布前进行许可证审查。

### 9. 架构迁移造成行为回归

风险：

- 播放、预取、规则刷新和页面导航包含大量取消与迟到结果竞态。
- 移动类型或拆分协调器时可能改变暂停跳转、进度保存、缓存保护或错误恢复。

缓解：

- 先补特征测试，再迁移一个职责或命令族。
- `PlaybackCoordinator` 保留唯一串行化入口和状态所有者。
- 每个批次删除旧入口并运行完整质量门禁。

### 10. 跨 SQLite 与文件系统不一致

风险：

- 导入、删除、缓存写入在进程崩溃时可能留下孤儿文件、缺失文件或未完成 staging。

缓解：

- 使用持久化 operation journal 和幂等启动恢复。
- SQLite 事务只声明数据库原子性，不夸大为跨文件系统事务。
- 对每个故障点增加恢复集成测试。

### 11. 持久化路径越界

风险：

- 当前数据库保存绝对路径；数据库被篡改后，移动或删除可能指向应用数据根目录外。

缓解：

- 集中路径规范化、根目录包含检查和 reparse point 策略。
- 新数据使用相对 storage key，旧数据通过兼容读取迁移。
- 增加恶意路径不得触碰根目录外文件的测试。

### 12. 文档与实现漂移

风险：

- 历史里程碑、建议接口和已完成功能混在数字设计文档中，AI 可能重复实现或错误宣称能力。

缓解：

- 数字编号文档只描述产品/架构终态。
- 迁移过程、依赖和状态只写入 `TASK_BACKLOG.md`。
- 行为声明以代码和测试复核，重大差异同步 AGENTS、README 和决策文档。

## 已知限制（第一版）

- 不保证兼容所有社区规则。
- 不支持 WebView 登录相关规则。
- 不支持 `jsLib`。
- 不支持复杂 `source.get/put` 可变状态语义。
- 不支持会话 Cookie、Cookie 持久化和 `cookie.*` 兼容对象。
- 不支持 LoginInfo 结构化输入、持久化和求值。
- 不支持真正的流式边生成边播放。
- 不包含 Windows 本地 TTS 回退。
- 当前不提供 SecretStore，规则中的敏感值未进行静态加密。
- 首次发布不进行代码签名，Windows SmartScreen 可能显示提示。

## 默认实现决策

为了避免阻塞开发，第一版直接采用：

- 暂停时最多继续预取 1 个段落。
- 当前段最终失败后暂停；播放页仅在故障时显示“再次尝试”和“切换规则”，不提供跳过。
- 保存段内音频时间。
- 第一版重点支持 MP3 和 WAV。
- 规则没有 Content-Type 时尝试按文件头和解码结果识别。
- 删除书籍时提供“同时删除音频缓存”，默认勾选；始终保留用户外部源文件。
- 单本书专属规则和语速推迟到第二阶段；播放页仅使用当前全局规则和全局语速，播放会话只保存本次音频调度所使用的语速快照。
- 发布形式使用自包含 `win-x64` 便携目录 ZIP，不要求单文件 EXE。
- 首次发布不要求代码签名；发布文档必须说明 Windows SmartScreen 可能提示。
- 常规日志写入滚动文件，并统一经过脱敏。
- 发布包包含 `THIRD-PARTY-NOTICES.txt`，诊断与关于页提供第三方许可证入口。
- 项目以 GPL-3.0-or-later 发布；发布包同时包含项目许可证和第三方通知。
- 发布工作流只接受 `vX.Y.Z` 标签，并以标签版本写入程序集诊断信息。

## UI/UX 已确定补充决策

- 应用启动进入书库，不自动进入播放页。
- 点击书籍恢复上次位置但保持暂停。
- 书架显示自动生成的稳定文字封面、当前章节、剩余章节和无数字比例进度条。
- 书库提供按书名/作者搜索，以及最近阅读/书名排序；章节目录第一版不提供搜索。
- 播放页不提供切换书籍、停止、常驻重试、跳过和正文字号设置。
- 播放页进度条表示当前段在本章总段落中的位置，可拖动并在松开后跳转。
- 播放中进行章节、段落、规则或语速跳转后继续播放；暂停中保持暂停。
- 手动滚动后，只有连续 4 秒没有任何滚动输入且未拖动滚动条时才恢复自动居中；旧计时任务不得抢滚动。
- 设置首页使用分组列表，仅提供二级页入口，不直接显示具体设置项，也不提供统一保存按钮。
- 设置二级页为播放设置、TTS 规则、导入与文本、章节规则、缓存与数据、外观、诊断与关于。
- 二级设置页内部不再额外显示设置项分组标题。
- TTS 规则试听按钮放在右侧编辑区域，不打开独立试听弹窗，也不建立独立试听调试页。
- TTS 规则页采用左侧规则列表 + 右侧规则编辑区域，不使用悬浮编辑弹窗或三级编辑页；规则页通过页内右侧覆盖浮层提供规则编写帮助。
- 章节规则页采用左侧章节规则列表 + 右侧章节规则编辑区域，不使用独立编辑页、悬浮编辑弹窗或三级编辑页；启用开关和排序放在左侧列表并即时保存；帮助入口使用页内右侧覆盖浮层。
- 当前 TTS 规则禁用或删除时，不再要求选择替代规则；危险确认后可直接清除当前规则并进入无可用规则状态。
- 缓存与数据二级页提供全局缓存总览、可编辑缓存上限、缓存管理入口和应用数据目录入口；缓存管理三级页提供按书籍选择、章节缓存管理、清理本书缓存、清理章节缓存和清理全部缓存；单书详情页仍保留当前书缓存管理。
- 日志级别放在诊断与关于页。
- 关闭窗口行为与托盘行为归属外观页，但第一版只规划，不实现 UI；后续不单独提供“显示托盘图标”开关，选择最小化到托盘时才显示托盘图标。
- 正则替换已进入当前主线，入口为“设置 → 导入与文本 → 正则替换”。
- 当前只支持全局规则；不提供预览、导入、导出、默认规则、正则选项或单本书规则。
- 正则替换在动态分段后逐段执行，固定使用 `CultureInvariant` 和每条规则每段 `100 ms` 超时；修改规则不要求重新导入。
- 规则执行字段、启用、排序或删除变化后立即重建当前章节并取消受影响的旧预取。
- 当前映射段 `SpeechText` 变化或被过滤时才从段首重建当前音频；仅 `DisplayText` 变化时不中断音频；修改前播放/暂停状态保持不变。
- 空 `DisplayText` 不显示，空 `SpeechText` 不请求 TTS，两者都为空时运行时完全跳过。
- 返回、帮助、关闭帮助、更多菜单、搜索清空、排序方向、章节规则排序以及播放页外围控制统一使用无边框图标按钮；无边框仅移除常驻背景和描边，不移除悬停、按下、禁用和键盘焦点反馈。
- 设置入口、书籍卡片主体、章节目录、规则列表、缓存列表和菜单项统一使用无边框整行按钮，由整行悬停 / 选中背景、指示条或外层 surface 表达层级。
- 播放页规则切换使用无边框图标按钮；语速使用大圆角有边框胶囊；播放 / 暂停使用强调色实体圆形按钮；“回到当前段”使用圆形有边框悬浮按钮。

## 剩余待定问题

- 应用正式名称。
- 是否以及何时实现会话 Cookie 与 LoginInfo；若进入范围，必须作为独立兼容性 Epic，不夹带在架构迁移中。
