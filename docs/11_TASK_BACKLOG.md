# 发布版任务清单

本清单是用户向 Codex 分配任务的主入口。UI/UX 行为以 `06_UI_AND_USER_FLOWS.md` 为准，技术边界同时参考 `02_TECH_STACK_AND_ARCHITECTURE.md`、`04_PLAYBACK_PIPELINE.md` 和 `05_DATA_AND_PERSISTENCE.md`。

## 使用方式

- 每次优先只领取一个带编号的未完成任务，例如：`实现 UI-003`。
- 开始前先阅读任务依赖和相关文档，不要顺手重构无关模块。
- 任务完成后更新本文件对应复选框，并记录必要的已知限制。
- 新 UI 不得把数据库、文件系统、HTTP 或播放协调逻辑写入 code-behind。
- 若实现发现本文与 `06_UI_AND_USER_FLOWS.md` 冲突，应先修正文档或报告冲突，不自行改变产品行为。

## 单任务完成定义

除任务另有说明外，完成时必须同时满足：

- 实现与文档一致，未引入平行交互方案。
- 补齐 ViewModel、应用层或基础设施层测试；纯视觉部分至少提供可重复的手动验收步骤。
- 异步操作支持取消或隔离迟到结果，不阻塞 UI 线程。
- `dotnet format --verify-no-changes`、`dotnet build -c Release`、`dotnet test -c Release` 通过。
- 不遗留开发占位文本、临时按钮、明文敏感信息或无说明的 TODO。

## 推荐实施顺序

1. `BL-*`：补齐仍未完成的后端基础任务。
2. `UI-*`：建立 Wpf.Ui 壳层、主题和导航。
3. `LIB-*`：重做书库、导入和书籍详情。
4. `PLY-*`：重做播放页和滚动交互。
5. `SET-*`、`TTSUI-*`、`CHUI-*`、`CACHEUI-*`：设置及管理页面。
6. `UX-*`：无障碍、响应式、性能和旧 UI 清理。
7. `SEC-*`、`REL-*`：安全和发布候选验收。
