# 设置页规划

## 1. 文档定位

本文件专门维护 NovelSpeaker 设置页的信息架构、页面布局、设置项归属、保存策略和扩展预留。`06_UI_AND_USER_FLOWS.md` 只保留设置页总览；涉及设置首页或设置二级页的变更，应优先更新本文。

设置页遵循以下原则：

- 一级设置页只提供入口，不直接放置开关、输入框、保存按钮或危险操作。
- 所有设置项都进入二级页面。
- 设置首页使用分组列表，不使用卡片。
- 设置首页入口采用接近主导航侧栏的整行按钮样式：左侧图标，中间标题，右侧进入箭头，占满内容宽度。
- 设置首页入口按钮不单独绘制边框或分隔线，依靠更宽松的上下内距形成点击层级。
- 设置首页列表项不显示一行摘要，也不显示当前值。
- 常规二级页面使用统一的扁平设置列表：设置名称在上，当前值或控件在下，左对齐，项与项之间使用浅色横线分隔。
- 简单偏好自动保存；复杂编辑使用保存/取消；危险操作必须二次确认。

## 2. 设置首页

设置首页是 `SettingsPage`，只负责导航。

页面布局：

```text
设置

常用
  播放设置                                      >
  TTS 规则                                     >

文本处理
  导入与文本                                    >
  章节规则                                     >

应用
  缓存与数据                                    >
  外观                                         >
  诊断与关于                                    >
```

列表项要求：

- 左侧可以显示图标。
- 中间只显示标题。
- 右侧显示进入箭头。
- 按钮占满内容区宽度，点击热区覆盖整行。
- 同组入口之间不使用分隔线，分组之间使用浅色分割线。
- 不显示固定说明。
- 不显示当前关键值。
- 点击整行进入对应二级页。
- 键盘聚焦时整行可按 Enter 进入。

设置首页不包含：

- 默认语速、主题、缓存上限等具体设置项。
- 统一“保存设置”按钮。
- 清理缓存、清除凭据、重置设置等危险操作。
- TTS 规则、章节规则或缓存列表的内嵌内容。

## 3. 页面导航和通用布局

所有设置二级页使用统一结构：

```text
< 返回  页面标题

[页面内容]
```

通用要求：

- 左上角统一使用返回按钮。
- 常规设置项使用“标题在上、值在下”的单列布局，控件与只读值左对齐。
- 设置项之间使用浅色横线分隔，不再使用双列表单对齐。
- `Alt+Left` 和 `Esc` 在无弹窗、无文本编辑冲突时执行返回。
- 简单设置保存成功默认静默。
- 保存失败使用 Snackbar，不丢失用户输入。
- 有未保存修改的复杂编辑弹窗或编辑页返回时，使用“保存 / 放弃 / 取消”确认。
- 危险操作使用 ContentDialog 二次确认，并明确影响范围。

## 4. 播放设置

页面职责：配置听书过程中的全局播放偏好。

页面布局：

```text
< 返回  播放设置

默认语速                         [步进器/数字输入]
预取段落数量                     [步进器/数字输入]
当前 TTS 规则                    [前往 TTS 规则]
定时停止                         [后续]
```

第一版设置项：

- 默认语速。
- 预取段落数量。
- 当前 TTS 规则入口。

行为规则：

- 默认语速是全局设置。
- 播放页修改语速时，也写回全局默认语速。
- 修改语速后，当前段从头重新生成；旧语速缓存保留给 LRU 清理。
- 预取段落数量修改后只影响新调度的预取任务，不强制取消当前正在播放的音频。
- 当前 TTS 规则不在播放设置页直接选择，只提供“前往 TTS 规则”。
- TTS 规则页是正式规则管理入口。
- 播放页仍允许快速切换规则；播放页切换规则会写入同一持久化当前规则。

后续预留：

- 定时停止。
- 单本书语速或单本书播放偏好。
- 播放失败后的自动处理策略。
- 后台播放策略。

保存策略：

- 自动保存。
- 数字输入使用防抖、失焦或回车提交。
- 输入值必须先在 ViewModel 中规范化和校验，不能把无效值写入设置文件。

## 5. TTS 规则

页面职责：管理 HTTP TTS 规则，并设置当前使用规则。

页面布局：

```text
< 返回  TTS 规则                      [新建] [导入文件] [从剪贴板] [?]

当前规则状态

[规则列表]
  规则名称 / 启用状态 / 当前标记 / 兼容性状态 / 不支持字段摘要
  [启用开关] [试听] [更多]
```

页面要求：

- 使用卡片列表或设置式列表，不使用 `DataGrid`。
- 顶部提供帮助入口，打开规则编写帮助。
- 帮助内容应覆盖规则字段、模板表达式、Header、LoginInfo、试听、兼容限制和常见错误。
- 当前规则必须有明确标记。
- “设为当前规则”在本页即时保存。
- 播放页快速切换规则复用同一持久化当前规则。
- 规则编辑使用悬浮弹窗，不使用三级编辑页。
- 试听使用小型模态对话框，不建立独立试听调试页面。

规则列表项操作：

- 点击主体：打开规则编辑悬浮弹窗。
- 启用开关：即时保存。
- 试听：打开试听对话框。
- 更多菜单：设为当前规则、导出、删除。

规则编辑悬浮弹窗：

```text
规则编辑

名称                             [文本输入]
启用                             [开关]
请求 URL / 模板                   [多行输入]
请求方法                         [GET/POST]
Content-Type                     [输入/选择]
请求体                           [多行输入]
Header                           [可增删键值行]
LoginInfo 定义                   [可增删键值行]
Cookie / 并发限制等高级字段       [输入]
原始 JSON                        [折叠高级区]
兼容性状态                       [只读]
不支持字段                       [只读]

[试听] [取消] [保存]
```

编辑规则：

- 使用编辑副本，保存前不修改持久化对象。
- 原始 JSON 和结构化字段共享同一编辑模型。
- 原始 JSON 修改后必须成功解析、转换和验证才能保存。
- 有未保存修改时关闭弹窗，显示保存、放弃、取消三选项。
- Header 和 LoginInfo 不使用数据库式表格，使用可增删行或小卡片。

当前规则保护：

- 当前规则不能在无处理的情况下直接禁用或删除。
- 若存在其他已启用规则，提示先选择替代规则。
- 若没有替代规则，可提供明确的“清除当前规则并继续”危险选项，使应用进入无可用规则状态。

保存策略：

- 列表操作即时保存。
- 编辑弹窗使用保存/取消。
- 危险操作必须二次确认。

## 6. 导入与文本

页面职责：配置导入、书籍元信息解析和正文进入消费链路前的文本处理策略。

页面布局：

```text
< 返回  导入与文本

文件名模板                       [文本输入]
模板说明                         {{name}} / {{author}}
启用超长段落拆分                 [开关]
长段拆分阈值                     [数字输入]
正则替换                         [后续，进入规则管理]
编码识别策略                     [后续]
重复书籍处理                     [后续]
```

第一版设置项：

- 文件名模板。
- 启用超长段落拆分。
- 长段拆分阈值。

文件名模板：

- 默认值为 `{{name}} 作者：{{author}}`。
- 留空则禁用模板解析，回退为文件名书名。
- 模板只影响导入时的书名和作者解析，不改变正文内容。

超长段落拆分：

- 用于避免单段过长导致 UI、TTS 请求或缓存粒度异常。
- 阈值必须有上下限校验。
- 修改后影响后续动态分段，不要求重新导入。

正则替换长期规划：

- 第一版暂不实现正则替换。
- 后续在本页提供“正则替换”入口，进入规则管理页面。
- 正则替换位于“根据书籍偏移和长度读取内容”与“消费内容”之间。
- 修改正则替换规则不需要重新导入书籍。
- 每条规则可选择作用范围：展示、语音、两者。
- 展示范围影响 UI 文本。
- 语音范围影响请求 TTS 的文本和音频缓存键。
- 多条正则替换规则按顺序组合执行。
- 详细技术设计见 `12_REGEX_REPLACEMENT_PIPELINE.md`。

保存策略：

- 自动保存。
- 文本和数字输入使用防抖、失焦或回车提交。
- 保存失败使用 Snackbar，并保留用户输入。

## 7. 章节规则

页面职责：管理章节识别规则。

页面布局：

```text
< 返回  章节规则                         [新建] [导入默认] [恢复默认]

[章节规则列表]
  名称 / 正则表达式摘要 / 启用状态 / 排序手柄
  [启用开关] [更多]
```

页面要求：

- 使用卡片列表或设置式列表，不使用 `DataGrid`。
- 章节规则只负责章节识别，不负责正文正则替换。
- 点击列表项进入章节规则编辑页。
- 启用开关即时保存。
- 排序即时保存；失败时回滚 UI 顺序或重新加载。
- 第一版不提供完整小说章节测试调试器。
- 后续可增加“测试识别结果”面板。

编辑页：

```text
< 返回  编辑章节规则

名称                             [文本输入]
正则表达式                       [文本输入]
启用                             [开关]
基础语法说明                     [只读说明]
即时校验结果                     [只读状态]

[取消] [保存]
```

默认规则：

- 导入默认规则：补充缺失的内置规则，按稳定标识更新已有内置规则，保留用户自建规则。
- 恢复全部默认规则：重置内置规则，但不删除用户自建规则，必须二次确认。

保存策略：

- 列表启用和排序即时保存。
- 编辑页使用保存/取消。
- 删除和恢复默认必须二次确认。

## 8. 缓存与数据

页面职责：提供全局缓存视角和应用数据入口。

页面布局：

```text
< 返回  缓存与数据

当前缓存总占用                   328 MB
缓存上限                         [2] [GB]
使用率                           [进度条]
LRU 清理说明                     [只读说明]

[按书籍缓存列表]
  书名 / 作者 / 缓存占用 / 最近访问时间 / [清理本书缓存]

清理全部缓存                     [危险按钮]
打开应用数据目录                 [按钮]
```

第一版设置和操作：

- 显示当前缓存总占用。
- 编辑缓存上限。
- 显示使用率。
- 显示 LRU 清理说明。
- 按书籍显示缓存占用。
- 允许清理任意一本书的缓存。
- 提供清理全部缓存。
- 提供打开应用数据目录。

缓存上限：

- 默认 `2 GB`。
- 最小 `256 MB`。
- 可使用 MB / GB 单位输入。
- 修改后自动保存。
- 如果新上限低于当前占用，必须二次确认。
- 确认后立即按 LRU 清理旧缓存。

缓存清理：

- “清理本书缓存”在全局缓存列表中针对任意书籍执行。
- 书籍详情页仍保留当前书缓存管理，作为上下文快捷操作。
- “清理全部缓存”不删除书籍、章节、阅读进度、TTS 规则或章节规则。
- 当前播放文件和正在写入的缓存文件受保护。
- 清理过程异步执行，不能冻结 UI。
- 清理完成后刷新统计。

不包含：

- 日志级别。
- 打开日志目录。
- 清除全部凭据。
- 重置所有设置。
- 第一版章节级缓存清理。

后续预留：

- 清除全部凭据。
- 重置所有设置。
- 清除全部应用数据。
- 章节级缓存占用和清理。

保存策略：

- 缓存上限自动保存。
- 触发清理时必须二次确认。
- 保存或清理失败使用 Snackbar 或结果摘要。

## 9. 外观

页面职责：配置主题和窗口外观行为。

页面布局：

```text
< 返回  外观

主题                             [跟随系统/浅色/深色]
关闭窗口时                       [后续：退出应用/最小化到托盘]
启动时恢复窗口大小和位置         [后续]
```

第一版设置项：

- 主题。

主题：

- 默认跟随系统。
- 支持跟随系统、浅色、深色。
- 修改后立即应用并自动保存。
- 持久化使用稳定枚举值，不依赖本地化文案。

关闭窗口行为 / 托盘行为：

- 已纳入规划，但第一版只规划，不实现 UI。
- 后续实现时放在外观页。
- 可选值为退出应用、最小化到托盘。
- 不单独提供“显示托盘图标”开关。
- 只有当用户选择“关闭窗口时最小化到托盘”时才显示托盘图标。
- 托盘菜单第一版实现时可只包含显示窗口和退出；播放暂停等菜单项后续再加。

保存策略：

- 主题自动保存并立即生效。
- 后续窗口行为设置自动保存。

## 10. 诊断与关于

页面职责：展示运行信息、打开日志目录、配置日志级别，并提供后续诊断入口。

页面布局：

```text
< 返回  诊断与关于

应用名称                         NovelSpeaker
应用版本                         x.y.z
项目说明                         [只读文本]
数据库版本 / SchemaVersion        [只读]
应用数据目录路径                 [只读，可复制]
日志目录路径                     [打开日志目录]
日志级别                         [下拉选择]
复制脱敏诊断摘要                 [后续]
第三方许可证                     [后续]
```

第一版内容：

- 应用名称。
- 应用版本。
- 项目说明。
- 数据库版本 / SchemaVersion。
- 应用数据目录路径，只读展示，可复制。
- 打开日志目录。
- 日志级别。

后续内容：

- 复制脱敏诊断摘要。
- 第三方许可证入口。

日志级别：

- 放在诊断与关于页，不放在缓存与数据页。
- 自动保存。
- 文案使用用户可理解的等级，持久化使用稳定枚举值。

不包含：

- 缓存清理。
- 应用数据目录打开按钮；该操作归属缓存与数据页。
- 清除凭据。
- 重置所有设置。

## 11. 保存策略汇总

| 页面 | 策略 |
|---|---|
| 播放设置 | 自动保存；数字输入防抖、失焦或回车提交 |
| TTS 规则 | 列表操作即时保存；编辑弹窗保存/取消 |
| 导入与文本 | 自动保存；文本和数字输入防抖、失焦或回车提交 |
| 章节规则 | 列表启用和排序即时保存；编辑页保存/取消 |
| 缓存与数据 | 缓存上限自动保存；触发清理前二次确认 |
| 外观 | 主题立即应用并保存；窗口行为后续自动保存 |
| 诊断与关于 | 日志级别自动保存；只读信息无需保存 |

通用要求：

- 成功保存默认静默。
- 失败显示 Snackbar。
- 保存请求串行化，旧请求不得覆盖新值。
- 输入必须先规范化和校验。
- 危险操作必须二次确认。
- 复杂编辑必须支持未保存修改保护。

## 12. 第一版与后续边界

第一版必须完成：

- 设置首页改为分组入口列表。
- 所有设置项迁移到二级页。
- 播放设置：默认语速、预取段落数量、当前 TTS 规则入口。
- TTS 规则：列表、当前规则、导入、导出、启用、试听、悬浮编辑弹窗、帮助入口。
- 导入与文本：文件名模板、超长段落拆分、长段拆分阈值。
- 章节规则：列表、编辑、启用、排序、默认规则操作。
- 缓存与数据：总览、缓存上限、按书籍缓存列表、清理本书缓存、清理全部缓存、打开应用数据目录。
- 外观：主题。
- 诊断与关于：版本、数据库版本、路径展示、打开日志目录、日志级别。
- 自动保存和危险操作二次确认。

后续规划但第一版不要求实现：

- 正则替换。
- 定时停止。
- 单本书播放偏好。
- 关闭窗口行为 / 托盘行为 UI。
- 复制脱敏诊断摘要。
- 第三方许可证入口。
- 清除全部凭据。
- 重置所有设置。
- 章节级缓存清理。
