# UI 与用户流程

## 1. 文档定位

本文件是 NovelSpeaker 当前 UI/UX 设计基线的总览。实现、评审和验收均以本文以及设置页专项文档 `07_SETTINGS_PAGES.md` 为准。

涉及以下内容时，应更新本文或对应专项文档，不再建立并行方案：

- 主窗口壳层、导航和页面层级。
- 书库、播放、设置及各二级管理页面。
- 播放状态、跳转、自动滚动和错误恢复。
- 书籍、TTS 规则、章节规则和缓存的管理交互。
- 主题、响应式布局、键盘操作和可访问性。

设置首页、七个设置二级页、保存策略和后续设置扩展统一维护在 `07_SETTINGS_PAGES.md`。`TASK_BACKLOG.md` 负责将设计拆成可分配给 Codex 的开发任务；若两者冲突，以设计文档为产品行为准。

---

## 2. 已确定的产品方向

- 技术栈保持 `.NET 10 + WPF + CommunityToolkit.Mvvm`。
- UI 采用 `Wpf.Ui 4.x` 的 Fluent 风格组件和主题能力。
- 支持 Windows 10 和 Windows 11；Windows 11 可使用 Mica 等效果，Windows 10 自动降级。
- 主窗口一级入口仅保留“书库”和“设置”。
- 播放页、书籍详情和设置二级页均为上下文页或二级页。
- 删除底部全局播放条，不再在所有页面常驻完整播放控制。
- 不使用 `DataGrid` 作为书库、TTS 规则或章节规则的主要交互形式。
- 优先使用图标、卡片、菜单和清晰的状态反馈，去除开发阶段残留说明文本。
- 应用启动进入书库，不自动播放声音。
- 从书库打开书籍时恢复上次位置，但保持暂停。

## 3. 设计原则

1. **听书优先**：正文用于定位和辅助阅读，不扩展为完整电子书阅读器。
2. **低打扰**：成功操作尽量静默或使用 Snackbar；仅危险操作和未保存修改使用对话框。
3. **上下文明确**：用户始终能确认当前书籍、章节、段落和播放状态。
4. **主操作集中**：播放页承载全部播放控制，书库页不复制完整播放器。
5. **复杂管理页工作台化**：TTS 规则、章节规则和缓存管理等复杂页面优先使用左侧选择、右侧编辑/管理的分栏工作台。
6. **状态不只靠颜色**：选中、播放、错误、禁用等状态同时使用图标、文字或控件状态表达。
7. **不显示无价值信息**：不在书架展示最近导入时间；不常驻显示当前 TTS 规则名称。
8. **避免竞态**：页面跳转、播放会话、自动滚动、导入和规则试听必须可取消并隔离旧结果。

## 4. 信息架构

```text
MainWindow / AppShell
├─ LibraryPage                         一级入口
│  ├─ DirectImportFlow                 直接导入流程，必要时打开最小编码选择对话框
│  ├─ BookDetailsPage                  二级页
│  └─ PlayerPage                       上下文页
└─ SettingsPage                        一级入口，分组列表，仅提供入口
   ├─ PlaybackSettingsPage             二级页
   ├─ TtsRulesPage                     二级页，左侧规则列表 + 右侧规则编辑 + 页内帮助浮层
   ├─ ImportTextSettingsPage           二级页
   │  └─ RegexReplacementRulesPage     三级页，左侧规则列表 + 右侧编辑区
   ├─ ChapterRulesPage                 二级页，左侧规则列表 + 右侧规则编辑 + 页内帮助浮层
   ├─ CacheAndDataPage                 二级页，总览 + 缓存管理入口
   │  └─ CacheManagementPage           三级页，左侧书籍列表 + 右侧章节缓存管理
   ├─ AppearanceSettingsPage           二级页
   └─ DiagnosticsAboutPage             二级页
```

### 4.1 一级导航

左侧 `NavigationView` 仅显示：

- 书库。
- 设置。

导航栏规则：

- 默认展开，约 `220 px`，显示图标和文字。
- 用户可以手动折叠为约 `64 px` 的纯图标状态。
- 窗口宽度不足约 `1080 px` 时自动折叠。
- 书库和设置之间切换不销毁正在播放的会话。

### 4.2 正在播放入口

导航栏底部显示紧凑的“正在播放”入口：

- 仅在已打开过一本书且存在播放会话上下文时显示。
- 显示耳机/播放状态图标、书名和简短状态。
- 暂停时仍保留。
- 播放错误时显示错误状态图标。
- 点击后返回对应书籍的播放页。
- 不提供播放、暂停、上一段等控制，避免重新形成全局播放条。

### 4.3 二级页导航

- 二级页左上角统一使用无边框返回图标按钮；默认不绘制常驻背景或描边，仅在悬停、按下和键盘聚焦时显示 Fluent 状态层。
- `Alt+Left` 和 `Esc` 在无对话框、无文本编辑冲突时执行返回。
- 返回应恢复上一页面的滚动位置和筛选状态。
- 播放页返回书库时音频继续播放；导航栏底部入口用于返回播放页。

## 5. 主窗口与视觉系统

### 5.1 主窗口

- 使用 `Wpf.Ui.Controls.FluentWindow`。
- 默认尺寸约 `1280 × 820`。
- 最小尺寸约 `900 × 640`。
- Windows 11 可启用 Mica；不支持时使用主题背景色，不因特效失败影响启动。
- 内容区使用统一页面边距、最大阅读宽度和滚动策略；鼠标位于内容区任意元素时，滚轮应驱动所在可滚动区域，不要求将光标移到滚动条上。
- 嵌套滚动区域优先响应；到达其顶部或底部后，滚轮继续驱动外层可滚动区域。
- 播放页、书籍详情和左右分栏工作台等固定视口页面统一使用导航视口高度约束；不得通过页面内容撑高外层导航滚动区域。标题和固定操作区留在视口内，长列表或编辑区各自承担内部滚动。

### 5.2 主题

设置支持：

- 跟随系统。
- 浅色。
- 深色。

要求：

- 默认跟随系统。
- 修改后立即生效并自动保存。
- 使用 Windows 系统强调色表达主按钮、选中状态和焦点。
- 颜色必须来自主题资源，页面 XAML 不再散落固定十六进制颜色。

### 5.3 图标、文本与按钮层级

- 使用 Wpf.Ui `SymbolIcon` 或统一图标资源，所有图标按钮必须提供 `ToolTip` 和 `AutomationProperties.Name`。
- **仅图标按钮**：返回、帮助、关闭帮助、更多菜单、搜索清空、排序方向、上移 / 下移、拖动手柄、播放控制按钮，以及书库导入小说、TTS 规则页新建规则 / 文件导入 / 剪贴板导入和章节缓存清理；这些按钮必须提供 Tooltip 与 `AutomationProperties.Name`。
- **图标 + 文字按钮**：章节规则页新建规则、导入默认、恢复默认，清理缓存、进入缓存管理等需要用户快速理解的入口。
- **文字为主按钮**：保存、取消、删除、确认、放弃、替换等决策类或危险操作。危险操作可附带警示图标，但不得只显示图标。
- 同一页面中相同语义的操作保持同一呈现方式；不要在一处使用纯图标、另一处使用纯文字。
- 图标不得替代必要说明。首次可见、低频、不可逆或容易误解的操作必须保留文字；本节明确列出的高频工具栏入口和章节缓存清理为产品指定的纯图标例外，并通过 Tooltip 与无障碍名称补充说明。

按钮视觉层级固定为以下四类：

1. **无边框图标按钮**：返回、帮助、关闭帮助、更多菜单、搜索清空、排序方向、章节规则上移 / 下移 / 拖动手柄、播放页规则切换，以及上一章 / 上一段 / 下一段 / 下一章。默认背景透明且不绘制常驻边框；悬停、按下和键盘聚焦时必须显示清晰的 Fluent 状态层，不能因“无边框”而失去可发现性或焦点反馈。
2. **无边框整行按钮**：设置首页入口、书籍卡片主体、章节目录项、规则列表项、缓存书籍列表项、章节缓存列表项、弹出菜单项等。按钮自身不单独绘制边框，由所在卡片、列表选中背景、悬停背景或菜单 surface 表达层级；整行点击热区必须保留。
3. **紧凑有边框控件**：播放页语速使用图标 + 原始整数值的紧凑圆角按钮，保留轻量描边；可见按钮高度约 `40 px`、宽度保持紧凑，避免形成过度扁平的细长胶囊；“回到当前段”使用圆形有边框悬浮按钮，可附加轻量阴影以区别正文内容。
4. **标准有边框或实体按钮**：章节规则页导入默认、恢复默认，书籍详情和缓存页的清理操作等图标 + 文字操作保留标准按钮轮廓；保存、取消、删除、确认等决策操作保留文字和清晰边界；播放 / 暂停作为主操作使用强调色实体圆形按钮。书库导入小说、TTS 规则页新建 / 导入和章节缓存清理按上面的产品指定例外使用纯图标按钮。

### 5.4 组件风格一致性

- 自定义按钮、图标按钮和悬浮按钮必须基于现有 Fluent 默认控件样式扩展，只允许调整尺寸、内边距、圆角和布局，不得另起一套脱离全局主题的颜色体系。
- 无边框按钮仅移除常驻背景与描边，不移除悬停、按下、禁用和键盘焦点状态；焦点轮廓或状态层必须满足键盘可达性。
- 无边框整行按钮不得再嵌套一层普通按钮边框；选中态、当前项、禁用态和拖拽目标应由整行背景、左侧指示条、图标或文字状态共同表达。
- `Popup`、菜单和其它非模态临时面板必须复用与页面卡片或输入控件一致的背景、描边和圆角资源；菜单外层保留 surface 边界，内部菜单项使用无边框整行样式。
- 新增页面部件在浅色和深色主题下，都应与现有卡片、按钮、输入框保持同一套 surface 层级和控件语言；发现偏离时优先收敛到既有样式资源，而不是继续扩散新的局部风格。

### 5.5 自动封面

第一版不保存用户封面文件。封面由书籍信息稳定生成：

- 使用规范化书名计算稳定哈希。
- 哈希决定预设渐变组合、装饰图形和文字布局。
- 同一本书在重启和不同页面中保持同一视觉。
- 封面显示书名，必要时使用省略和分行。
- 深色主题下自动保证文字对比度。
- 不提供随机换色或手动编辑封面。

## 6. 书库页

### 6.1 页面职责

书库页负责：

- 导入 TXT。
- 搜索和排序书籍。
- 进入播放页。
- 进入书籍详情。
- 删除书籍。

书库页不负责：

- 切换 TTS 规则。
- 直接编辑元信息。
- 展示导入时间。
- 常驻显示导入调试信息、导入预览或后端状态文本。

### 6.2 页面布局

书库页采用“顶部工具栏 + 响应式书架网格”，页面主体不再包裹一个大面积外层容器。内容区直接承载工具栏、状态提示和书籍卡片，弱化空白感。

```text
书库                                      [搜索框        x] [排序：最近阅读 v] [导入图标]
共 x 本 · 最近阅读优先

[横向书籍卡片] [横向书籍卡片]
[横向书籍卡片] [横向书籍卡片]
```

布局要求：

- 页面使用统一外边距和标题区，不再额外绘制覆盖整页的大卡片背景。
- 搜索框、排序菜单和导入按钮在标题行右侧对齐；空间不足时允许换到第二行，但不得挤压标题。
- “清空搜索”作为搜索框内部无边框图标按钮，仅在有搜索文本时显示；不再放置独立“清空”按钮。
- 标题下方可显示轻量摘要，例如 `共 12 本 · 最近阅读优先`。摘要不显示最近导入时间。
- 书籍区域使用响应式 `ItemsControl` / `WrapPanel` / 虚拟化面板等卡片网格，不使用 `DataGrid`。
- 横向书籍卡片为默认形态：封面在左，信息在右。
- 常规宽屏建议一行显示 2～3 张横向卡片；最小宽度下至少保持一列可用。
- 卡片区域自身可滚动；顶部工具栏固定在页面可视范围内。

空书库时改为：

```text
书库                                      [导入图标]

[空状态图标]
尚未导入小说
将 TXT 拖到这里，或选择文件导入
[导入图标]
```

空状态要求：

- 空状态不使用开发占位文案。
- 支持拖入单个 `.txt` 文件。
- 非 TXT、多文件、目录拖入时拒绝并给出简短原因。

### 6.3 搜索与排序

书库提供轻量搜索：

- 按书名和作者匹配。
- 输入后本地即时过滤，可使用短延迟避免频繁刷新。
- 搜索框内使用无边框清空图标按钮恢复完整书架。
- 搜索无结果时显示页内空状态，并提供清空搜索入口。

排序选项：

- 最近阅读，默认。
- 书名。

排序规则：

- “最近阅读”优先排列有阅读记录的书籍。
- 从未播放的书籍排在其后。
- 不提供按最近导入排序。
- 第一版不提供手动拖动排序。

### 6.4 最近阅读入口

- 不再提供独立“继续收听”卡片。
- 书库默认使用“最近阅读”排序，使最近有阅读记录的书籍出现在书架前部。
- 用户从书籍卡片进入播放页时，仍恢复上次章节和段落，并保持暂停。

### 6.5 书籍卡片

横向书籍卡片显示：

- 自动生成封面。
- 书名。
- 作者；作者为空时显示“未知作者”。
- 当前章节标题。
- `剩余 N 章` 或最后一章状态。
- 无数字比例的总体进度条。

卡片视觉要求：

- 封面固定在左侧，保持接近书封比例。
- 信息区按“书名 > 作者 > 当前章节 > 剩余章节 / 进度”排列。
- 卡片背景、圆角、描边和悬停态使用统一 Fluent 资源，不使用页面内硬编码颜色。
- 悬停或键盘聚焦时增强描边或阴影，并显示右上角更多菜单。
- 卡片高度固定或受控，长书名和章节标题使用省略与 Tooltip，不能撑破网格。
- 不额外显示“正在阅读 / 未开始 / 已读完”状态标签，保持卡片简洁。

交互：

- 卡片主体作为无边框整卡按钮，左键点击后进入该书播放页；卡片自身的 surface、描边与悬停态负责表达边界，不再在内部叠加普通按钮边框。
- 卡片右上角在悬停、键盘聚焦或触控场景下显示更多菜单；更多按钮使用无边框纯图标样式，默认不显示常驻背景或描边，仅在悬停、按下和聚焦时显示圆形或圆角状态层；按钮位于卡片内部，不得漂浮在卡片外。
- 更多菜单包含：
  - 书籍详情。
  - 删除书籍。
- 清理单本书缓存放在书籍详情页，不重复放入一级菜单。

不显示：

- 最近导入时间。
- 最近播放时间。
- `第 X / Y 章` 文字。
- 直接编辑输入框。

### 6.6 剩余章节定义

`剩余章节数 = 总章节数 - 当前章节索引 - 1`。

- 当前章节是否朗读完成不影响该数字。
- 已到最后一章时显示“最后一章”或“剩余 0 章”，全应用保持统一。
- 书籍尚无阅读记录时，从第一章计算剩余章节。

## 7. 小说导入流程

### 7.1 入口

- 空书库时显示拖放区域和“导入小说”按钮。
- 有书籍时顶部显示“导入小说”按钮。
- 无论是否为空，都允许将单个 `.txt` 文件拖入书库内容区。
- `Ctrl+O` 打开文件选择器。

### 7.2 直接导入

选择文件或拖入文件后，不再进入导入预览流程。导入按以下顺序执行：

1. 校验文件类型、大小和可读性。
2. 异步检测文本编码。
3. 编码高置信度时直接解析章节并写入正式数据。
4. 编码低置信度或自动检测失败时，打开最小编码选择对话框。
5. 导入成功后刷新书架并显示 Snackbar。
6. 导入失败时不污染正式书库，并给出可执行错误说明。

直接导入要求：

- 不显示正文预览。
- 不要求用户确认章节预览。
- 不再提供“重新预览”。
- 导入成功前不得在书库中显示半成品书籍。
- 导入任务必须可取消；页面关闭、重新选择文件或应用退出时取消未完成任务并忽略迟到结果。

### 7.3 最小编码选择对话框

只有编码低置信度或自动检测失败时，才打开最小对话框。对话框只包含：

- 文件名。
- 当前检测结论或失败原因。
- 编码选择。
- 取消。
- 继续导入。

行为：

- 用户选择编码并继续后，仍然直接导入，不显示正文预览。
- 取消时不写入任何正式数据。
- 继续导入失败时保留对话框和用户选择，显示简短错误原因。

### 7.4 导入进度

- 小文件导入使用轻量页内进度或 Snackbar 进行状态提示。
- 大文件、章节解析耗时较长或文件复制耗时明显时，显示可取消进度对话框。
- 进度文案只展示阶段和必要百分比，例如“正在解析章节”“正在写入书库”。
- 不显示技术堆栈、临时路径或调试字段。

### 7.5 重复书籍处理

重复书籍第一版直接拒绝导入，并提示：

> 该小说已经导入

判重策略由应用服务统一实现，UI 不在前端自行猜测。拒绝重复导入时不得修改原有书籍、章节、阅读进度或缓存。

### 7.6 导入错误

错误文案面向用户，不显示异常堆栈。例如：

- 文件无法读取。
- 该小说已经导入。
- 无法识别编码，请手动选择。
- 章节解析失败，请检查文件内容。
- 导入已取消。
- 存储空间不足。

诊断细节写入日志，可提供“复制错误摘要”但不默认展开。

## 8. 书籍详情页

### 8.1 页面职责

书籍详情页负责当前书籍的元信息、进度摘要、章节目录和上下文操作。页面整体不使用全局纵向滚动；所有主要元素必须在支持的最小窗口范围内保持可见，列表区域使用内部滚动。

### 8.2 页面布局

书籍详情页采用左右分栏，参考 TTS 规则页和章节规则页的工作台布局。

```text
< 返回  书籍详情                                  [删除] [清理缓存] [取消] [保存]

┌──────────────────────────────┬──────────────────────────────────────────────┐
│ 书籍信息                     │ 章节目录                                     │
│                              │                                              │
│ [自动封面]                   │ 共 x 章 · 当前第 n 章                        │
│ 书名             [输入框]    │ [虚拟化章节列表]                             │
│ 作者             [输入框]    │   章节标题                                   │
│ 章节总数         只读值      │   当前章节高亮                               │
│ 当前章节         只读值      │                                              │
│ 阅读进度         进度条/文本 │                                              │
│ 缓存占用         只读值      │                                              │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

布局要求：

- 顶部工具条固定可见，包含返回、标题、删除、清理缓存、取消和保存。
- 左侧为书籍信息区，右侧为章节目录区。
- 左侧宽度建议固定在 320～420 px，右侧占据剩余空间。
- 右侧章节目录使用虚拟化列表，支持数千章节，不得被外层 `ScrollViewer` 破坏虚拟化。
- 页面不显示源文件名和文本编码。
- 页面不提供章节搜索。
- 窄窗口下仍保持左右分栏，不切换为全局长滚动页。

### 8.3 页面内容

左侧显示：

- 自动生成封面。
- 可编辑：书名、作者。
- 只读：
  - 章节总数。
  - 当前章节。
  - 总体阅读进度。
  - 本书缓存占用。

右侧显示：

- 章节目录虚拟列表。
- 当前章节高亮。
- 章节标题过长时省略并提供 Tooltip。

第一版不提供：

- 重新选择章节规则并重新解析。
- 重新导入源文件。
- 重置阅读进度。
- 自定义封面。

### 8.4 章节跳转

- 点击章节后进入播放页并定位到该章第一段。
- 如果当前书正在播放，跳转后继续播放。
- 如果当前书处于暂停状态，跳转后保持暂停。
- 如果跳转到非当前书或需要重建会话，必须先保存当前进度、停止旧音频和旧预取，再打开目标章节。
- 跳转完成后播放页正文预览按自动居中规则平滑定位到当前段。

### 8.5 元信息保存

- 使用明确的“保存”和“取消”。
- 书名不能为空，去除首尾空白后校验。
- 作者允许为空。
- 保存成功后刷新书库、播放页标题和正在播放入口。
- 有未保存修改时返回、删除、跳转章节或离开页面，显示三选项对话框：
  - 保存并继续。
  - 放弃修改。
  - 取消操作。
- 保存失败时保留编辑副本，并阻止继续原操作。

### 8.6 清理缓存

- 显示本书当前缓存占用。
- 清理前确认。
- 不清除阅读进度、书籍元数据或内部 TXT。
- 当前正在播放、生成或写入的缓存文件必须受到保护；必要时停止当前段并重新生成，而不是删除正在使用的文件。

### 8.7 删除书籍

确认对话框说明：

- 删除数据库中的书籍、章节和阅读进度。
- 删除应用数据目录中的内部 TXT 副本。
- 永远不修改或删除用户最初选择的外部 TXT 文件。
- 提供“同时删除音频缓存”复选框，默认勾选。

若该书正在播放：

1. 明确提示删除后将停止播放。
2. 确认后停止音频和旧预取任务。
3. 保存或结束当前会话。
4. 返回书库。
5. 执行删除并刷新书架。

操作失败时不得留下“书架已移除但数据未完全删除”的假成功状态。

## 9. 播放页

### 9.1 页面入口与书籍切换

- 播放页不提供选择书籍的下拉框或书籍列表。
- 仅由书库书籍卡片或正在播放入口进入。
- 打开书籍时恢复上次位置并保持暂停。
- 若另一书籍正在播放，打开新书时：
  1. 停止旧书音频和预取。
  2. 保存旧书进度。
  3. 创建新书会话。
  4. 恢复新书位置并保持暂停。

### 9.2 页面布局

```text
[返回] 书名                       [切换规则] [语速 10]

┌───────────────┬────────────────────────────────┐
│ 目录          │ 章节标题 / 歌词式正文预览      │
│ 虚拟列表       │                                │
│ 当前章高亮     │ 上文淡化                       │
│               │ 当前段高亮、居中                │
│               │ 下文淡化                       │
└───────────────┴────────────────────────────────┘

              [上一章] [上一段] [播放/暂停] [下一段] [下一章]
```

- 播放页在应用支持的窗口宽度范围内固定分为四个区域：顶部工具条、左侧目录区、右侧正文区、底部播放条。
- 顶部工具条和底部播放条始终固定可见；中间左右两区占据可视窗口剩余高度。
- 页面本身不依赖全局纵向滚动条完成主要交互；目录区与正文区分别使用各自的内部滚动。
- 第一版不再为播放页单独实现目录抽屉；在最小支持宽度下仍保持目录和正文双栏同时可见。

### 9.3 顶部区域

左侧：

- 无边框返回图标按钮。
- 书名。

右侧：

- 切换规则使用无边框图标按钮。
- 语速使用图标 + 当前原始整数值的有边框胶囊按钮，例如 `10`；胶囊使用明显大于普通按钮的圆角，保证两端接近半圆，不与普通矩形工具按钮混淆。
- 正文预览标题区显示当前章节标题，并在右侧内联展示“正在准备 / 正在加载 / 正在恢复”等加载类状态。

不提供：

- 正文字号调整。
- 当前规则名称常驻文本。
- 停止按钮。
- 常驻“重试当前段”和“跳过当前段”。
- 独立占位的播放状态卡片。

打开规则菜单时，菜单外层保留 Fluent Popup surface，内部规则项使用无边框整行按钮；当前规则使用勾选标记，菜单中可进入 TTS 规则管理页。

### 9.4 章节目录

- 使用虚拟化列表，支持数千章节。
- 目录项主体使用无边框整行按钮，显示章节标题和当前章节状态；当前项通过整行选中背景或指示条表达。
- 当前章节高亮并自动滚动到可见范围。
- 第一版不提供章节搜索。
- 点击章节后定位到该章第一段。
- 播放中点击：切换后继续播放。
- 暂停中点击：切换后保持暂停。
- 切换章节必须取消旧会话和旧预取，迟到结果不得更新当前页面。

### 9.5 歌词式正文预览

- 当前段使用最高对比度、稍大字重和充足行距。
- 当前段前后若干段逐级降低不透明度。
- 超出核心范围的段落可进一步淡化，但必须保持可读。
- 当前段正常情况下尽量位于视图垂直中心。
- 标题区显示当前章节标题，右侧紧凑展示段落进度和加载类状态，不再占用独立卡片高度。
- 正文段落项使用无边框整行交互，不为每段绘制按钮轮廓；点击正文段落可跳转到该段：
  - 播放中继续播放。
  - 暂停中保持暂停。
- 正文采用虚拟化或增量容器，不能为超长章节一次创建过多复杂控件。

### 9.6 手动滚动、自动居中与滚动动画

必须实现为明确状态机，不能使用固定周期定时器持续争夺滚动位置。

正文预览滚动状态固定为三态：

- `AutoCentering`
- `ManualBrowsing`
- `ScrollbarDragging`

状态规则：

1. 默认进入 `AutoCentering`。
2. 用户的鼠标滚轮、键盘滚动、触控或触摸板滚动进入 `ManualBrowsing`。
3. 拖动滚动条进入 `ScrollbarDragging`；拖拽结束后转回 `ManualBrowsing` 并开始恢复计时。
4. 每次新的滚动输入都取消旧恢复计时并重新开始 `4 秒` 静默计时。
5. 只有连续 4 秒没有任何滚动输入，且当前不处于 `ScrollbarDragging` 时，才允许恢复 `AutoCentering`。
6. 使用递增版本号或可取消 `CancellationTokenSource` 隔离旧计时任务，旧任务不得在新滚动后触发居中。
7. 自动滚动自身产生的 `ScrollChanged` 不应被误判为用户输入并无限重置计时。
8. `ManualBrowsing` 和 `ScrollbarDragging` 期间显示“回到当前段”悬浮按钮；该按钮使用圆形有边框图标样式，可带轻量阴影，不能改成无边框按钮。
9. 点击“回到当前段”立即恢复 `AutoCentering` 并定位当前段。
10. 播放自动切段或自动跨章时：
    - 当前处于 `AutoCentering` 时，继续让新当前段居中。
    - 当前处于 `ManualBrowsing` 或 `ScrollbarDragging` 时，不强制抢回滚动位置。
11. 用户主动跳转时立即恢复 `AutoCentering`，包括：
    - 上一段、下一段。
    - 上一章、下一章。
    - 点击正文段落。
    - 点击目录章节。
    - 从书籍详情页点击章节进入播放页。
    - 拖动章节段落进度条并提交。
    - 点击当前段、当前章节或当前进度位等“同目标”操作。
12. 页面离开时取消全部滚动恢复任务并重置为 `AutoCentering`。

滚动动画要求：

- 自动切段、自动跨章、点击上一段 / 下一段、点击上一章 / 下一章、点击正文段落、点击目录章节、从详情页跳转章节、拖动进度条提交后进行居中时，默认使用平滑滚动动画。
- 动画目标是让当前段尽量位于正文区域垂直中心。
- 建议动画时长约 `180–250 ms`，使用缓出曲线，不做弹性或过度装饰动画。
- 动画期间不得阻塞播放控制、规则切换或页面返回。
- 新的跳转或滚动请求到来时取消旧动画，直接以最新目标为准。
- 用户手动滚动、拖动滚动条或系统恢复 `ManualBrowsing` 时，不启动居中动画。
- 系统开启“减少动画”时禁用平滑动画，改为直接定位。
- 距离极大或虚拟化容器尚未生成目标项时，允许先跳到近似位置，再在容器生成后执行一次短动画或直接定位，不能出现长时间空白。

### 9.7 播放控制

五个按钮顺序固定：

1. 上一章。
2. 上一段。
3. 播放/暂停。
4. 下一段。
5. 下一章。

要求：

- 上一章、上一段、下一段、下一章使用无边框纯图标按钮，默认不绘制常驻边框或背景。
- 播放/暂停为视觉主操作，使用强调色实体圆形按钮，并通过尺寸和 surface 层级明显区别于其余四个无边框按钮。
- 不可用动作必须禁用，例如第一章的上一章；禁用态仍需可辨识，但不得只依赖降低透明度到不可见。
- 操作执行中避免重复提交同类命令。
- 按钮提供 Tooltip、键盘焦点和 Automation Name。

### 9.8 章节段落进度

进度条表示：

> 当前段落索引在当前章节总段落数中的位置。

要求：

- 显示 `X / Y`。
- 显示位置位于正文预览标题区，不在底部播放控制区重复展示。
- 不以当前音频播放毫秒作为主进度。
- 允许点击或拖动。
- 拖动时显示目标段落。
- 仅在松开后执行一次跳转，不在拖动过程中反复请求 TTS。
- 吸附到段落边界。
- 播放中跳转后继续播放；暂停中跳转后保持暂停。

### 9.9 规则与语速切换

语速：

- UI 显示后端使用的原始整数，不伪装为倍速。
- 点击语速胶囊按钮后打开滑块或步进输入面板；范围必须由领域设置统一定义并验证。
- 加减按钮即时更新面板中的目标值，并在连续调整停止后防抖提交一次，避免每次点击都重新请求音频。
- 提交时写入全局默认语速；播放页和播放设置页不维护会话专属语速。
- 修改后立即对当前段生效：停止当前音频、创建新会话、重新生成并从当前段开头播放。
- 若修改前为暂停，重新准备后仍保持暂停。

规则：

- 当前规则名称不常驻显示。
- 切换菜单中使用勾选标记。
- 切换规则后采用与语速相同的立即生效策略。

### 9.10 无可用规则

仍允许进入播放页并查看目录和正文。控制区显示空状态：

> 尚无可用的朗读规则

提供“前往 TTS 规则”按钮。返回播放页后保留书籍、章节和段落位置，不自动播放。

### 9.11 播放错误

正常状态下不显示重试或跳过按钮。

后端自动重试仍失败时：

- 暂停播放。
- 在正文上方显示紧凑错误条。
- 提供：
  - 再次尝试。
  - 切换规则。
- 不提供“跳过当前段”。
- 导航栏正在播放入口同步显示错误状态。

不同错误的用户文案：

- 网络错误：检查连接后重试。
- 401/403：登录信息、Token 或签名可能无效。
- 429：请求过于频繁，显示等待状态，不误判为永久失败。
- 响应类型错误：服务未返回可播放音频，可进入规则编辑。
- 连续失败：说明已暂停以避免无限请求。

技术细节默认折叠，日志中必须脱敏。

## 10. 设置页总览

设置页采用“一级入口 + 二级页面”的结构。

设置首页只提供入口，不直接放置开关、输入框、保存按钮或危险操作。首页使用分组列表，不使用卡片，不显示一行摘要或当前值。

```text
设置

常用
  播放设置                                      >
  TTS 规则                                     >

文本处理
  导入与文本                                    >
  章节规则                                     >

应用
  缓存与数据                                    >
  外观                                         >
  诊断与关于                                    >
```

七个设置二级页为：

1. 播放设置。
2. TTS 规则。
3. 导入与文本。
4. 章节规则。
5. 缓存与数据。
6. 外观。
7. 诊断与关于。

二级页面内部不再使用额外设置分组标题，使用扁平设置项列表、工具栏、列表区和必要说明组织内容。

详细布局、设置项、保存策略和后续扩展统一见 `07_SETTINGS_PAGES.md`。

## 11. TTS 规则管理摘要

TTS 规则是设置页下的二级页面，也是当前 TTS 规则的正式管理入口。

页面要求：

- 顶部提供返回、标题、新建规则、文件导入、剪贴板导入和帮助入口；前三项使用带 Tooltip 和无障碍名称的纯图标按钮。
- 页面采用左右分栏：左侧为规则列表，右侧为规则编辑区域。
- 左侧规则列表和右侧编辑区域分别使用内部滚动条，参考播放页的目录与正文区域。
- 当前规则只在左侧列表项中明确标记，不在顶部单独显示当前规则状态区。
- 规则列表使用卡片或设置式列表，不使用 `DataGrid`；列表项主体使用无边框整行按钮，由悬停背景、选中背景和当前规则标记表达状态。
- 列表项显示规则名称、启用状态和当前使用标记；不显示兼容性状态和不支持字段摘要。
- 点击左侧列表项切换右侧编辑副本。
- 新建规则在右侧打开空白编辑副本，不使用弹窗或三级页。
- 规则编辑在右侧区域完成，不使用悬浮编辑弹窗。
- 右侧编辑区域只保留结构化表单字段，不提供折叠原始 JSON 编辑区。
- 右侧编辑区域提供设为当前、试听、导出、删除、取消和保存操作。
- 右侧表单字段保留名称、启用、请求 URL/模板、请求方法、Content-Type、Header、并发限制和请求体；请求体仅在 POST 时显示。
- 试听按钮放在右侧编辑区域，不打开试听弹窗；第一版不要求用户额外输入试听文本或语速。
- 文件导入和剪贴板导入直接导入，不提供导入预览。
- 导入时丢弃多余字段；缺少必需字段、类型错误或请求模板无法解析时不允许导入。
- 同名但内容不同的规则允许导入，并自动追加“(2)”、“(3)”等后缀改名。
- 设为当前规则在本页即时保存。
- 播放页仍允许快速切换规则；播放页切换规则复用同一持久化当前规则。
- 页面不常驻显示状态文案；成功/失败反馈优先通过 Snackbar 或通知显示。
- 返回、帮助和帮助浮层关闭操作均使用无边框图标按钮；帮助浮层关闭后不得丢失编辑副本。
- 规则编写帮助通过页内右侧覆盖浮层打开，说明常见字段、模板、Header、试听、导入限制和常见错误。

当前规则保护：

- 当前规则不能在无处理的情况下直接禁用或删除。
- 禁用或删除当前规则时，统一使用一次危险确认；确认后直接清空当前规则，使应用进入无可用规则状态。
- 播放中切换规则时，当前段从头重新生成并继续播放；暂停时保持暂停。

未保存修改保护：

- 切换规则、返回、新建、导入、删除或关闭页面前，如果右侧编辑副本存在未保存修改，必须提供保存、放弃、取消三选项。
- 保存失败时保留编辑内容，并阻止继续切换。

## 12. 章节规则管理摘要

章节规则是设置页下的二级页面，只负责章节识别，不负责通用文本处理或正则替换。

页面要求：

- 页面采用与 TTS 规则页一致的左右分栏工作台：左侧为章节规则列表，右侧为章节规则编辑区域。
- 左侧规则列表和右侧编辑区域分别使用内部滚动条，参考播放页目录与正文区域。
- 不使用 `DataGrid`，不使用独立编辑页，不使用悬浮编辑弹窗。
- 左侧列表项主体使用覆盖整张卡片的无边框整行按钮，显示规则名称、正则表达式摘要、启用开关和排序操作；不显示“内置 / 自定义”。快捷操作保持独立控件，不改变卡片主体选择行为。
- 启用开关只放在左侧列表并即时保存；右侧编辑区域不再显示启用字段。
- 排序支持拖拽，同时提供上移 / 下移键盘等价操作；拖动手柄、上移和下移全部使用无边框纯图标按钮；排序即时保存，失败时回滚 UI 顺序或重新加载。
- 点击左侧列表项切换右侧编辑副本。
- 新建规则在右侧打开空白编辑副本，保存前不进入左侧列表。
- 右侧编辑区域只包含名称、正则表达式、正则校验提示、删除、取消和保存。
- 正则表达式输入框提供即时校验；第一版不提供完整小说章节测试调试器，也不提供单行标题测试区。
- 用户自建规则可以删除，内置规则不可删除、只能禁用；左侧不显示类型，右侧删除按钮按规则能力禁用或隐藏。
- 顶部提供新建规则、导入默认规则、恢复默认规则和帮助入口。
- 返回、帮助和帮助浮层关闭操作均使用无边框图标按钮。
- 帮助入口使用页内右侧覆盖浮层，说明正则写法、章节标题示例、排序优先级、内置规则限制和误识别处理。

启用、排序与编辑解耦：

- 左侧启用 / 禁用直接更新持久化对象的启用字段，并即时保存。
- 左侧排序直接更新持久化顺序，并即时保存。
- 当前正在右侧编辑的规则也允许在左侧启用 / 禁用和排序。
- 右侧名称和正则表达式使用编辑副本，点击保存后才持久化。
- 右侧保存时必须基于最新持久化对象做字段级更新，只写入名称和正则表达式，不覆盖左侧已保存的启用状态和排序。
- 左侧即时保存失败时回滚对应 UI 状态，不影响右侧正在编辑的名称和正则表达式副本。

默认规则操作：

- “导入默认规则”补充缺失的内置规则，按稳定标识更新已有内置规则，保留用户自建规则；直接执行并显示结果摘要。
- “恢复默认规则”重置所有内置规则，但不删除用户自建规则，必须二次确认。

未保存修改保护：

- 切换左侧规则、返回、新建、导入默认、恢复默认、删除或关闭页面前，如果右侧编辑副本存在未保存修改，必须提供保存、放弃、取消三选项。
- 左侧启用 / 禁用和排序属于独立即时操作，不因右侧存在未保存名称或正则表达式修改而被阻止。
- 保存失败时保留编辑内容，并阻止继续切换。

## 13. 缓存与数据摘要

缓存与数据是设置页下的二级页面，负责全局缓存总览、缓存上限设置、应用数据目录入口和进入缓存管理三级页。单书详情页仍保留当前书缓存管理，作为上下文快捷入口。

缓存与数据二级页要求：

- 显示当前缓存总占用、缓存上限、使用率进度和 LRU 说明。
- 缓存上限第一版可编辑，默认 `2 GB`，最小 `256 MB`。
- 新上限低于当前占用时，二次确认后立即按 LRU 清理旧缓存。
- 提供“进入缓存管理”入口，进入三级缓存管理页。
- 提供“打开应用数据目录”。
- 二级页不直接显示按书籍缓存列表。
- 二级页不提供“清理全部缓存”；清理全部缓存只放在三级缓存管理页。

缓存管理三级页要求：

- 三级页采用与 TTS 规则页一致的左右分栏工作台：左侧选择书籍，右侧管理该书章节缓存。
- 左侧书籍列表显示书名、作者、缓存占用、已缓存章节数；不提供搜索或筛选。
- 如果缓存摘要只有 `BookId`、章节数、条目数和大小，应用服务必须联合书籍元数据补齐书名和作者。
- 右侧章节列表显示章节序号、章节标题、缓存占用、缓存条目数和章节缓存完整度。
- 如果章节缓存摘要只有章节索引、条目数和大小，应用服务必须联合章节元数据补齐章节标题。
- 章节缓存完整度定义为“已缓存语音段数 / 当前章节可播放语音段总数”，例如 `12/45 段（27%）`；无法计算总段数时只显示已缓存段数。
- 未选择书籍时显示“请选择左侧书籍”；选择后无缓存时显示“该书暂无缓存”。
- 右侧顶部提供“清理本书全部缓存”，每个章节项提供“清理本章缓存”；章节项操作使用带 Tooltip 和无障碍名称的删除图标按钮。
- 三级页顶部提供“清理全部缓存”危险操作。
- 缓存清理不删除书籍、阅读进度、章节规则或 TTS 规则。
- 当前播放、正在生成和正在写入的缓存受保护。
- 清理完成后刷新二级页总览、左侧书籍列表和右侧章节列表；部分失败时显示失败摘要。

## 14. 状态反馈与对话框

### 14.1 反馈层级

1. **静默成功**：自动保存等频繁操作。
2. **Snackbar**：导入成功、缓存清理完成、规则导入完成。
3. **页内状态**：空状态、加载状态、播放错误、无规则状态。
4. **ContentDialog**：删除、清除凭据、未保存修改等阻断性决策。

所有 `Snackbar` 和 `ContentDialog` 都应悬浮在主窗口内容之上，不参与页面内部布局，不随页面滚动。

### 14.2 加载与空状态

所有列表页必须定义：

- 首次加载。
- 空列表。
- 加载失败。
- 正常内容。

不得使用“这里未来会显示……”之类开发占位文本。

### 14.3 异步操作

- 长操作允许取消。
- 关闭页面或对话框时取消相关任务。
- 使用操作版本号、会话 ID 或 CancellationToken 忽略迟到结果。
- 主线程只更新 UI，不执行文件解析、数据库批量操作或网络等待。

## 15. 响应式布局

### 15.1 通用

- 默认宽屏优先。
- 小于约 `1080 px` 时导航栏自动折叠。
- 页面卡片网格根据可用宽度改变列数。
- 文本使用省略和 Tooltip，不能挤压主操作消失。

书架断点：`900–1199 px` 使用一列横向书籍卡片，`1200–1599 px` 使用两列，`1600 px` 及以上使用三列。播放、详情和规则/缓存工作台在最小窗口仍保持双栏，左右区域各自滚动。

### 15.2 播放页

- 常规宽度和最小支持宽度均保持左侧目录 + 右侧正文双栏。
- 顶部工具条和底部播放条固定可见。
- 目录区和正文区分别使用内部滚动。
- 正文和五个播放按钮始终保持可用。
- 第一版不实现目录抽屉；低于最小宽度由窗口约束阻止继续缩小。

## 16. 键盘与可访问性

### 16.1 快捷键

- `Ctrl+O`：导入小说。
- `Space`：播放/暂停；文本框正在编辑时不触发。
- `Alt+Left`：返回上一级或书库。
- `Ctrl+Left / Ctrl+Right`：上一段 / 下一段。
- `Ctrl+Shift+Left / Ctrl+Shift+Right`：上一章 / 下一章。
- `Ctrl+,`：打开设置。
- `Esc`：关闭对话框、菜单或返回上一级。

快捷键仲裁规则：

- 所有快捷键由主窗口统一处理，不允许页面各自注册重复的全局按键。
- 焦点在文本、密码或富文本输入框，或可编辑组合框、组合框下拉、菜单、Popup、对话框打开时，不触发应用级快捷键；`Esc` 优先由当前临时界面关闭。
- `Space`、段落和章节快捷键仅在播放页有效，避免在书库和设置页意外控制后台会话。
- `Ctrl+O` 在任意页面选择 TXT 后切换到书库并开始既有直接导入流程；取消选择不改变当前页面。

### 16.2 可访问性要求

- 所有关键控件可通过键盘到达。
- 焦点顺序符合视觉顺序。
- 仅图标控件提供可读名称。
- 无边框图标按钮和无边框整行按钮仍必须具备可见的悬停、按下、键盘焦点和禁用状态。
- 播放状态、当前章节和错误状态可被屏幕阅读器读取。
- 深浅主题下保持足够对比度。
- 动画不影响操作；系统减少动画时应降低或关闭非必要过渡。

## 17. App 代码组织和边界

App 按功能切片组织页面、ViewModel、组件、页面控制器和功能注册，不再把所有 Page、View 和 ViewModel 分散到三个全局目录：

```text
NovelSpeaker.App/
├─ Bootstrap/
├─ Shell/
│  ├─ Navigation/
│  ├─ Activation/
│  └─ Input/
├─ Features/
│  ├─ Library/
│  ├─ BookDetails/
│  ├─ Playback/
│  │  ├─ Components/
│  │  ├─ Presentation/
│  │  └─ Scrolling/
│  ├─ TtsRules/
│  ├─ ChapterRules/
│  ├─ RegexReplacementRules/
│  ├─ Cache/
│  ├─ PlaybackSettings/
│  ├─ ImportTextSettings/
│  ├─ Appearance/
│  ├─ Diagnostics/
│  └─ RuleEditing/
└─ Shared/
   ├─ Feedback/
   ├─ Theming/
   ├─ Dialogs/
   └─ Presentation/
      ├─ Books/
      └─ Platform/
```

准入规则：

- Feature 目录包含该功能的 Page、ViewModel、可复用组件、presentation-only service 和 DI 注册模块。
- `Shared` 类型必须有两个以上稳定消费者；单功能 helper 留在功能内部。
- Page 是导航、页面激活、取消和未保存保护边界。
- UserControl 只用于复用组件或拥有独立视觉行为/测试价值的复杂区域；不保留仅把整页包进同名 UserControl 的一对一 wrapper。
- 页面离开时取消 activation 内的加载、导入、试听、自动保存和动画任务；跨页面播放会话不随 Page 取消。

### 17.1 导航

- App 定义自己的强类型 route 和参数，ViewModel 不引用具体 Page 类型。
- Wpf.Ui 的 Page 映射、选中项和兼容处理集中在 Shell 导航适配器。
- 所有离开路径统一经过导航守卫：页面返回、一级导航、快捷键、正在播放入口、功能跳转和窗口关闭。
- TTS、章节、正则和书籍详情的编辑副本使用同一离开协议；不能只在 BackCommand 内检查未保存状态。

### 17.2 ViewModel

ViewModel 可以：

- 暴露语义状态、编辑副本和命令。
- 调用 Application 用例并投影结果。
- 进行页面级轻量校验。

ViewModel 不可以：

- 直接操作 Window、Dispatcher、文件系统、SQLite、NAudio、Jint 或 HttpClient。
- 引用具体 Page，或公开 `FontWeight`、Brush、Wpf.Ui 图标等视觉类型。
- 自己维护核心播放状态机、分段正文或缓存策略。
- 依赖 Singleton 生命周期偶然保存页面状态。

播放页 ViewModel 是页面门面；正文/章节投影、Snapshot 投影、规则/语速设置控制等职责使用功能内部协作者拆分，滚动输入和视觉定位仍属于 View/Scrolling 协调器。

### 17.3 Code-behind 和平台适配

- code-behind 只处理 WPF 生命周期、焦点、拖放、虚拟化、滚动、动画和事件桥接。
- 文件打开/保存、剪贴板、目录打开、对话框和 Snackbar 使用统一 presentation port，不在各页面直接调用不同平台 API。
- 事件桥接传递页面/操作 Token；迟到结果按 activation/operation version 隔离。
- 图标、字重、颜色和可见性由 XAML 资源、触发器或转换器根据语义状态映射。

## 18. UI 与 Application 合同

UI 只消费面向用例的 Application 合同：

- 书库摘要、书籍详情、章节摘要和元信息更新。
- 可恢复的导入、删除和缓存清理结果。
- 播放命令、不可变 Snapshot 和章节/段落只读投影。
- TTS、章节、正则规则的列表、编辑副本、校验和保护结果。
- 设置读取、规范化更新和变更通知。
- 缓存总览、书籍/章节统计和清理结果。

Application 合同不包含 SQLite connection、绝对存储路径、`HttpRequestMessage`、NAudio、WPF/Wpf.Ui 类型或用户视觉文案。Infrastructure 负责具体存储/设备适配，App 负责将安全结果映射为可访问的页面反馈。

## 19. 核心用户流程

### 19.1 首次使用

```text
启动 → 空书库 → 导入 TXT → 自动检测编码并直接导入 → 书架出现书籍
→ 点击书籍 → 若无规则则前往 TTS 规则 → 导入并试听
→ 返回播放页 → 点击播放
```

### 19.2 日常继续收听

```text
启动 → 书库最近阅读排序首位书籍 → 恢复位置但保持暂停 → 点击播放
```

### 19.3 返回书库后继续播放

```text
播放中 → 返回书库 → 音频继续
→ 导航栏底部出现正在播放入口 → 点击返回播放页
```

### 19.4 切换书籍

```text
旧书播放中 → 返回书库 → 点击新书
→ 保存并停止旧会话 → 打开新书上次位置且保持暂停
```

### 19.5 规则故障恢复

```text
自动重试失败 → 播放暂停 → 页内错误条
→ 再次尝试 或 切换规则 → 当前段从头恢复
```

## 20. 明确不做

第一轮 UI 改造不包含：

- 在线封面或元数据搜索。
- 自定义封面图片。
- 章节搜索。
- 导入预览和章节预览确认。
- 正文字号调整。
- 详情页重新解析、重新导入、重置进度。
- 独立的规则试听调试页面。
- 播放页切换书籍。
- 常驻停止、重试、跳过按钮。
- 全局底部播放器条。
- 关闭窗口行为 / 托盘行为 UI；本轮仅在外观页规划。
- 手机或触屏专用布局。

## 21. UI 改造完成标准

- 一级导航只剩书库和设置。
- 所有主要页面使用 Wpf.Ui Fluent 视觉和统一主题资源。
- 书库、TTS 规则、章节规则不再使用 `DataGrid`。
- 书架使用去外层大容器的响应式横向卡片网格，可搜索、排序、进入播放、进入详情和删除。
- 播放页具有虚拟目录、歌词式正文、五键控制和章节段落进度条。
- 手动滚动后只有连续 4 秒无输入才恢复自动居中，且无竞态抢滚动；自动切段和用户主动跳转居中时有平滑滚动动画。
- 返回书库后播放继续，正在播放入口可返回。
- 设置首页使用分组列表，仅提供七个二级页入口；所有设置项进入二级页。
- TTS 规则支持左侧规则列表、右侧编辑区域、新建、直接导入、帮助入口和右侧一键试听。
- 章节规则支持左侧规则列表、右侧编辑区域、左侧启用和排序、字段级保存、默认规则操作以及页内帮助浮层。
- 缓存与数据二级页提供总览和缓存管理入口；缓存管理三级页支持左侧选择书籍、右侧管理章节缓存。
- 浅色、深色、跟随系统和 Windows 10 降级均可用。
- 小说导入不再需要预览确认；常见编码文件可直接导入，低置信度编码才要求用户选择。
- 书籍详情页全局不滚动，章节目录虚拟化，并支持点击章节进入播放页。
- 关键路径可以仅用键盘完成。
- 不再出现开发占位提示、技术错误堆栈或无用元信息。
