# UI 与用户流程

## 1. 文档定位

本文件是 NovelSpeaker 当前 UI/UX 设计基线的总览。实现、评审和验收均以本文以及设置页专项文档 `06A_SETTINGS_PAGES.md` 为准。

涉及以下内容时，应更新本文或对应专项文档，不再建立并行方案：

- 主窗口壳层、导航和页面层级。
- 书库、播放、设置及各二级管理页面。
- 播放状态、跳转、自动滚动和错误恢复。
- 书籍、TTS 规则、章节规则和缓存的管理交互。
- 主题、响应式布局、键盘操作和可访问性。

设置首页、七个设置二级页、保存策略和后续设置扩展统一维护在 `06A_SETTINGS_PAGES.md`。`11_TASK_BACKLOG.md` 负责将设计拆成可分配给 Codex 的开发任务；若两者冲突，以设计文档为产品行为准。

---

## 2. 已确定的产品方向

- 技术栈保持 `.NET 10 + WPF + CommunityToolkit.Mvvm`。
- UI 采用 `Wpf.Ui 4.x` 的 Fluent 风格组件和主题能力。
- 支持 Windows 10 和 Windows 11；Windows 11 可使用 Mica 等效果，Windows 10 自动降级。
- 主窗口一级入口仅保留“书库”和“设置”。
- 播放页、书籍详情和设置二级页均为上下文页或二级页。
- 删除底部全局播放条，不再在所有页面常驻完整播放控制。
- 不使用 `DataGrid` 作为书库、TTS 规则或章节规则的主要交互形式。
- 优先使用图标、卡片、菜单和清晰的状态反馈，去除开发阶段残留说明文本。
- 应用启动进入书库，不自动播放声音。
- 从书库打开书籍时恢复上次位置，但保持暂停。

---

## 3. 设计原则

1. **听书优先**：正文用于定位和辅助阅读，不扩展为完整电子书阅读器。
2. **低打扰**：成功操作尽量静默或使用 Snackbar；仅危险操作和未保存修改使用对话框。
3. **上下文明确**：用户始终能确认当前书籍、章节、段落和播放状态。
4. **主操作集中**：播放页承载全部播放控制，书库页不复制完整播放器。
5. **复杂管理页工作台化**：TTS 规则、章节规则和缓存管理等复杂页面优先使用左侧选择、右侧编辑/管理的分栏工作台。
6. **状态不只靠颜色**：选中、播放、错误、禁用等状态同时使用图标、文字或控件状态表达。
7. **不显示无价值信息**：不在书架展示最近导入时间；不常驻显示当前 TTS 规则名称。
8. **避免竞态**：页面跳转、播放会话、自动滚动、导入和规则试听必须可取消并隔离旧结果。

## 4. 信息架构

```text
MainWindow / AppShell
├─ LibraryPage                         一级入口
│  ├─ ImportBookDialog                 模态对话框
│  ├─ BookDetailsPage                  二级页
│  └─ PlayerPage                       上下文页
└─ SettingsPage                        一级入口，分组列表，仅提供入口
   ├─ PlaybackSettingsPage             二级页
   ├─ TtsRulesPage                     二级页，左侧规则列表 + 右侧规则编辑 + 页内帮助浮层
   ├─ ImportTextSettingsPage           二级页
   │  └─ RegexReplacementRulesPage     三级页，后续规划
   ├─ ChapterRulesPage                 二级页，左侧规则列表 + 右侧规则编辑 + 页内帮助浮层
   ├─ CacheAndDataPage                 二级页，总览 + 缓存管理入口
   │  └─ CacheManagementPage           三级页，左侧书籍列表 + 右侧章节缓存管理
   ├─ AppearanceSettingsPage           二级页
   └─ DiagnosticsAboutPage             二级页
```

### 4.1 一级导航

左侧 `NavigationView` 仅显示：

- 书库。
- 设置。

导航栏规则：

- 默认展开，约 `220 px`，显示图标和文字。
- 用户可以手动折叠为约 `64 px` 的纯图标状态。
- 窗口宽度不足约 `1080 px` 时自动折叠。
- 书库和设置之间切换不销毁正在播放的会话。

### 4.2 正在播放入口

导航栏底部显示紧凑的“正在播放”入口：

- 仅在已打开过一本书且存在播放会话上下文时显示。
- 显示耳机/播放状态图标、书名和简短状态。
- 暂停时仍保留。
- 播放错误时显示错误状态图标。
- 点击后返回对应书籍的播放页。
- 不提供播放、暂停、上一段等控制，避免重新形成全局播放条。

### 4.3 二级页导航

- 二级页左上角统一使用返回按钮。
- `Alt+Left` 和 `Esc` 在无对话框、无文本编辑冲突时执行返回。
- 返回应恢复上一页面的滚动位置和筛选状态。
- 播放页返回书库时音频继续播放；导航栏底部入口用于返回播放页。

## 5. 主窗口与视觉系统

### 5.1 主窗口

- 使用 `Wpf.Ui.Controls.FluentWindow`。
- 默认尺寸约 `1280 × 820`。
- 最小尺寸约 `900 × 640`。
- Windows 11 可启用 Mica；不支持时使用主题背景色，不因特效失败影响启动。
- 内容区使用统一页面边距、最大阅读宽度和滚动策略。

### 5.2 主题

设置支持：

- 跟随系统。
- 浅色。
- 深色。

要求：

- 默认跟随系统。
- 修改后立即生效并自动保存。
- 使用 Windows 系统强调色表达主按钮、选中状态和焦点。
- 颜色必须来自主题资源，页面 XAML 不再散落固定十六进制颜色。

### 5.3 图标和文本

- 使用 Wpf.Ui `SymbolIcon` 或统一图标资源。
- 常见动作可使用“图标 + Tooltip”，危险和不常见动作保留文字说明。
- 仅图标按钮必须提供 `ToolTip` 和 `AutomationProperties.Name`。
- 删除、保存、导入等关键操作不能只依赖难以理解的图标。

### 5.4 组件风格一致性

- 自定义按钮、图标按钮和悬浮按钮必须基于现有 Fluent 默认控件样式扩展，只允许调整尺寸、内边距和布局，不得另起一套脱离全局主题的颜色、边框或圆角。
- `Popup`、菜单和其它非模态临时面板必须复用与页面卡片或输入控件一致的背景、描边和圆角资源，不得出现默认系统灰底、黑边或与页面主体割裂的独立配色。
- 新增页面部件在浅色和深色主题下，都应与现有卡片、按钮、输入框保持同一套 surface 层级和控件语言；发现偏离时优先收敛到既有样式资源，而不是继续扩散新的局部风格。

### 5.5 自动封面

第一版不保存用户封面文件。封面由书籍信息稳定生成：

- 使用规范化书名计算稳定哈希。
- 哈希决定预设渐变组合、装饰图形和文字布局。
- 同一本书在重启和不同页面中保持同一视觉。
- 封面显示书名，必要时使用省略和分行。
- 深色主题下自动保证文字对比度。
- 不提供随机换色或手动编辑封面。

## 6. 书库页

### 6.1 页面职责

书库页负责：

- 导入 TXT。
- 搜索和排序书籍。
- 进入播放页。
- 进入书籍详情。
- 删除书籍。

书库页不负责：

- 切换 TTS 规则。
- 直接编辑元信息。
- 展示导入时间。
- 常驻显示导入调试信息或后端状态文本。

### 6.2 页面布局

```text
页面标题                         搜索框  排序菜单  [导入]

[响应式书架卡片网格]
```

空书库时改为：

```text
页面标题

[空状态插图/图标]
尚未导入小说
将 TXT 拖到这里，或选择文件
[导入小说]
```

### 6.3 搜索与排序

书库提供轻量搜索：

- 按书名和作者匹配。
- 输入后本地即时过滤，可使用短延迟避免频繁刷新。
- 清空按钮恢复完整书架。

排序选项：

- 最近阅读，默认。
- 书名。

排序规则：

- “最近阅读”优先排列有阅读记录的书籍。
- 从未播放的书籍排在其后。
- 不提供按最近导入排序。
- 第一版不提供手动拖动排序。

### 6.4 最近阅读入口

- 不再提供独立“继续收听”卡片。
- 书库默认使用“最近阅读”排序，使最近有阅读记录的书籍出现在书架前部。
- 用户从书籍卡片进入播放页时，仍恢复上次章节和段落，并保持暂停。

### 6.5 书籍卡片

每张卡片显示：

- 自动生成封面。
- 书名。
- 作者；作者为空时显示“未知作者”。
- 当前章节标题。
- `剩余 N 章`。
- 无数字比例的总体进度条。

交互：

- 左键点击卡片主体：进入该书播放页。
- 卡片右上角在悬停、键盘聚焦或触控场景下显示更多菜单；按钮位于卡片内部，不得漂浮在卡片外。
- 更多菜单包含：
  - 书籍详情。
  - 删除书籍。
- 清理单本书缓存放在书籍详情页，不重复放入一级菜单。

不显示：

- 最近导入时间。
- 最近播放时间。
- `第 X / Y 章` 文字。
- 直接编辑输入框。

### 6.6 剩余章节定义

`剩余章节数 = 总章节数 - 当前章节索引 - 1`。

- 当前章节是否朗读完成不影响该数字。
- 已到最后一章时显示“最后一章”或“剩余 0 章”，全应用保持统一。
- 书籍尚无阅读记录时，从第一章计算剩余章节。

## 7. 小说导入流程

### 7.1 入口

- 空书库时显示大型拖放区域。
- 有书籍时顶部显示“导入小说”按钮。
- 无论是否为空，都允许将单个 `.txt` 文件拖入书库内容区。
- `Ctrl+O` 打开文件选择器。

### 7.2 导入对话框

选择文件后打开 `ImportBookDialog`，不在书库页面长期展开导入面板。

对话框包含：

- 文件名和文件大小。
- 自动检测编码。
- 文本预览。
- 编码选择。
- “重新预览”。
- 导入阶段和进度。
- 取消。
- 确认导入。

行为：

1. 选择文件后异步分析。
2. 自动检测失败时允许切换编码并刷新预览。
3. 确认前不写入正式数据。
4. 导入期间显示可取消进度。
5. 导入成功后关闭对话框、刷新书架并显示 Snackbar。
6. 导入失败时保留对话框和已选编码，显示可执行的错误说明。
7. 关闭对话框必须取消未完成分析或导入，并忽略迟到结果。

### 7.3 导入错误

错误文案面向用户，不显示异常堆栈。例如：

- 文件无法读取。
- 该小说已经导入。
- 无法识别编码，请手动选择。
- 导入已取消。
- 存储空间不足。

诊断细节写入日志，可提供“复制错误摘要”但不默认展开。

## 8. 书籍详情页

### 8.1 页面内容

- 自动生成封面。
- 可编辑：书名、作者。
- 只读：
  - 源文件名。
  - 文本编码。
  - 章节总数。
  - 当前章节。
  - 总体阅读进度。
- 章节列表预览，仅用于检查解析结果。
- 清理本书缓存。
- 删除书籍。

第一版不提供：

- 重新选择章节规则并重新解析。
- 重新导入源文件。
- 重置阅读进度。
- 从详情页点击章节直接播放。
- 自定义封面。

### 8.2 元信息保存

- 使用明确的“保存”和“取消”。
- 书名不能为空，去除首尾空白后校验。
- 作者允许为空。
- 保存成功后刷新书库、播放页标题和正在播放入口。
- 有未保存修改时返回，显示三选项对话框：
  - 保存并返回。
  - 放弃修改。
  - 取消返回。

### 8.3 清理缓存

- 显示本书当前缓存占用。
- 清理前确认。
- 不清除阅读进度、书籍元数据或内部 TXT。
- 当前正在播放或写入的缓存文件必须受到保护；必要时停止当前段并重新生成，而不是删除正在使用的文件。

### 8.4 删除书籍

确认对话框说明：

- 删除数据库中的书籍、章节和阅读进度。
- 删除应用数据目录中的内部 TXT 副本。
- 永远不修改或删除用户最初选择的外部 TXT 文件。
- 提供“同时删除音频缓存”复选框，默认勾选。

若该书正在播放：

1. 明确提示删除后将停止播放。
2. 确认后停止音频和旧预取任务。
3. 保存或结束当前会话。
4. 返回书库。
5. 执行删除并刷新书架。

操作失败时不得留下“书架已移除但数据未完全删除”的假成功状态。

## 9. 播放页

### 9.1 页面入口与书籍切换

- 播放页不提供选择书籍的下拉框或书籍列表。
- 仅由书库书籍卡片或正在播放入口进入。
- 打开书籍时恢复上次位置并保持暂停。
- 若另一书籍正在播放，打开新书时：
  1. 停止旧书音频和预取。
  2. 保存旧书进度。
  3. 创建新书会话。
  4. 恢复新书位置并保持暂停。

### 9.2 页面布局

```text
[返回] 书名                       [切换规则] [语速 10]

┌───────────────┬────────────────────────────────┐
│ 目录          │ 章节标题 / 歌词式正文预览      │
│ 虚拟列表       │                                │
│ 当前章高亮     │ 上文淡化                       │
│               │ 当前段高亮、居中                │
│               │ 下文淡化                       │
└───────────────┴────────────────────────────────┘

              [上一章] [上一段] [播放/暂停] [下一段] [下一章]
```

- 播放页在应用支持的窗口宽度范围内固定分为四个区域：顶部工具条、左侧目录区、右侧正文区、底部播放条。
- 顶部工具条和底部播放条始终固定可见；中间左右两区占据可视窗口剩余高度。
- 页面本身不依赖全局纵向滚动条完成主要交互；目录区与正文区分别使用各自的内部滚动。
- 第一版不再为播放页单独实现目录抽屉；在最小支持宽度下仍保持目录和正文双栏同时可见。

### 9.3 顶部区域

左侧：

- 返回按钮。
- 书名。

右侧：

- 切换规则图标按钮。
- 语速图标按钮和当前原始整数值，例如 `10`。
- 正文预览标题区显示当前章节标题，并在右侧内联展示“正在准备 / 正在加载 / 正在恢复”等加载类状态。

不提供：

- 正文字号调整。
- 当前规则名称常驻文本。
- 停止按钮。
- 常驻“重试当前段”和“跳过当前段”。
- 独立占位的播放状态卡片。

打开规则菜单时，当前规则使用勾选标记；菜单中可进入 TTS 规则管理页。

### 9.4 章节目录

- 使用虚拟化列表，支持数千章节。
- 显示章节标题和当前章节状态。
- 当前章节高亮并自动滚动到可见范围。
- 第一版不提供章节搜索。
- 点击章节后定位到该章第一段。
- 播放中点击：切换后继续播放。
- 暂停中点击：切换后保持暂停。
- 切换章节必须取消旧会话和旧预取，迟到结果不得更新当前页面。

### 9.5 歌词式正文预览

- 当前段使用最高对比度、稍大字重和充足行距。
- 当前段前后若干段逐级降低不透明度。
- 超出核心范围的段落可进一步淡化，但必须保持可读。
- 当前段正常情况下尽量位于视图垂直中心。
- 标题区显示当前章节标题，右侧紧凑展示段落进度和加载类状态，不再占用独立卡片高度。
- 点击正文段落可跳转到该段：
  - 播放中继续播放。
  - 暂停中保持暂停。
- 正文采用虚拟化或增量容器，不能为超长章节一次创建过多复杂控件。

### 9.6 手动滚动与自动居中

必须实现为明确状态机，不能使用固定周期定时器持续争夺滚动位置。

正文预览滚动状态固定为三态：

- `AutoCentering`
- `ManualBrowsing`
- `ScrollbarDragging`

状态规则：

1. 默认进入 `AutoCentering`。
2. 用户的鼠标滚轮、键盘滚动、触控或触摸板滚动进入 `ManualBrowsing`。
3. 拖动滚动条进入 `ScrollbarDragging`；拖拽结束后转回 `ManualBrowsing` 并开始恢复计时。
4. 每次新的滚动输入都取消旧恢复计时并重新开始 `4 秒` 静默计时。
5. 只有连续 4 秒没有任何滚动输入，且当前不处于 `ScrollbarDragging` 时，才允许恢复 `AutoCentering`。
6. 使用递增版本号或可取消 `CancellationTokenSource` 隔离旧计时任务，旧任务不得在新滚动后触发居中。
7. 自动滚动自身产生的 `ScrollChanged` 不应被误判为用户输入并无限重置计时。
8. `ManualBrowsing` 和 `ScrollbarDragging` 期间显示“回到当前段”悬浮按钮。
9. 点击“回到当前段”立即恢复 `AutoCentering` 并定位当前段。
10. 播放自动切段或自动跨章时：
    - 当前处于 `AutoCentering` 时，继续让新当前段居中。
    - 当前处于 `ManualBrowsing` 或 `ScrollbarDragging` 时，不强制抢回滚动位置。
11. 用户主动跳转时立即恢复 `AutoCentering`，包括：
    - 上一段、下一段。
    - 上一章、下一章。
    - 点击正文段落。
    - 点击目录章节。
    - 拖动章节段落进度条并提交。
    - 点击当前段、当前章节或当前进度位等“同目标”操作。
12. 页面离开时取消全部滚动恢复任务并重置为 `AutoCentering`。

### 9.7 播放控制

五个按钮顺序固定：

1. 上一章。
2. 上一段。
3. 播放/暂停。
4. 下一段。
5. 下一章。

要求：

- 播放/暂停为视觉主操作。
- 不可用动作必须禁用，例如第一章的上一章。
- 操作执行中避免重复提交同类命令。
- 按钮提供 Tooltip、键盘焦点和 Automation Name。

### 9.8 章节段落进度

进度条表示：

> 当前段落索引在当前章节总段落数中的位置。

要求：

- 显示 `X / Y`。
- 显示位置位于正文预览标题区，不在底部播放控制区重复展示。
- 不以当前音频播放毫秒作为主进度。
- 允许点击或拖动。
- 拖动时显示目标段落。
- 仅在松开后执行一次跳转，不在拖动过程中反复请求 TTS。
- 吸附到段落边界。
- 播放中跳转后继续播放；暂停中跳转后保持暂停。

### 9.9 规则与语速切换

语速：

- UI 显示后端使用的原始整数，不伪装为倍速。
- 使用滑块或步进输入，范围必须由领域设置统一定义并验证。
- 修改后立即对当前段生效：停止当前音频、创建新会话、重新生成并从当前段开头播放。
- 若修改前为暂停，重新准备后仍保持暂停。

规则：

- 当前规则名称不常驻显示。
- 切换菜单中使用勾选标记。
- 切换规则后采用与语速相同的立即生效策略。

### 9.10 无可用规则

仍允许进入播放页并查看目录和正文。控制区显示空状态：

> 尚无可用的朗读规则

提供“前往 TTS 规则”按钮。返回播放页后保留书籍、章节和段落位置，不自动播放。

### 9.11 播放错误

正常状态下不显示重试或跳过按钮。

后端自动重试仍失败时：

- 暂停播放。
- 在正文上方显示紧凑错误条。
- 提供：
  - 再次尝试。
  - 切换规则。
- 不提供“跳过当前段”。
- 导航栏正在播放入口同步显示错误状态。

不同错误的用户文案：

- 网络错误：检查连接后重试。
- 401/403：登录信息、Token 或签名可能无效。
- 429：请求过于频繁，显示等待状态，不误判为永久失败。
- 响应类型错误：服务未返回可播放音频，可进入规则编辑。
- 连续失败：说明已暂停以避免无限请求。

技术细节默认折叠，日志中必须脱敏。

## 10. 设置页总览

设置页采用“一级入口 + 二级页面”的结构。

设置首页只提供入口，不直接放置开关、输入框、保存按钮或危险操作。首页使用分组列表，不使用卡片，不显示一行摘要或当前值。

```text
设置

常用
  播放设置                                      >
  TTS 规则                                     >

文本处理
  导入与文本                                    >
  章节规则                                     >

应用
  缓存与数据                                    >
  外观                                         >
  诊断与关于                                    >
```

七个设置二级页为：

1. 播放设置。
2. TTS 规则。
3. 导入与文本。
4. 章节规则。
5. 缓存与数据。
6. 外观。
7. 诊断与关于。

二级页面内部不再使用额外设置分组标题，使用扁平设置项列表、工具栏、列表区和必要说明组织内容。

详细布局、设置项、保存策略和后续扩展统一见 `06A_SETTINGS_PAGES.md`。

## 11. TTS 规则管理摘要

TTS 规则是设置页下的二级页面，也是当前 TTS 规则的正式管理入口。

页面要求：

- 顶部提供返回、标题、新建规则、文件导入、剪贴板导入和帮助入口。
- 页面采用左右分栏：左侧为规则列表，右侧为规则编辑区域。
- 左侧规则列表和右侧编辑区域分别使用内部滚动条，参考播放页的目录与正文区域。
- 当前规则只在左侧列表项中明确标记，不在顶部单独显示当前规则状态区。
- 规则列表使用卡片或设置式列表，不使用 `DataGrid`。
- 列表项显示规则名称、启用状态和当前使用标记；不显示兼容性状态和不支持字段摘要。
- 点击左侧列表项切换右侧编辑副本。
- 新建规则在右侧打开空白编辑副本，不使用弹窗或三级页。
- 规则编辑在右侧区域完成，不使用悬浮编辑弹窗。
- 右侧编辑区域只保留结构化表单字段，不提供折叠原始 JSON 编辑区。
- 右侧编辑区域提供设为当前、试听、导出、删除、取消和保存操作。
- 右侧表单字段保留名称、启用、请求 URL/模板、请求方法、Content-Type、Header、并发限制和请求体；请求体仅在 POST 时显示。
- 试听按钮放在右侧编辑区域，不打开试听弹窗；第一版不要求用户额外输入试听文本或语速。
- 文件导入和剪贴板导入直接导入，不提供导入预览。
- 导入时丢弃多余字段；缺少必需字段、类型错误或请求模板无法解析时不允许导入。
- 同名但内容不同的规则允许导入，并自动追加“(2)”、“(3)”等后缀改名。
- 设为当前规则在本页即时保存。
- 播放页仍允许快速切换规则；播放页切换规则复用同一持久化当前规则。
- 页面不常驻显示状态文案；成功/失败反馈优先通过 Snackbar 或通知显示。
- 规则编写帮助通过页内右侧覆盖浮层打开，说明常见字段、模板、Header、试听、导入限制和常见错误。

当前规则保护：

- 当前规则不能在无处理的情况下直接禁用或删除。
- 禁用或删除当前规则时，统一使用一次危险确认；确认后直接清空当前规则，使应用进入无可用规则状态。
- 播放中切换规则时，当前段从头重新生成并继续播放；暂停时保持暂停。

未保存修改保护：

- 切换规则、返回、新建、导入、删除或关闭页面前，如果右侧编辑副本存在未保存修改，必须提供保存、放弃、取消三选项。
- 保存失败时保留编辑内容，并阻止继续切换。

## 12. 章节规则管理摘要

章节规则是设置页下的二级页面，只负责章节识别，不负责通用文本处理或正则替换。

页面要求：

- 页面采用与 TTS 规则页一致的左右分栏工作台：左侧为章节规则列表，右侧为章节规则编辑区域。
- 左侧规则列表和右侧编辑区域分别使用内部滚动条，参考播放页目录与正文区域。
- 不使用 `DataGrid`，不使用独立编辑页，不使用悬浮编辑弹窗。
- 左侧列表项显示规则名称、正则表达式摘要、启用开关和排序操作；不显示“内置 / 自定义”。
- 启用开关放在左侧列表并即时保存；保存失败时恢复 UI 状态。
- 排序支持拖拽，同时提供上移 / 下移键盘等价操作；排序即时保存，失败时回滚 UI 顺序或重新加载。
- 点击左侧列表项切换右侧编辑副本。
- 新建规则在右侧打开空白编辑副本，保存前不进入左侧列表。
- 右侧编辑区域只包含名称、正则表达式、启用、删除、取消和保存。
- 正则表达式输入框提供即时校验；第一版不提供完整小说章节测试调试器，也不提供单行标题测试区。
- 用户自建规则可以删除，内置规则不可删除、只能禁用；左侧不显示类型，右侧删除按钮按规则能力禁用或隐藏。
- 顶部提供新建规则、导入默认规则、恢复默认规则和帮助入口。
- 帮助入口使用页内右侧覆盖浮层，说明正则写法、章节标题示例、排序优先级、内置规则限制和误识别处理。

默认规则操作：

- “导入默认规则”补充缺失的内置规则，按稳定标识更新已有内置规则，保留用户自建规则；直接执行并显示结果摘要。
- “恢复默认规则”重置所有内置规则，但不删除用户自建规则，必须二次确认。

未保存修改保护：

- 切换左侧规则、返回、新建、导入默认、恢复默认、删除或关闭页面前，如果右侧编辑副本存在未保存修改，必须提供保存、放弃、取消三选项。
- 保存失败时保留编辑内容，并阻止继续切换。

## 13. 缓存与数据摘要

缓存与数据是设置页下的二级页面，负责全局缓存总览、缓存上限设置、应用数据目录入口和进入缓存管理三级页。单书详情页仍保留当前书缓存管理，作为上下文快捷入口。

缓存与数据二级页要求：

- 显示当前缓存总占用、缓存上限、使用率进度和 LRU 说明。
- 缓存上限第一版可编辑，默认 `2 GB`，最小 `256 MB`。
- 新上限低于当前占用时，二次确认后立即按 LRU 清理旧缓存。
- 提供“进入缓存管理”入口，进入三级缓存管理页。
- 提供“打开应用数据目录”。
- 二级页不直接显示按书籍缓存列表。
- 二级页不提供“清理全部缓存”；清理全部缓存只放在三级缓存管理页。

缓存管理三级页要求：

- 三级页采用与 TTS 规则页一致的左右分栏工作台：左侧选择书籍，右侧管理该书章节缓存。
- 左侧书籍列表显示书名、作者、缓存占用、已缓存章节数；不提供搜索或筛选。
- 如果缓存摘要只有 `BookId`、章节数、条目数和大小，应用服务必须联合书籍元数据补齐书名和作者。
- 右侧章节列表显示章节序号、章节标题、缓存占用、缓存条目数和章节缓存完整度。
- 如果章节缓存摘要只有章节索引、条目数和大小，应用服务必须联合章节元数据补齐章节标题。
- 章节缓存完整度定义为“已缓存语音段数 / 当前章节可播放语音段总数”，例如 `12/45 段（27%）`；无法计算总段数时只显示已缓存段数。
- 未选择书籍时显示“请选择左侧书籍”；选择后无缓存时显示“该书暂无缓存”。
- 右侧顶部提供“清理本书全部缓存”，每个章节项提供“清理本章缓存”。
- 三级页顶部提供“清理全部缓存”危险操作。
- 缓存清理不删除书籍、阅读进度、章节规则或 TTS 规则。
- 当前播放、正在生成和正在写入的缓存受保护。
- 清理完成后刷新二级页总览、左侧书籍列表和右侧章节列表；部分失败时显示失败摘要。

## 14. 状态反馈与对话框

### 14.1 反馈层级

1. **静默成功**：自动保存等频繁操作。
2. **Snackbar**：导入成功、缓存清理完成、规则导入完成。
3. **页内状态**：空状态、加载状态、播放错误、无规则状态。
4. **ContentDialog**：删除、清除凭据、未保存修改等阻断性决策。

所有 `Snackbar` 和 `ContentDialog` 都应悬浮在主窗口内容之上，不参与页面内部布局，不随页面滚动。

### 14.2 加载与空状态

所有列表页必须定义：

- 首次加载。
- 空列表。
- 加载失败。
- 正常内容。

不得使用“这里未来会显示……”之类开发占位文本。

### 14.3 异步操作

- 长操作允许取消。
- 关闭页面或对话框时取消相关任务。
- 使用操作版本号、会话 ID 或 CancellationToken 忽略迟到结果。
- 主线程只更新 UI，不执行文件解析、数据库批量操作或网络等待。

- 深浅主题下保持足够对比度。
- 动画不影响操作；系统减少动画时应降低或关闭非必要过渡。

## 18. 应用层能力补充

当前后端主链路已完成，但新 UI 需要补齐以下应用层能力：

- 书库摘要返回总章节数、当前章节索引、剩余章节数和总体进度。
- 获取书籍详情和章节摘要。
- 更新书名和作者。
- 原子删除书籍、章节、阅读进度和内部文件。
- 可选清理删除书籍对应缓存。
- 按书名/作者进行本地筛选所需字段。
- 打开指定书籍但保持暂停的播放会话 API。
- 按章节索引或段落索引跳转且保持原播放状态。
- TTS 规则完整编辑、克隆和验证 API。
- 当前规则删除/禁用的保护结果。
- 章节规则左右分栏编辑模型、左侧启用即时保存、排序即时保存和默认规则操作结果摘要。
- 缓存管理摘要模型：书籍摘要需包含书名、作者、缓存占用和已缓存章节数；章节摘要需包含章节序号、标题、缓存占用、缓存条目数和章节缓存完整度。
- 按书籍、按章节和全部缓存清理的统一应用服务，并复用播放/生成/写入缓存保护策略。

这些能力应放入 Application/Infrastructure，不应在 code-behind 中拼接 SQL 或协调播放。

## 19. 核心用户流程

### 19.1 首次使用

```text
启动 → 空书库 → 导入 TXT → 确认预览 → 书架出现书籍
→ 点击书籍 → 若无规则则前往 TTS 规则 → 导入并试听
→ 返回播放页 → 点击播放
```

### 19.2 日常继续收听

```text
启动 → 书库最近阅读排序首位书籍 → 恢复位置但保持暂停 → 点击播放
```

### 19.3 返回书库后继续播放

```text
播放中 → 返回书库 → 音频继续
→ 导航栏底部出现正在播放入口 → 点击返回播放页
```

### 19.4 切换书籍

```text
旧书播放中 → 返回书库 → 点击新书
→ 保存并停止旧会话 → 打开新书上次位置且保持暂停
```

### 19.5 规则故障恢复

```text
自动重试失败 → 播放暂停 → 页内错误条
→ 再次尝试 或 切换规则 → 当前段从头恢复
```

## 20. 明确不做

第一轮 UI 改造不包含：

- 在线封面或元数据搜索。
- 自定义封面图片。
- 章节搜索。
- 正文字号调整。
- 详情页重新解析、重新导入、重置进度。
- 独立的规则试听调试页面。
- 播放页切换书籍。
- 常驻停止、重试、跳过按钮。
- 全局底部播放器条。
- 关闭窗口行为 / 托盘行为 UI；本轮仅在外观页规划。
- 手机或触屏专用布局。

## 21. UI 改造完成标准

- 一级导航只剩书库和设置。
- 所有主要页面使用 Wpf.Ui Fluent 视觉和统一主题资源。
- 书库、TTS 规则、章节规则不再使用 `DataGrid`。
- 书架可搜索、排序、进入播放、进入详情和删除。
- 播放页具有虚拟目录、歌词式正文、五键控制和章节段落进度条。
- 手动滚动后只有连续 4 秒无输入才恢复自动居中，且无竞态抢滚动。
- 返回书库后播放继续，正在播放入口可返回。
- 设置首页使用分组列表，仅提供七个二级页入口；所有设置项进入二级页。
- TTS 规则支持左侧规则列表、右侧编辑区域、新建、直接导入、帮助入口和右侧一键试听。
- 章节规则支持左侧规则列表、右侧编辑区域、左侧启用和排序、默认规则操作以及页内帮助浮层。
- 缓存与数据二级页提供总览和缓存管理入口；缓存管理三级页支持左侧选择书籍、右侧管理章节缓存。
- 浅色、深色、跟随系统和 Windows 10 降级均可用。
- 关键路径可以仅用键盘完成。
- 不再出现开发占位提示、技术错误堆栈或无用元信息。
