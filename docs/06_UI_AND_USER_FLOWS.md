# UI 与用户流程

## 1. 视觉方向

NovelSpeaker 使用 Wpf.Ui/Fluent 作为基础视觉语言，并采用“克制型 Fluent”统一交互反馈：目标是轻量、专注、清楚，通过柔和表面层级、克制强调色和有限动效形成统一风格。

全局原则：

- Wpf.Ui 保持标准控件的默认模板与基础交互，NovelSpeaker 不以全局模板替换改变全部控件。
- 页面保持清晰层级和足够留白，但不通过多层空卡片制造层级。
- 高频工具优先使用图标 + Tooltip；需要明确文字语义的主动作保留文本。
- Accent 只用于主操作、当前状态、进度和焦点，不把所有按钮或卡片染成主题色。
- 危险操作不靠红色常驻大按钮强调，而在最终确认和错误状态中体现风险。
- 选中、Hover、Pressed、Focus、Disabled 必须是不同且可访问的状态。
- Light、Dark 与 High Contrast 使用同一交互结构；Mouse Hover 不使用 Keyboard Focus Ring，持续 Selected/Checked 状态不得被普通 Hover 覆盖。
- UI 文案使用短动作或名词，例如“清理”“缓存管理”“定位到当前章节”。

## 2. 样式作用域与交互状态

NovelSpeaker 的通用视觉由语义 palette、有限的稳定 Design Token、具名样式和应用自有组件构成。页面专用列宽、边距和工作台分栏由对应页面或组件管理，不作为全局令牌传播。

### 普通工具图标

- 默认无边框、无背景。
- Hover 使用柔和圆角状态层，不绘制突兀方形 Stroke。
- Pressed 加深状态层。
- Keyboard Focus 使用独立焦点环。
- Disabled 保留位置但降低强调，不隐藏。
- 页面通过显式 `App.*` 样式或应用自有组件选择外观，不依赖应用级隐式标准控件样式。

### 列表与输入

- 整行可点击的列表项由整行拥有唯一弱 Hover；行内独立按钮只在自身小命中区反馈，不与父项形成双层大面积高亮。
- 整行不可点击的设置项不提供整行 Hover，仅 ToggleSwitch、ComboBox、TextBox、Button 等真实操作目标响应。
- TextBox/ComboBox 等字段型输入主要通过边界变化表达 Hover/Focus，不以明显背景高亮模拟按钮。
- ToggleSwitch 的 Hover/Pressed 只增强轨道或 Thumb；纯开关 Focus/HitTest 范围贴合实际开关区域。

### 媒体控制

- 播放/暂停、上一段/下一段、上一章/下一章和音量使用相同尺寸的中性媒体按钮。
- 播放/暂停不再通过 Accent 背景或更大的按钮制造额外层级，媒体语义由图标、位置和 Tooltip 表达。
- 普通媒体按钮 Rest 透明，Hover 只增强图标，Pressed 使用轻微内容反馈；不出现与媒体按钮命中区同尺寸的矩形/圆角背景块。
- 播放页和迷你播放器共享媒体按钮的尺寸和中性状态语义，但各自拥有布局、间距和排列。

### 布局所有权

- Shell 拥有标题栏、一级导航、Window Background，以及 `NavigationView` 内容宿主的 Canvas、边界和左上圆角。
- 正式 Page 根节点保持透明；页面 Padding 只是 Shell Canvas 上的布局留白。页面不得绘制不透明根 Canvas 遮住内容宿主圆角，也不允许通过外层 Window Background + 内层带 Margin Canvas 形成第二圈页面背景。
- 页面拥有页面内部边距、分栏和内容滚动结构。
- 复合组件拥有自身内部间距和最小尺寸。
- 同一段空白、宽度或对齐只允许一个 owner，避免 Shell、NavigationView、页面和组件重复叠加。

## 3. 主窗口信息架构

一级导航只保留：

- 书库
- 设置

Shell Footer 可额外显示以下全局入口：

- “正在播放”：存在播放上下文时显示。
- “缓存中 · x/y 章 · n%”：存在主动缓存批次时显示。
- “导出中 · x/y 章 · n%”或“导出完成 · N 章”：存在章节导出运行态或待确认的成功终态时显示。
- Light/Dark 快捷切换：始终位于 Footer 最后一项，作为跨页面常驻入口。

主动缓存和章节导出入口分别点击后打开轻量 Flyout；当前阶段不新增一级“任务中心”。

主题快捷入口只执行 Light 与 Dark 之间的切换，不提供 System 目标。展开导航栏时显示“切换到深色模式”或“切换到浅色模式”等动作语义，Compact 状态只显示对应的 Moon/Sun 图标，并保留等价 Tooltip 与 AutomationName。图标和文案表达“点击后的目标主题”，而不是重复显示当前主题。

当持久设置为 System 时，快捷入口先读取当前实际生效的系统主题：系统当前为 Light 时点击后切换并持久化为 Dark，系统当前为 Dark 时点击后切换并持久化为 Light。快捷入口一旦被使用，主题即成为显式 Light/Dark；如需重新跟随系统，只能在“设置 → 外观”中选择 System。

## 4. 桌面选择模型

章节缓存选择统一采用文件管理器式语义，由可复用 selection controller 实现：

- 单击：单选。
- `Ctrl+Click`：增减选择。
- `Shift+Click`：从 anchor 到当前项区间选择。
- `Ctrl+A`：全选当前列表。
- `Esc`：退出临时选择模式或清除选择，具体由页面语义决定。
- 选中项必须有明显但不过度的整卡背景/边框变化。

不要使用 checkbox 常驻列表，也不要把 Ctrl/Shift 语义分别复制到多个页面 code-behind。

## 5. 书库页

- 书架式响应式卡片网格，不使用 DataGrid，也不使用固定卡宽的普通 WrapPanel 造成右侧大面积剩余。
- 显示封面、书名、作者、当前章节、剩余章节等核心信息。
- 顶部支持按书名/作者搜索，并可在“最近阅读”和“书名”排序之间切换。
- 搜索无匹配结果时显示居中的“清空搜索”操作。
- 导入使用顶部图标入口，也支持拖放。
- 单击书籍进入播放；书籍上下文菜单提供详情和删除入口。
- 删除属于书籍实体操作，放入书籍上下文菜单或明确入口，并保持二次确认。
- 列表/网格滚动位置和排序尽量保持。
- 卡片水平宽度以书库 ScrollViewer 的实际可用 viewport 为依据动态计算，不以 Window 宽度或固定断点直接决定。卡片最小宽度为 `300 px`，最大宽度为 `360 px`，水平/垂直间距为 `16 px`。
- 对实际可用宽度 $V$，列数使用 $N=\max(1,\lfloor(V+16)/(300+16)\rfloor)$；填满时卡宽为 $W_{\mathrm{raw}}=(V-(N-1)\times16)/N$，最终卡宽为 $W=\min(W_{\mathrm{raw}},360)$。
- 书架网格始终以内容区左侧基线为起点。卡片达到 `360 px` 最大宽度后不再继续拉宽，剩余空间全部保留在右侧；不足一整行的最后一行也保持左对齐，不单独居中。默认 `1280 px` 主窗口应稳定呈现约 3 列；更窄或更宽窗口按实际 viewport 自然切换列数。
- `BookCardView` 保持 `104 × 140 px` 封面、`16 px` 卡片内边距和封面到文字列 `16 px` 间距。右上角 MoreButton 只占用标题区域所需的安全空间；作者、当前章节、剩余章节和进度条使用完整文字列宽，不再为 MoreButton 全列永久预留大块右侧空白。

## 6. 书籍详情页

- 顶部显示书籍摘要和主要操作。
- 允许编辑应用内书名和作者；取消/保存只作用于编辑副本，离开或执行冲突操作时经过未保存保护。
- 删除书籍保持二次确认，且永不修改外部源文件。
- 章节目录使用虚拟化列表，整个页面不依赖外层长滚动。
- 点击章节进入播放/切换章节。
- 当前章节只使用已有整卡/强调条样式和无障碍语义，不显示“当前”文本标记。
- 章节右侧只在存在当前有效朗读清单且完整度大于 0% 时显示缓存百分比；0%、清单缺失、清单过期、不可用、无可播放段落或仍在加载时不显示。0% 隐藏是明确的用户体验规则，不作为缺陷修正。
- 当用户滚动离开当前章节时，章节区域出现悬浮“定位到当前章节”图标；点击后平滑滚动并在到达后隐藏。
- 不在这里重复提供复杂缓存管理；缓存管理统一进入设置页专门工作台。

## 7. 播放页

布局保持双区域：章节目录 + 正文/媒体控制。

### 7.1 章节目录

- 正常状态单击章节执行跳转。
- 用户滚离当前章节时显示“定位到当前章节”悬浮按钮。
- 当前章节只使用已有整卡/强调条样式和无障碍语义，不显示“当前”文本标记。
- 章节右侧只在存在当前有效朗读清单且完整度大于 0% 时显示当前配置缓存百分比；0% 和其它非正常状态不显示。
- 点击“缓存”工具后进入主动缓存选择模式；此时单击章节改为选择，不再跳转。
- 选择模式顶部显示“已选择 N 章”“取消选择”“开始缓存”。

### 7.2 正文

- 歌词式段落列表，当前段明显但不过度高亮。
- 播放推进自动居中；用户主动滚动后暂停自动追随。
- 当当前段离开可见区域时显示“返回当前段落”悬浮按钮。
- 上一/下一段、拖动进度产生的新定位也使用平滑滚动。

### 7.3 播放工具区

主要媒体控制：

- 上一章
- 上一段
- 播放/暂停
- 下一段
- 下一章
- 进度条
- 播放音量图标按钮；点击后打开悬浮窗，用竖向滑块调整应用内播放音量，不改变系统音量。

五个核心媒体按钮与音量入口保持一致的图标尺寸和命中区。播放/暂停位于核心控制组中心，但不通过更大的图标、实心 Accent 圆钮或 Hover 背景方块建立层级；按钮 Hover 仅增强图标，Pressed 使用轻微内容反馈。

Dark Mode 下 Pressed 仍必须保持高对比度主题前景；媒体、Toolbar 和普通 Icon Button 不允许在按下瞬间把图标切换为黑色或其它与当前 Surface 对比不足的 Provider 默认颜色。

播放进度条使用两段对比轨道：已播放部分为 Accent，未播放部分为弱中性色。Thumb 默认隐藏，Mouse Hover、Keyboard Focus 或 Dragging 时出现；Dragging 时保持显示并略强化，不给整个 Slider 绘制外框。

音量 Flyout 使用竖向 Slider，已设置音量与剩余轨道保持明显但克制的对比，Thumb 默认显示；填充条和剩余轨道保持同一固定厚度并连续延伸到 Thumb 下方，不在控制柄附近出现局部收缩/掐腰；音量为 0 时入口切换为静音图标。
音量 Thumb 在 Pressed/Dragging 时允许轻微增强或放大，但外层布局包络保持固定并按最大视觉尺寸预留，不能因为状态变化在右侧产生裁切、遮挡或横向位移。

目录卡片和正文预览段落的 Hover 只允许显示一层圆角状态面；`ListBoxItem`、透明点击宿主和内部 Selection Border 中只有 Selection Border 可以绘制可见 Hover/Selected 背景，不允许出现额外的直角矩形 PointerOver 层。

播放页和迷你播放器的进度条在鼠标悬浮或拖动时，通过 Tooltip 显示当前段落位置，例如 `xx/xx`。

顶部或章节标题附近的低频工具使用图标：

- 主动缓存
- 定时停止
- 迷你播放器
- TTS 规则切换；菜单只列出已启用规则，当前规则只在该菜单中表达选中状态。没有已启用规则时提供前往 TTS 规则管理页的入口，但不提示用户在规则管理页“设为当前”。

定时停止使用 Flyout，不进入设置页常驻配置；工具按钮显示剩余分钟数，不显示单位，未设置时显示占位符。

语速入口直接显示 TTS 规则变量使用的原始整数值，不转换为 `0.8× / 1.0× / 1.2×` 等播放器倍速。语速 Flyout 使用 `− / 可编辑整数 / +`，步进为 1，并保持现有有效范围、输入校验与 TTS/cache 行为不变。

定时停止入口采用轻量 Pill：未启用时保持中性，启用时使用弱 Accent 持续状态。Flyout 中 `15 / 30 / 45 / 60 / 90` 为轻量 Choice，当前选择使用弱 Accent；自定义分钟为次级输入，“关闭定时”保持中性而非危险色。

## 8. 主动缓存进度 UI

Shell 紧凑入口示例：

```text
缓存中 · 3/8 章 · 42%
```

Flyout 内容：

```text
正在缓存
第三章                 已完成
第四章                 18 / 42
第五章                 等待中

总进度 76 / 168 段
[取消任务]
```

任务完成后入口自动消失，以 Snackbar 报告完成；失败保留安全错误摘要和可理解结果，不显示请求细节。

## 9. 规则工作台

TTS、章节规则和正则替换共享一套交互骨架。

### 左侧规则卡片

- 卡片采用左右布局：左侧显示名称和一行摘要，右侧使用 ToggleSwitch 控制启用状态。
- ToggleSwitch 是独立命中区域，不触发卡片选择、编辑器切换或拖动；宿主使用内容宽度布局，不能让不可见空白扩大开关命中范围。
- 单击卡片主体才打开右侧编辑器。页面进入、导入完成或恢复页面时都不自动选中第一条规则。
- 右键卡片打开单规则 ContextMenu，但不改变当前编辑对象；键盘使用 `Shift+F10`/Menu Key 打开同一菜单。
- 三类规则菜单都提供“导出到文件”“复制到剪切板”和删除；章节/正则另外提供上移/下移。
- 不显示 `⋮` 更多按钮。TTS 卡片也不显示“当前规则”或“设为当前”。

页面级“从文件导入”“从剪切板导入”放在 `AppPageHeader.Actions`；导出始终是单规则右键操作，不提供页面级导出。

导入采用合并语义：完全重复规则跳过，同名但内容不同的规则作为新规则追加；导入不覆盖现有规则，也不自动打开导入项。章节/正则的新规则按导入源顺序追加到现有排序末尾。

### 启用状态与 TTS 当前规则

- ToggleSwitch 属于列表级即时设置，不属于右侧编辑草稿，也不参与 Dirty State；持久化失败时回滚列表状态并投影错误。
- TTS 当前规则只在播放页选择，播放页的规则切换列表只显示已启用规则。
- 当前 TTS 规则被禁用或删除时直接清空当前选择，不自动切换其它规则；导入、新建或重新启用规则不会自动成为当前规则。

### 排序拖动

- 章节规则和正则替换不显示拖动手柄，整张卡片主体作为拖动区域；ToggleSwitch 和 ContextMenu 交互区域不参与拖动手势。
- 鼠标按下约 `300 ms` 后进入可拖动态，随后移动才启动拖动；长按阈值前释放仍按普通单击处理。
- 本阶段采用轻量反馈方案：拖动态使用透明度/边框/光标等状态反馈和明确插入线，不实现相邻卡片位移动画。
- 鼠标位于目标卡片垂直中心线上方时插入目标之前，下方时插入目标之后；拖到列表顶部/底部边缘时自动滚动。
- 排序只在 Drop 后持久化；右键菜单中的上移/下移继续作为键盘和备用等价操作。

### 右侧编辑区

- 未选中规则时显示统一空状态，不展示任何规则字段。
- 只显示规则字段和必要的编辑辅助。
- TTS 底部只保留“试听”“取消”“保存”。
- 章节/正则保留“取消”“保存”以及页面特有的帮助入口。
- 右侧编辑器一旦打开，“取消”始终可用；点击后直接丢弃当前草稿、清除选择并关闭编辑器，返回空状态。
- “保存”只在草稿存在修改且校验通过时可用；保存完成后编辑器可以继续保持打开。
- 未保存保护统一覆盖返回、左侧切换、一级导航、快捷键和窗口退出。

## 10. 设置入口视觉

设置首页和二级页进入三级页均使用导航行，而不是传统 Button：

```text
[icon]  缓存管理                                      >
```

- 无常驻边框。
- 整行可点击。
- Hover 使用圆角状态层。
- 只显示 icon + 标题 + Chevron；不在入口下堆说明文字。

普通设置项采用轻量分组面板 + 设置行：左侧标题/必要说明，右侧控件。

## 11. 缓存管理页

左右分栏：

- 左侧：单选书籍，显示书名、作者、缓存大小和已缓存章节数。
- 右侧：直接从当前书籍摘要开始，不再显示重复的“章节缓存 / 当前书名”二级 Header；其下为章节缓存列表。
- 右侧 `AppSectionSurface` 允许无 Header/Description，空 Header 时不保留额外标题间距。

章节卡片首行显示章节序号和标题，次行显示缓存大小、条目数和“完整度”。所有章节卡片必须铺满列表可用宽度，不按内容宽度收缩，也不使用固定像素宽度。

- 列表来源是缓存索引，因此显示当前书籍全部有缓存章节。
- 当前配置命中 0 段时仍保留章节卡片，并明确显示 `0/N 段 · 0%`。
- 清单过期或异常缺失时仍保留章节卡片，先显示“计划更新中/计划计算中”，后台完成后原位刷新。

交互：

- 平时单击章节即选择；不需要额外“进入批量模式”按钮。
- 支持 Ctrl/Shift/Ctrl+A。
- PageHeader 右侧显示“已选择 N 章”，并提供无文字的清理 DangerIcon 与导出 IconButton；0 项选择时两者禁用，按钮保留 Tooltip 与 AutomationName。
- 章节 ContextMenu 保留“清理所选章节”“导出所选章节”快捷入口，并与 PageHeader 复用同一命令。右键已选章节保持多选集合；右键未选章节先将它变成唯一选中项，再打开菜单。
- 不显示逐章删除按钮，不显示“清理本书”按钮；选中整本书全部章节后清理即为等价操作。
- 不支持跨多本书选择章节。

“清理全部缓存”放在上一级“缓存与数据”页面。

## 12. MP3 导出交互

- 用户选中一个或多个章节后点击 PageHeader 导出图标或章节 ContextMenu 的“导出所选章节”。
- 页面负责前置流程：检查可导出性 → 必要时确认跳过不可导出章节 → 选择目标根目录 → 提交进程级章节导出协调器。全部不可导出时不打开目录选择器；不会自动生成缺失缓存。
- 提交时冻结本次书籍、章节集合和目标目录；此后改变页面选择、切换书籍、导航离开或隐藏主窗口均不影响已经运行的批次。全应用同一时间最多一个章节导出批次。
- 每章生成一个含章节名的 MP3；应用自动创建安全书名子目录。
- 章节卡片不常驻显示“可导出”或“缓存不完整，无法导出”等文案，详细原因通过 Tooltip 和 AutomationName 提供。
- 缓存管理页不显示导出 Progress/Cancel/Open Directory 面板。运行中的状态由 Shell Footer 显示 `导出中 · x/y 章 · n%`；点击打开 Flyout，显示书名、当前章节、章级总进度和“取消任务”。
- 成功时发送一次 Snackbar，并把 Shell 项转为 `导出完成 · N 章`；点击 Flyout 可“打开目录”或“关闭”，执行任一操作后该完成项消失。
- 取消或失败通过 Snackbar 通知后移除 Shell 项。真正退出应用时取消后台导出并完成有界清理。

## 13. 迷你播放器

迷你播放器是小型独立窗口：

- 书名、当前章节。
- 不显示系统标题栏。
- 上一章、上一段、播放/暂停、下一段、下一章。
- 使用播放页同款可拖动章节段落进度条，显示当前段落在本章中的位置；悬浮或拖动时通过 Tooltip 显示 `xx/xx`。
- 五个媒体按钮和音量按钮使用统一 `48 × 48` 命中区及中性状态；播放/暂停不单独使用 Accent 背景或更大按钮。
- 置顶按钮在已置顶时使用强调色状态，并显示“取消置顶”语义。
- 恢复主窗口按钮；关闭按钮用于退出应用。

进入后隐藏主窗口。点击恢复主窗口只退出迷你模式；关闭迷你窗口或其关闭按钮等价于退出应用。位置与置顶状态可记忆，迷你模式本身不跨启动恢复，下一次启动仍按主窗口/托盘设置初始化。窗口空白区域可拖动位置，右侧边缘仅可调整宽度，按钮和其它交互控件区域保留原有操作。

## 14. 托盘

托盘菜单保持精简：

- 显示主窗口
- 播放/暂停
- 迷你播放器
- 退出

最小化到托盘时不能把“关闭窗口”误当作进程退出。

## 15. 反馈和对话框

反馈层级：

1. 控件内校验：字段错误。
2. 页内状态：加载、空列表、不可用原因。
3. Snackbar：导入、清理、缓存完成、导出完成等非阻塞结果。
4. 对话框：删除书籍、清理全部缓存、放弃未保存修改等高影响确认。

错误信息只给用户可操作内容，不展示技术堆栈或敏感请求信息。

Dialog、Flyout、Popup 和独立状态浮窗遵循单一主 Surface 原则：宿主已经形成完整浮层时，内容保持平面，不再嵌套第二张带完整背景、边框、圆角和阴影的卡片。ContentDialog 内部以标题、正文、字段/选项和 Footer 建立层级；StartupStatusWindow 由窗口自身承担 Raised Surface，内部状态控件使用 Embedded 模式。复杂对话框确有独立二级信息分组时，优先使用 Divider 或弱背景，而不是完整 Card-in-Dialog。

语速调节、规则切换、音量控制、定时停止等 Popup/Flyout 的圆角内容 Surface 是唯一可见实体层。四角圆弧之外必须真正透明并直接露出底层页面，只允许存在与圆角轮廓一致的柔和阴影；不得在背后残留高透明度直角矩形宿主、Provider 背板或第二层方形 Effect。

ContextMenu、下拉菜单和 Popup 内的菜单项 Rest 透明，Hover 使用单一弱圆角状态层，Pressed 稍增强，Checked/Selected 使用弱 Accent。分组分隔线必须是独立 Separator，并以统一左右 inset 与文字列对齐；不得把分隔线画成某个 MenuItem 的 Bottom Border，也不得让分隔线继承相邻项的 Disabled/Opacity 状态。

## 16. 键盘与可访问性

现有播放快捷键继续保留，并加入桌面列表选择语义：

- `Space`：播放/暂停（播放页且焦点不在输入控件）。
- `Ctrl+Left/Right`：上一/下一段。
- `Ctrl+Shift+Left/Right`：上一/下一章。
- `Alt+Left`：返回。
- `Ctrl+,`：设置。
- `Ctrl+A`：在支持多选的章节列表中全选。
- `Esc`：退出选择/临时界面。

要求：

- 所有图标按钮有 Tooltip 和 AutomationName。
- 键盘 focus 可见。
- 颜色不是唯一状态信号。
- 虚拟化列表选择和定位可被键盘操作。

## 17. UI 代码边界

- ViewModel 不引用 Page、Window、Dispatcher 或具体 WPF 视觉类型。
- code-behind 只处理焦点、拖放、虚拟化、滚动、动画、窗口和平台事件桥接。
- 选择状态、dirty state、导航保护和后台任务状态优先放入可测试 controller/Application service。
- 文件选择、目录打开、媒体键、托盘和迷你窗口通过平台 port 统一实现。
