# UI 与用户流程

## 说明

本文件是当前项目唯一维护的 UI/UX 正式方案。

后续涉及以下内容时，应直接更新本文件，而不是再维护第二份并行的 UI/UX 设计文档：

- 主窗口信息架构和导航层级。
- 书库页、播放页、规则页、设置页的职责边界。
- 全局播放器条、状态提示和错误反馈模式。
- 缓存管理、章节规则管理等低频管理功能的位置。
- 整体视觉方向、组件气质和可访问性基线。

## 设计原则

- 界面服务于听书，不追求完整阅读器功能。
- 产品整体为播放器优先，而不是阅读器优先。
- 用户应始终知道当前书籍、章节、播放状态和错误原因。
- 正常播放时隐藏技术细节。
- 错误时提供可执行操作，而不仅是错误码。
- 设置和规则编辑不阻塞主播放页。
- 整体视觉参考当前流行的现代媒体产品风格，但保持桌面工具应有的稳定与清晰。
- 状态提示以轻提示优先，尽量减少打断式弹窗。

## 页面结构

```text
MainWindow
├─ LibraryView
├─ PlayerView
├─ TtsRulesView
└─ SettingsView
```

第一版使用单窗口页面式导航，并保持稳定的媒体壳层。一级导航固定为：

- `书库`
- `播放`
- `规则`
- `设置`

主窗口采用稳定三层结构：

- 顶部全局导航。
- 中央页面内容区。
- 底部全局播放器条。

`TtsRuleEditorView` 不要求作为一级导航页面存在，可以作为规则页中的二级状态、覆盖式面板或子页面。

### 顶部全局导航

职责：

- 承载一级导航。
- 显示应用名称或当前上下文。
- 提供轻量全局动作入口，例如返回当前播放。

### 中央页面内容区

职责：

- 承载书库、播放、规则、设置四个主页面。
- 保持统一边距、标题层级和操作区风格。

### 底部全局播放器条

职责：

- 承载全局核心播放控制。
- 展示当前书籍、章节、规则、状态与关键操作。

要求：

- 在所有主页面中持续可见。
- 即使没有当前书籍，也显示空状态引导，而不是隐藏。
- `播放/暂停` 始终是最强主操作。

## 启动与首页行为

应用启动默认进入 `书库` 页。

即使后续支持恢复最近播放，也不直接抢占式跳入播放页，而是在书库首页展示“继续收听”入口：

- 首次使用：显示空状态欢迎区和导入入口。
- 已有最近播放：在首页顶部展示“继续收听”卡片。
- 用户主动点击后进入播放页。

## 书库页

书库页是应用首页，不只是书籍列表。它承担三种职责：

- 导入新书。
- 继续最近播放。
- 管理已有书籍。

布局建议从上到下分为三段：

1. 继续收听区
2. 导入操作区
3. 书籍列表区

### 继续收听区

如果存在最近播放书籍，应显示一张较醒目的“继续收听”卡片，包含：

- 书名。
- 当前章节。
- 最近播放时间。
- 继续收听按钮。

### 导入操作区

内容：

- 导入小说按钮。
- 拖放区域。
- 导入分析预览区。
- 导入进度与取消入口。
- 导入失败的轻量提示区。

要求：

- 首次使用时足够显眼。
- 导入失败优先就地提示，而不是对话框打断。
- 手动切换编码时先刷新预览，再由用户确认导入。

### 书籍列表区

每本书显示：

- 书名
- 作者
- 当前章节
- 最近播放时间
- 大致进度

主操作：

- 打开或继续播放

次操作收进更多菜单：

- 删除书籍
- 查看章节
- 编辑元数据
- 清理单本书缓存

不需要：

- 封面搜索。
- 在线元数据。
- 复杂排序。
- 标签系统。

视觉上，书库页应更像媒体资料库，而不是数据库管理表格。

## 播放页

播放页是主消费页，但定位仍然是“播放控制中心”，而不是沉浸式阅读器。

核心原则：

- 控制与状态优先。
- 正文是辅助上下文，不是绝对主角。
- 用户应在短时间内看懂“现在正在听什么、处于什么状态、能做什么”。

中央区域建议采用左右布局：

```text
┌──────────────┬────────────────────────────┐
│ 章节目录      │ 当前播放摘要                │
│              │ 当前章节标题                │
│ 第一章        │ 状态 / 规则 / 快捷动作      │
│ 第二章        │                            │
│ 第三章        │ 正文……                     │
│              │ 当前朗读段落高亮            │
│              │ 后续正文……                 │
└──────────────┴────────────────────────────┘

全局底部播放器条：
播放/暂停  上一段  下一段  上一章  下一章  规则  语速  状态  进度
```

功能：

- 章节选择。
- 当前段落高亮。
- 自动滚动。
- 播放、暂停、停止。
- 上一段、下一段。
- 上一章、下一章。
- 规则选择。
- 语速设置。
- 缓冲和错误状态。
- 重试当前段。
- 跳过当前段。

### 当前播放摘要区

包含：

- 书名。
- 当前章节标题。
- 当前规则名。
- 当前状态。
- 快捷动作：
  - 切换规则
  - 重试当前段
  - 跳过当前段

### 正文上下文区

用于显示章节正文与当前朗读段位置。

要求：

- 当前朗读段高亮清晰但不刺眼。
- 自动滚动优先服务定位，不做复杂阅读器交互。
- 行宽、字号、行高更偏快速扫读而不是长时间沉浸阅读。

## TTS 规则页

规则页是低频但关键的工具空间。

列表内容：

- 规则名称。
- 启用状态。
- 最近使用时间。
- 兼容状态。
- 测试结果。

操作：

- 新建。
- 从文件导入。
- 从剪贴板导入。
- 导出。
- 编辑。
- 删除。
- 测试连接。
- 输入试听文本。
- 清除 Cookie。
- 配置登录信息。

主播放页中对规则只做轻量露出：

- 显示当前规则名。
- 提供快速切换。
- 提供跳转到规则页的入口。
- 不直接展示复杂请求细节。

## 规则编辑

规则编辑作为规则页中的二级状态、覆盖式面板或子页面出现，不作为一级导航页面。

字段：

- 名称。
- URL/规则内容。
- Header。
- Content-Type。
- ConcurrentRate。
- 是否启用 Cookie。
- 登录信息键值。
- 原始 JSON 预览。
- 当前版本不支持字段提示。

提供：

- 模板语法提示。
- 测试文本。
- 临时 `loginInfo` 输入，按测试态内存值处理，不持久化。
- 请求预览，但敏感值脱敏。
- 响应状态和 Content-Type。
- 有限长度错误正文。
- 试听、取消和清除单规则 Cookie。

## 设置页

第一版：

- 默认语速。
- 预取段落数量。
- 日志级别。
- 主题。
- 缓存管理入口。
- 章节规则管理入口。
- 清除全部凭据。
- 打开数据目录。

### 高级缓存管理

缓存管理位于设置页下的子页面。

前提：

- 实际缓存粒度是每一条段落音频。
- 管理粒度以章节为最小单位。
- 淘汰策略采用 `LRU`。

要求：

- 展示总缓存上限与当前占用。
- 说明 `LRU` 过时淘汰策略。
- 按书籍查看缓存占用。
- 以章节为最小管理单位进行清理。
- 支持清理整本书缓存和全部缓存。

### 章节规则管理

章节规则管理位于设置页中的“导入与文本”分组下，作为子页面或弹层存在。

支持：

- 查看全部章节规则。
- 新增规则。
- 修改规则。
- 删除规则。
- 启用或禁用规则。
- 调整顺序。
- 导入默认规则。

## 视觉语言

整体视觉方向采用以下组合：

- 现代媒体感为主。
- 克制工具感兜底。
- 参考当前流行的应用设计风格，但避免为了“潮流感”牺牲可用性。

视觉特征：

- 顶部导航、中央页面、底部播放器条具有明确壳层感。
- 页面使用适度卡片化布局，但避免过度装饰。
- 色彩以清晰层次、稳定对比和有限强调色为主。
- 播放状态、当前内容和主操作是视觉焦点。

组件风格要求：

- 顶部导航简洁，短标签，当前态清晰。
- 书库页“继续收听”卡片是视觉重点。
- 底部播放器条是全局视觉重点之一。
- 规则、设置、缓存管理等工具页在视觉上更克制，优先信息清晰度。

## 首次使用流程

```text
启动应用
  ↓
进入书库页
  ↓
无最近播放：空书库提示 / 有最近播放：显示继续收听卡片
  ↓
导入 TXT 或继续收听
  ↓
自动解析章节
  ↓
无 TTS 规则时引导导入或新建规则
  ↓
测试规则
  ↓
进入播放页
  ↓
点击播放
```

## 导入规则流程

```text
选择 JSON 文件或粘贴 JSON
  ↓
解析对象或数组
  ↓
显示规则预览
  ↓
标记不支持字段
  ↓
用户确认导入
  ↓
保存
  ↓
测试规则
```

## 状态与错误反馈

反馈分成四类：

1. 静默成功
2. 轻量成功或提醒
3. 持续状态
4. 阻断性错误

### 网络错误

- 简洁说明。
- 重试。
- 打开规则设置。
- 跳过当前段。

### 鉴权错误

显示：

- “服务返回 401/403，可能是密钥、Token 或签名无效。”
- 打开登录信息。
- 不进行无限自动重试。

### 限流错误

显示：

- “请求过于频繁，正在等待。”
- 可显示预计等待时间。
- 不将其标记为永久故障。

### 内容类型错误

显示：

- 实际 Content-Type。
- 截断后的响应正文。
- 打开规则编辑器。

### 反馈位置

- 轻量成功或提醒：顶部信息条、页内消息、短时轻提示。
- 持续状态：底部全局播放器条、播放页摘要区。
- 阻断性错误：仅在关键场景使用对话框或强提醒。

## 窗口与布局约束

- 默认体验优先适配常见桌面宽屏。
- 较窄窗口下布局应退化而不是崩坏。
- 章节列表允许折叠。
- 播放摘要允许压缩。
- 次要元信息可延后显示。
- 底部全局播放器条必须始终保留核心主操作。

## 可访问性

- 关键按钮支持键盘操作。
- 播放状态不能只用颜色表示。
- 正文允许调整字号。
- 高亮不应降低可读性。
- 控件提供 AutomationProperties.Name。
- 同类动作在不同页面命名一致，例如：
  - `导入 TXT`
  - `导入规则`
  - `导入默认规则`
  - `清理缓存`
