# UI 与用户流程

## 1. 视觉方向

NovelSpeaker 使用 Wpf.Ui/Fluent 作为基础视觉语言，目标是轻量、专注、清楚，并通过柔和表面层级、克制强调色和轻量悬浮质感形成统一风格。

全局原则：

- Wpf.Ui 保持标准控件的默认模板与基础交互，NovelSpeaker 不以全局模板替换改变全部控件。
- 页面保持清晰层级和足够留白，但不通过多层空卡片制造层级。
- 高频工具优先使用图标 + Tooltip；需要明确文字语义的主动作保留文本。
- Accent 只用于主操作、当前状态、进度和焦点，不把所有按钮或卡片染成主题色。
- 危险操作不靠红色常驻大按钮强调，而在最终确认和错误状态中体现风险。
- 选中、Hover、Pressed、Focus、Disabled 必须是不同且可访问的状态。
- UI 文案使用短动作或名词，例如“清理”“缓存管理”“定位到当前章节”。

## 2. 样式作用域与交互状态

NovelSpeaker 的通用视觉由语义 palette、有限的稳定 Design Token、具名样式和应用自有组件构成。页面专用列宽、边距和工作台分栏由对应页面或组件管理，不作为全局令牌传播。

### 普通工具图标

- 默认无边框、无背景。
- Hover 使用柔和圆角状态层，不绘制突兀方形 Stroke。
- Pressed 加深状态层。
- Keyboard Focus 使用独立焦点环。
- Disabled 保留位置但降低强调，不隐藏。
- 页面通过显式 `App.*` 样式或应用自有组件选择外观，不依赖应用级隐式标准控件样式。

### 媒体控制

- 播放/暂停、上一段/下一段、上一章/下一章和音量使用相同尺寸的中性媒体按钮。
- 播放/暂停不再通过 Accent 背景或更大的按钮制造额外层级，媒体语义由图标、位置和 Tooltip 表达。
- 普通媒体按钮使用中性状态层，不替换标准按钮全局模板。
- 播放页和迷你播放器共享媒体按钮的尺寸和中性状态语义，但各自拥有布局、间距和排列。

### 布局所有权

- Shell 拥有标题栏、一级导航、Window Background，以及 `NavigationView` 内容宿主的 Canvas、边界和左上圆角。
- 正式 Page 根节点保持透明；页面 Padding 只是 Shell Canvas 上的布局留白。页面不得绘制不透明根 Canvas 遮住内容宿主圆角，也不允许通过外层 Window Background + 内层带 Margin Canvas 形成第二圈页面背景。
- 页面拥有页面内部边距、分栏和内容滚动结构。
- 复合组件拥有自身内部间距和最小尺寸。
- 同一段空白、宽度或对齐只允许一个 owner，避免 Shell、NavigationView、页面和组件重复叠加。

## 3. 主窗口信息架构

一级导航只保留：

- 书库
- 设置

Shell 可额外显示两个运行时入口：

- “正在播放”：存在播放上下文时显示。
- “缓存中 · x/y 章 · n%”：存在主动缓存批次时显示。

主动缓存入口点击后打开轻量 Flyout，不新增一级“任务中心”。

## 4. 桌面选择模型

章节缓存选择统一采用文件管理器式语义，由可复用 selection controller 实现：

- 单击：单选。
- `Ctrl+Click`：增减选择。
- `Shift+Click`：从 anchor 到当前项区间选择。
- `Ctrl+A`：全选当前列表。
- `Esc`：退出临时选择模式或清除选择，具体由页面语义决定。
- 选中项必须有明显但不过度的整卡背景/边框变化。

不要使用 checkbox 常驻列表，也不要把 Ctrl/Shift 语义分别复制到多个页面 code-behind。

## 5. 书库页

- 书架式卡片，不使用 DataGrid。
- 显示封面、书名、作者、当前章节、剩余章节等核心信息。
- 顶部支持按书名/作者搜索，并可在“最近阅读”和“书名”排序之间切换。
- 搜索无匹配结果时显示居中的“清空搜索”操作。
- 导入使用顶部图标入口，也支持拖放。
- 单击书籍进入播放；书籍上下文菜单提供详情和删除入口。
- 删除属于书籍实体操作，放入书籍上下文菜单或明确入口，并保持二次确认。
- 列表/网格滚动位置和排序尽量保持。

## 6. 书籍详情页

- 顶部显示书籍摘要和主要操作。
- 允许编辑应用内书名和作者；取消/保存只作用于编辑副本，离开或执行冲突操作时经过未保存保护。
- 删除书籍保持二次确认，且永不修改外部源文件。
- 章节目录使用虚拟化列表，整个页面不依赖外层长滚动。
- 点击章节进入播放/切换章节。
- 当前章节只使用已有整卡/强调条样式和无障碍语义，不显示“当前”文本标记。
- 章节右侧只在存在当前有效朗读清单且完整度大于 0% 时显示缓存百分比；0%、清单缺失、清单过期、不可用、无可播放段落或仍在加载时不显示。0% 隐藏是明确的用户体验规则，不作为缺陷修正。
- 当用户滚动离开当前章节时，章节区域出现悬浮“定位到当前章节”图标；点击后平滑滚动并在到达后隐藏。
- 不在这里重复提供复杂缓存管理；缓存管理统一进入设置页专门工作台。

## 7. 播放页

布局保持双区域：章节目录 + 正文/媒体控制。

### 7.1 章节目录

- 正常状态单击章节执行跳转。
- 用户滚离当前章节时显示“定位到当前章节”悬浮按钮。
- 当前章节只使用已有整卡/强调条样式和无障碍语义，不显示“当前”文本标记。
- 章节右侧只在存在当前有效朗读清单且完整度大于 0% 时显示当前配置缓存百分比；0% 和其它非正常状态不显示。
- 点击“缓存”工具后进入主动缓存选择模式；此时单击章节改为选择，不再跳转。
- 选择模式顶部显示“已选择 N 章”“取消选择”“开始缓存”。

### 7.2 正文

- 歌词式段落列表，当前段明显但不过度高亮。
- 播放推进自动居中；用户主动滚动后暂停自动追随。
- 当当前段离开可见区域时显示“返回当前段落”悬浮按钮。
- 上一/下一段、拖动进度产生的新定位也使用平滑滚动。

### 7.3 播放工具区

主要媒体控制：

- 上一章
- 上一段
- 播放/暂停
- 下一段
- 下一章
- 进度条
- 播放音量图标按钮；点击后打开悬浮窗，用滑块调整应用内播放音量，不改变系统音量。

播放页和迷你播放器的进度条在鼠标悬浮或拖动时，通过 Tooltip 显示当前段落位置，例如 `xx/xx`。

顶部或章节标题附近的低频工具使用图标：

- 主动缓存
- 定时停止
- 迷你播放器
- TTS 规则切换；菜单只列出已启用规则，当前规则只在该菜单中表达选中状态。没有已启用规则时提供前往 TTS 规则管理页的入口，但不提示用户在规则管理页“设为当前”。

定时停止使用 Flyout，不进入设置页常驻配置；工具按钮显示剩余分钟数，不显示单位，未设置时显示占位符。

## 8. 主动缓存进度 UI

Shell 紧凑入口示例：

```text
缓存中 · 3/8 章 · 42%
```

Flyout 内容：

```text
正在缓存
第三章                 已完成
第四章                 18 / 42
第五章                 等待中

总进度 76 / 168 段
[取消任务]
```

任务完成后入口自动消失，以 Snackbar 报告完成；失败保留安全错误摘要和可理解结果，不显示请求细节。

## 9. 规则工作台

TTS、章节规则和正则替换共享一套交互骨架。

### 左侧规则卡片

- 卡片采用左右布局：左侧显示名称和一行摘要，右侧使用 ToggleSwitch 控制启用状态。
- ToggleSwitch 是独立命中区域，不触发卡片选择、编辑器切换或拖动；宿主使用内容宽度布局，不能让不可见空白扩大开关命中范围。
- 单击卡片主体才打开右侧编辑器。页面进入、导入完成或恢复页面时都不自动选中第一条规则。
- 右键卡片打开单规则 ContextMenu，但不改变当前编辑对象；键盘使用 `Shift+F10`/Menu Key 打开同一菜单。
- 三类规则菜单都提供“导出到文件”“复制到剪切板”和删除；章节/正则另外提供上移/下移。
- 不显示 `⋮` 更多按钮。TTS 卡片也不显示“当前规则”或“设为当前”。

页面级“从文件导入”“从剪切板导入”放在 `AppPageHeader.Actions`；导出始终是单规则右键操作，不提供页面级导出。

导入采用合并语义：完全重复规则跳过，同名但内容不同的规则作为新规则追加；导入不覆盖现有规则，也不自动打开导入项。章节/正则的新规则按导入源顺序追加到现有排序末尾。

### 启用状态与 TTS 当前规则

- ToggleSwitch 属于列表级即时设置，不属于右侧编辑草稿，也不参与 Dirty State；持久化失败时回滚列表状态并投影错误。
- TTS 当前规则只在播放页选择，播放页的规则切换列表只显示已启用规则。
- 当前 TTS 规则被禁用或删除时直接清空当前选择，不自动切换其它规则；导入、新建或重新启用规则不会自动成为当前规则。

### 排序拖动

- 章节规则和正则替换不显示拖动手柄，整张卡片主体作为拖动区域；ToggleSwitch 和 ContextMenu 交互区域不参与拖动手势。
- 鼠标按下约 `300 ms` 后进入可拖动态，随后移动才启动拖动；长按阈值前释放仍按普通单击处理。
- 本阶段采用轻量反馈方案：拖动态使用透明度/边框/光标等状态反馈和明确插入线，不实现相邻卡片位移动画。
- 鼠标位于目标卡片垂直中心线上方时插入目标之前，下方时插入目标之后；拖到列表顶部/底部边缘时自动滚动。
- 排序只在 Drop 后持久化；右键菜单中的上移/下移继续作为键盘和备用等价操作。

### 右侧编辑区

- 未选中规则时显示统一空状态，不展示任何规则字段。
- 只显示规则字段和必要的编辑辅助。
- TTS 底部只保留“试听”“取消”“保存”。
- 章节/正则保留“取消”“保存”以及页面特有的帮助入口。
- 右侧编辑器一旦打开，“取消”始终可用；点击后直接丢弃当前草稿、清除选择并关闭编辑器，返回空状态。
- “保存”只在草稿存在修改且校验通过时可用；保存完成后编辑器可以继续保持打开。
- 未保存保护统一覆盖返回、左侧切换、一级导航、快捷键和窗口退出。

## 10. 设置入口视觉

设置首页和二级页进入三级页均使用导航行，而不是传统 Button：

```text
[icon]  缓存管理                                      >
```

- 无常驻边框。
- 整行可点击。
- Hover 使用圆角状态层。
- 只显示 icon + 标题 + Chevron；不在入口下堆说明文字。

普通设置项采用轻量分组面板 + 设置行：左侧标题/必要说明，右侧控件。

## 11. 缓存管理页

左右分栏：

- 左侧：单选书籍，显示书名、作者、缓存大小和已缓存章节数。
- 右侧：当前书章节缓存列表。

章节卡片首行显示章节序号和标题，次行显示缓存大小、条目数和“完整度”。

- 列表来源是缓存索引，因此显示当前书籍全部有缓存章节。
- 当前配置命中 0 段时仍保留章节卡片，并明确显示 `0/N 段 · 0%`。
- 清单过期或异常缺失时仍保留章节卡片，先显示“计划更新中/计划计算中”，后台完成后原位刷新。

交互：

- 平时单击章节即选择；不需要额外“进入批量模式”按钮。
- 支持 Ctrl/Shift/Ctrl+A。
- 0 项选择时“清理”“导出”禁用。
- 不显示逐章删除按钮。
- 不显示“清理本书”按钮。
- 选中整本书全部章节后点击“清理”即可完成等价操作。
- 不支持跨多本书选择章节。

“清理全部缓存”放在上一级“缓存与数据”页面。

## 12. MP3 导出交互

- 用户选中一个或多个章节后点击“导出”。
- 选择目标根目录；应用自动创建安全书名子目录。
- 每章生成一个含章节名的 MP3。
- 选中项存在不可导出章节时，在目录选择前确认是否跳过；确认后只导出其余完整章节，取消则不开始。
  全部不可导出时不打开目录选择器；不会自动生成缺失缓存。
- 章节卡片不常驻显示“可导出”或“缓存不完整，无法导出”等文案，详细原因通过 Tooltip 和
  AutomationName 提供。
- 从目录选择开始到导出完成只允许一个页面导出操作；期间显示不定进度、章数状态和取消入口。
- 成功后 Snackbar 提供结果摘要，页面保留“打开目录”入口并通过统一桌面 launcher 执行。

## 13. 迷你播放器

迷你播放器是小型独立窗口：

- 书名、当前章节。
- 不显示系统标题栏。
- 上一章、上一段、播放/暂停、下一段、下一章。
- 使用播放页同款可拖动章节段落进度条，显示当前段落在本章中的位置；悬浮或拖动时通过 Tooltip 显示 `xx/xx`。
- 五个媒体按钮和音量按钮使用统一 `48 × 48` 命中区及中性状态；播放/暂停不单独使用 Accent 背景或更大按钮。
- 置顶按钮在已置顶时使用强调色状态，并显示“取消置顶”语义。
- 恢复主窗口按钮；关闭按钮用于退出应用。

进入后隐藏主窗口。点击恢复主窗口只退出迷你模式；关闭迷你窗口或其关闭按钮等价于退出应用。位置与置顶状态可记忆，迷你模式本身不跨启动恢复，下一次启动仍按主窗口/托盘设置初始化。窗口空白区域可拖动位置，右侧边缘仅可调整宽度，按钮和其它交互控件区域保留原有操作。

## 14. 托盘

托盘菜单保持精简：

- 显示主窗口
- 播放/暂停
- 迷你播放器
- 退出

最小化到托盘时不能把“关闭窗口”误当作进程退出。

## 15. 反馈和对话框

反馈层级：

1. 控件内校验：字段错误。
2. 页内状态：加载、空列表、不可用原因。
3. Snackbar：导入、清理、缓存完成、导出完成等非阻塞结果。
4. 对话框：删除书籍、清理全部缓存、放弃未保存修改等高影响确认。

错误信息只给用户可操作内容，不展示技术堆栈或敏感请求信息。

## 16. 键盘与可访问性

现有播放快捷键继续保留，并加入桌面列表选择语义：

- `Space`：播放/暂停（播放页且焦点不在输入控件）。
- `Ctrl+Left/Right`：上一/下一段。
- `Ctrl+Shift+Left/Right`：上一/下一章。
- `Alt+Left`：返回。
- `Ctrl+,`：设置。
- `Ctrl+A`：在支持多选的章节列表中全选。
- `Esc`：退出选择/临时界面。

要求：

- 所有图标按钮有 Tooltip 和 AutomationName。
- 键盘 focus 可见。
- 颜色不是唯一状态信号。
- 虚拟化列表选择和定位可被键盘操作。

## 17. UI 代码边界

- ViewModel 不引用 Page、Window、Dispatcher 或具体 WPF 视觉类型。
- code-behind 只处理焦点、拖放、虚拟化、滚动、动画、窗口和平台事件桥接。
- 选择状态、dirty state、导航保护和后台任务状态优先放入可测试 controller/Application service。
- 文件选择、目录打开、媒体键、托盘和迷你窗口通过平台 port 统一实现。
