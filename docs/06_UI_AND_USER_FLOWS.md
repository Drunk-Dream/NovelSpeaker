# UI 与用户流程

## 设计原则

- 界面服务于听书，不追求完整阅读器功能。
- 用户应始终知道当前书籍、章节、播放状态和错误原因。
- 正常播放时隐藏技术细节。
- 错误时提供可执行操作，而不仅是错误码。
- 设置和规则编辑不阻塞主播放页。

## 页面结构

```text
MainWindow
├─ LibraryView
├─ PlayerView
├─ TtsRulesView
├─ TtsRuleEditorView
└─ SettingsView
```

第一版可以使用单窗口导航。

## 书库页

内容：

- 导入小说按钮。
- 拖放区域。
- 最近播放。
- 书籍列表。
- 每本书显示：
  - 书名
  - 当前章节
  - 最近播放时间
  - 大致进度
- 删除书籍。
- 清理单本书缓存。

不需要：

- 封面搜索。
- 在线元数据。
- 复杂排序。
- 标签系统。

## 播放页

布局建议：

```text
┌──────────────┬────────────────────────────┐
│ 章节目录      │ 当前章节标题                │
│              │                            │
│ 第一章        │ 正文……                     │
│ 第二章        │ 当前朗读段落高亮            │
│ 第三章        │ 后续正文……                 │
├──────────────┴────────────────────────────┤
│ 上一段  上一章  播放/暂停  下一章  下一段   │
│ TTS规则  语速  状态信息  进度               │
└───────────────────────────────────────────┘
```

功能：

- 章节选择。
- 当前段落高亮。
- 自动滚动。
- 播放、暂停、停止。
- 上一段、下一段。
- 上一章、下一章。
- 规则选择。
- 语速设置。
- 缓冲和错误状态。
- 重试当前段。
- 跳过当前段。

## TTS 规则页

列表内容：

- 规则名称。
- 启用状态。
- 最近使用时间。
- 兼容状态。
- 测试结果。

操作：

- 新建。
- 从文件导入。
- 从剪贴板导入。
- 导出。
- 编辑。
- 删除。
- 测试连接。
- 输入试听文本。
- 清除 Cookie。
- 配置登录信息。

## 规则编辑页

字段：

- 名称。
- URL/规则内容。
- Header。
- Content-Type。
- ConcurrentRate。
- 是否启用 Cookie。
- 登录信息键值。
- 原始 JSON 预览。
- 当前版本不支持字段提示。

提供：

- 模板语法提示。
- 测试文本。
- 请求预览，但敏感值脱敏。
- 响应状态和 Content-Type。
- 有限长度错误正文。

## 设置页

第一版：

- 缓存上限。
- 预取段落数量。
- 默认语速。
- 日志级别。
- 主题。
- 清理全部缓存。
- 清除全部凭据。
- 打开数据目录。

## 首次使用流程

```text
启动应用
  ↓
空书库提示
  ↓
导入 TXT
  ↓
自动解析章节
  ↓
无 TTS 规则时引导导入或新建规则
  ↓
测试规则
  ↓
进入播放页
  ↓
点击播放
```

## 导入规则流程

```text
选择 JSON 文件或粘贴 JSON
  ↓
解析对象或数组
  ↓
显示规则预览
  ↓
标记不支持字段
  ↓
用户确认导入
  ↓
保存
  ↓
测试规则
```

## 错误提示要求

### 网络错误

显示：

- 简洁说明。
- 重试。
- 打开规则设置。
- 跳过当前段。

### 鉴权错误

显示：

- “服务返回 401/403，可能是密钥、Token 或签名无效。”
- 打开登录信息。
- 不进行无限自动重试。

### 限流错误

显示：

- “请求过于频繁，正在等待。”
- 可显示预计等待时间。
- 不将其标记为永久故障。

### 内容类型错误

显示：

- 实际 Content-Type。
- 截断后的响应正文。
- 打开规则编辑器。

## 可访问性

- 关键按钮支持键盘操作。
- 播放状态不能只用颜色表示。
- 正文允许调整字号。
- 高亮不应降低可读性。
- 控件提供 AutomationProperties.Name。
