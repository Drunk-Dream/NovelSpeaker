# 产品范围

## MVP 必须实现

### 小说导入

- 导入单个 `.txt` 文件。
- 支持文件选择器和拖放导入。
- 检测 BOM。
- 严格尝试 UTF-8。
- 回退到 GB18030。
- 可选支持 UTF-16 LE/BE。
- 识别失败时允许用户选择编码并预览。
- 计算文件内容哈希，避免完全相同文件重复导入。
- 将原始文件复制到应用数据目录，避免源文件移动后失效。

### 小说解析

- 识别常见章节标题：
  - 第 N 章
  - 第 N 节
  - 第 N 卷
  - 序章
  - 楔子
  - 前言
  - 后记
  - 番外
- 无法识别章节时，将整本书作为一个章节。
- 章节内容按自然段和中文标点切分为朗读段落。
- 每个朗读段落保留原文字符范围。
- 显示文本和朗读文本分离。

### 在线 TTS

- 导入单个规则 JSON。
- 导入规则 JSON 数组。
- 新建、编辑、删除、启用和禁用规则。
- 规则测试和试听。
- 必须兼容目标 HTTP TTS 后端接口语义，并尽量直接复用 Legado 风格朗读规则；若规则格式不完全兼容，可允许本地调整后接入同一后端。
- 支持 GET。
- 支持 POST JSON。
- 支持 POST Form。
- 支持自定义 Header。
- 支持自定义 Body。
- 支持会话内 Cookie。
- 支持只读 LoginInfo 输入。
- 支持请求超时和重试。
- 支持规则级限流。
- 支持 `speakText` 和 `speakSpeed`。
- 支持 `{{ ... }}` JavaScript 表达式。
- 支持少量白名单 Legado 风格兼容辅助函数。
- 不引入额外 Java 桥接服务或本地代理进程。
- 检查 HTTP 状态码和响应 Content-Type。

### 播放

- 播放、暂停、停止。
- 上一段、下一段。
- 上一章、下一章。
- 自动跨段和跨章。
- 当前段落高亮。
- 自动滚动到当前段落。
- 显示缓冲、播放、暂停、错误状态。
- 切换规则、语速或章节后取消旧会话。
- 音频损坏时删除缓存并允许重新生成。

### 缓存

- 按规则、语速和文本生成稳定缓存键。
- 音频写入先使用临时文件，再原子重命名。
- 缓存命中时不重新请求。
- 默认预取后续两个段落。
- 默认最大缓存容量 2 GB。
- LRU 清理。
- 清理当前书籍缓存。
- 清理全部缓存。

### 持久化

- 保存书籍、章节和导入信息。
- 保存当前书籍和播放位置。
- 保存启用的 TTS 规则。
- 保存用户设置。
- 保存缓存元数据。
- 应用关闭、暂停、切章和段落结束时保存进度。

## 第二阶段候选功能

- Windows 本地 TTS 回退。
- 用户自定义章节正则。
- 更多编码。
- EPUB。
- 单本书专属 TTS 设置。
- 自定义文本净化规则。
- 定时停止。
- 托盘图标。
- 媒体键。
- 输出设备选择。
- 可配置预取数量。
- 规则登录信息表单。
- 更高兼容度的 Legado `source`、`java` 和 `cookie` API。

## MVP 成功标准

满足以下条件时可以认为 MVP 主流程完成：

1. 使用至少三本不同格式的中文 TXT 小说测试导入成功。
2. 使用至少三个不同结构的 HTTP TTS 规则测试成功。
3. 连续播放至少三十分钟无状态错乱。
4. 播放过程中多次切章、切规则、暂停和恢复，不播放旧会话音频。
5. 重启应用后恢复到最近保存位置。
6. 缓存命中时不产生新的 HTTP 请求。
7. 网络断开、返回 JSON 错误、401、429 和损坏音频都有明确处理。
