# 产品范围

本文件描述 NovelSpeaker 的目标产品形态。尚未实现的目标由 `TASK_BACKLOG.md` 跟踪；仓库根目录 `README.md` 只描述已经提供的能力。

## 1. 书籍与文本

- 导入单个本地 `.txt` 文件，支持文件选择和拖放。
- BOM、UTF-8、GB18030 与常见 UTF-16 编码检测；低置信度时允许用户选择编码。
- 规范化正文复制到应用数据目录，外部源文件只读。
- 基于内容哈希避免重复导入。
- 自动识别常见中文章节标题；无法识别时整本书作为一个章节。
- 动态将章节切分为可朗读段落，保留原文位置，并将 DisplayText 与 SpeechText 分离。
- 播放设置可开启朗读标题，在每章正文段落前加入章节标题语音；该可选标题段不改变正文段缓存身份。
- 书库支持按书名/作者搜索，并可按最近阅读或书名排序。
- 书籍详情允许修改应用内书名/作者和删除书籍；这些操作不修改外部源文件。
- 书籍详情页和播放页的章节目录均提供“定位到当前章节”能力。

## 2. 章节规则与正则替换

- 章节规则支持新建、编辑、启用、禁用、排序、删除、从文件/剪切板合并导入、单规则导出、默认规则导入/恢复和帮助。
- 正则替换支持新建、编辑、启用、禁用、排序、删除、从文件/剪切板合并导入和单规则导出。
- 正则可以作用于展示文本、朗读文本或两者；动态分段后逐段执行，不改变章节边界。
- 规则变化后重建当前内容，并保持合理的播放/暂停语义。
- 所有规则工作台采用左侧规则卡片 + 右侧编辑区；页面进入时不自动打开规则，用户单击卡片后才进入编辑状态。
- 规则卡片左侧显示名称和摘要，右侧使用独立 ToggleSwitch 即时控制启用状态；启用状态不属于编辑草稿，也不参与 Dirty State。
- 已打开编辑器时“取消”始终可用并关闭编辑器；“保存”只在草稿存在修改且校验通过时可用。切换规则或离开页面仍受统一 Dirty State 保护。
- 章节规则和正则替换不显示拖动手柄，使用整卡长按后拖动排序，并保留右键菜单中的上移/下移备用操作。
- 在导入/导出操作中，“从文件导入”“从剪切板导入”位于 PageHeader；单规则“导出到文件”“复制到剪切板”和删除等操作位于卡片右键菜单，不提供页面级导出。

## 3. HTTP TTS

- 支持从文件或剪切板合并导入单条规则/规则数组，也可新建、编辑、启用、禁用、删除、单规则导出和试听。
- 支持 GET、POST JSON、POST Form、自定义 Header/Body、`speakText`、`speakSpeed`、模板表达式和受限 JavaScript。
- 对同一规则的播放、预取和主动缓存共享并发/速率限制。
- 请求支持取消、超时、重试、响应类型校验与脱敏错误投影。
- 规则脚本只运行在受限求值环境，不开放 CLR、文件、进程、反射或任意宿主能力。
- TTS 规则管理页不再设置“当前规则”；播放页只列出已启用规则，并且只有播放页能够切换当前 TTS 规则。
- 当前 TTS 规则被禁用或删除时直接清空当前选择，不自动切换到其它规则；导入、新建或重新启用规则也不会自动成为当前规则。

## 4. 播放

- 播放、暂停、停止、上一/下一段、上一/下一章、自动跨段/跨章。
- 当前段高亮、自动居中、手动滚动后可快速返回当前段落。
- 切换章节、规则、语速或文本处理结果时隔离旧会话，迟到结果不能覆盖新状态。
- 编辑现有 TTS 规则的请求语义后不复用旧规则生成的音频；只修改名称、启用状态或并发限制不无理由使缓存失效。
- 损坏缓存自动删除并允许重新生成。
- 播放页提供当前会话的定时停止：15/30/45/60/90 分钟和自定义时长。
- 定时停止只暂停播放；已经启动的主动缓存继续执行。

## 5. 主动缓存

- 播放页通过“缓存”入口进入章节选择模式。
- 章节选择遵循 PC 文件管理器习惯：单击选择、`Ctrl` 增减、`Shift` 区间、`Ctrl+A` 全选、`Esc` 退出。
- 一个主动缓存批次可以包含一个或多个章节；批次启动后与当前播放章节、当前页面无关。
- 全应用同一时间只有一个主动缓存批次，章节和段落顺序处理。
- 优先级固定为：当前播放 > 播放预取 > 主动缓存；三者共享规则级限流。
- 批次启动时冻结 TTS 规则、语速和文本处理配置快照，后续 UI 修改不改变已启动批次。
- 已有效缓存的段落跳过，缺失段落继续生成；任务可取消。
- Shell 在存在任务时显示紧凑进度入口，点击可查看章节/段落进度并取消任务；完成后入口自动消失并给出通知。

## 6. 缓存管理与 MP3 导出

- 缓存与数据页显示总占用、容量上限及其 LRU 说明、应用数据目录入口、缓存管理入口和“清理全部缓存”危险操作；清理入口使用可访问的危险图标按钮。
- 缓存管理页左侧一次只选择一本书，右侧只列出存在缓存索引的章节，并显示缓存占用、条目数和完整度。
- 播放页目录和书籍详情目录的首轮查询只聚合已经存在、且与当前文本配置一致的朗读清单；缺失计划不触发首次建立，过期计划返回更新中并由后台异步重建。缓存管理页对有缓存但缺失计划的章节异步补建，并保留章节行。
- 章节完整度使用现有朗读清单和缓存索引快速聚合，不因打开目录逐段读取正文、执行正则或解码音频；清单缺失或过期时不显示旧百分比。
- 章节列表不放逐行删除按钮，也不提供独立“清理本书”按钮。
- 右侧章节采用文件管理器式选择；所有章节卡片统一铺满列表可用宽度。PageHeader 显示“已选择 N 章”，并提供仅图标的“清理”“导出”动作；0 项选择时两者不可用。
- “清理”只处理当前选中的章节；选中整本书全部章节即等价于清理本书。
- 只有在当前规则、语速和当前文本处理结果下完整缓存的章节可以导出。
- 目录中的 0% 完整度保持不显示；该行为不代表查询失败。
- 导出前的跳过确认和目录选择属于缓存管理页操作；提交后转交进程级章节导出协调器，全应用同一时间最多一个批次，页面离开、切换书籍或隐藏主窗口不取消。
- Shell 显示章节导出进度和取消入口；成功后保留“导出完成 · N 章”状态，直到用户打开目录或关闭该状态，失败/取消通过 Snackbar 通知后清除。
- 每章导出为一个 MP3；同章节多个段落按播放顺序合并，不同章节始终分文件。
- 用户选择根目录后自动创建书名子目录；文件名包含章节序号与章节名，例如 `001_第一章.mp3`。
- Windows 非法字符、保留名、尾部空格/点必须安全清理；同名文件使用 ` (2)` 等后缀，不覆盖已有文件。

## 7. 桌面媒体体验

- 支持 Windows/耳机媒体播放暂停按键。
- 系统 Previous/Next 映射为上一段/下一段；章节切换只保留在应用 UI。
- Windows 媒体面板显示当前章节标题、书名和播放状态。
- 播放页和托盘均可打开迷你播放器。
- 迷你播放器显示书名、当前章节、章节/段落切换、播放暂停、进度条、置顶、恢复主窗口和退出应用。
- 进入迷你播放器后隐藏主窗口；恢复主窗口与关闭迷你播放器是不同操作，关闭迷你播放器退出应用。
- 记忆迷你播放器位置和置顶状态，但下次启动默认仍进入主窗口。

## 8. 设置与托盘

- 设置首页只负责导航；具体设置进入对应二级页。
- 普通设置页使用轻量分组面板和设置行，不使用大面积独立厚重卡片。
- 二级页进入三级页时使用无边框导航行：图标 + 标题 + Chevron，不使用传统执行按钮外观。
- 关闭主窗口行为支持：最小化到托盘、退出应用、每次询问。
- 支持“启动后最小化到托盘”。
- 托盘菜单提供显示主窗口、播放/暂停、迷你播放器和退出。

## 9. 持久化与安全

- 保存书籍、章节、导入信息、规则、用户设置、阅读进度、按需建立的每章当前朗读清单与缓存元数据。
- 正式音频缓存存在时，对应章节必须已经持久化朗读清单；朗读清单可以在当前进程内暂时没有缓存。
- 删除某章最后一条缓存索引时，在同一 SQLite 事务中删除该章朗读清单并级联删除段记录；仍有缓存或受保护条目时保留清单。
- 已发布 SQLite migration 只追加，不重写历史。
- 缓存写入使用临时文件和原子替换；清理时保护正在播放、生成、预取或写入的条目。
- 删除书籍时级联删除其朗读清单、清单段和缓存索引，并通过可恢复流程删除应用内部正文和音频文件。
- 日志、错误、Snackbar 和诊断信息不包含小说正文、完整请求内容或凭据。
- 用户外部源文件永不因删除书籍、缓存清理或恢复流程被修改。

## 10. 当前阶段非目标

- EPUB/PDF/MOBI 阅读。
- 在线书源与网络小说抓取。
- 云同步、账户、付费和跨设备同步。
- 插件商店或通用扩展平台。
- 语音克隆、多角色自动配音和专业音频编辑。
- WebSocket TTS、真正的实时流式语音播放。
- 跨平台桌面或移动版本。
