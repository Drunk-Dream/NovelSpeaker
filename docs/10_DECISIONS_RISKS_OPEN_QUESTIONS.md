# 决策、风险与待定问题

## 已确定决策

### 平台和 UI

- Windows 10/11。
- C#、.NET 10、WPF。
- 第一版 x64。
- CommunityToolkit.Mvvm。

### 文件格式

- 第一版只支持 TXT。
- EPUB 等格式推迟。

### 在线 TTS

- 核心为 Legado 风格 HTTP TTS 规则。
- 不绑定固定云服务商。
- 第一版不需要自建后端。
- 用户自行提供可用规则及其凭据。
- 完整段落音频下载后再播放。
- 不实现 WebSocket 和真正流式播放。

### 播放和缓存

- NAudio。
- 默认预取后续两个段落。
- 缓存默认上限 2 GB。
- 缓存按规则、语速和文本区分。
- 跳转和配置变化创建新播放会话。

### 数据

- SQLite 保存书籍、章节、进度、规则和缓存索引。
- JSON 保存非敏感设置。
- DPAPI 或 Credential Manager 保存敏感信息。

## 主要风险

### 1. Legado 规则兼容度不明确

风险：

- 社区规则可能依赖复杂 `java`、`source`、Cookie 或登录脚本。
- 一些规则可能依赖 Rhino 特性。
- 不同规则的 URL 附加配置格式可能存在边缘情况。

缓解：

- 明确发布兼容矩阵。
- 第一版只承诺常见 GET/POST 规则。
- 导入时显示不支持字段。
- 建立真实规则样本测试集。
- 解析和脚本层独立封装。

### 2. 不可信 JavaScript

风险：

- 无限循环。
- 资源消耗。
- 访问系统能力。
- 凭据泄露。

缓解：

- Jint 白名单环境。
- 禁止 CLR。
- 设置执行限制。
- 每条规则隔离。
- 日志脱敏。
- 不提供通用网络和文件 API。

### 3. 在线服务差异

风险：

- Content-Type 不准确。
- 返回 JSON 但状态为 200。
- 音频格式不统一。
- 限流语义不同。
- Token 频繁过期。

缓解：

- 响应验证。
- 音频解码验证。
- 可配置 Content-Type。
- 规则级限流。
- 清晰错误分类。
- 登录信息独立更新。

### 4. 播放状态竞争

风险：

- 用户快速切章。
- 旧请求晚到。
- 预取和当前段重复请求。
- 多个完成事件同时推进。

缓解：

- `PlaybackSessionId`。
- CancellationToken。
- 单一协调器。
- 状态变更串行化。
- In-flight 请求去重。
- 大量状态机测试。

### 5. TXT 格式混乱

风险：

- 编码误判。
- 章节规则误判。
- 超大文件。
- 无换行文本。

缓解：

- 编码预览。
- 多级回退。
- 无章节回退。
- 长段强制切分。
- 导入过程后台执行。
- 保留原始文件。

### 6. GPL 许可证

参考项目使用 GPL 类许可证。直接复制其代码可能带来开源义务。

缓解：

- 只参考公开行为、字段和交互思想。
- 独立编写 C# 实现。
- 不直接翻译或复制 Kotlin 源文件。
- 保存设计决策记录。
- 发布前进行许可证审查。

## 待定问题

### 产品

- 应用正式名称。
- 是否第一版包含 Windows 本地 TTS 回退。
- 是否第一版包含定时停止。
- 删除书籍时是否默认删除缓存。
- 是否允许一本书指定独立规则和语速。

### 规则兼容

- URL 与请求选项的准确分隔语法。
- `Header` 字段支持 JSON 还是多行文本，或两者都支持。
- 第一版是否支持 `jsLib`。
- 第一版是否持久化 Cookie。
- `source.get/put` 的数据作用域。
- 登录信息表单的最小格式。
- 是否兼容规则中的旧字段别名。

### 播放

- 暂停后是否继续预取。
- 当前段失败默认停止还是提示后跳过。
- 是否保存段内音频时间。
- MP3、WAV、OGG、AAC 的第一版支持范围。
- 是否允许规则返回无 Content-Type 的音频。

### 发布

- 便携 ZIP、MSIX 或传统安装器。
- 是否打包 .NET Runtime。
- 是否第一版支持自动更新。
- 是否收集匿名错误统计。

## 推荐默认答案

为了避免阻塞开发，未决定前采用：

- 第一版包含 Windows 本地 TTS 回退，但优先级低于 HTTP TTS 主链路。
- 暂停时继续预取 1 个段落。
- 当前段最终失败后暂停，用户选择重试或跳过。
- 保存段内音频时间。
- 第一版重点支持 MP3 和 WAV。
- 规则没有 Content-Type 时尝试按文件头和解码结果识别。
- Cookie 持久化推迟，第一版仅会话内保存。
- 发布形式先使用自包含便携 ZIP。
