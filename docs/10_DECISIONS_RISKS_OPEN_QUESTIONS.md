# 决策、风险与待定问题

## 已确定决策

### 平台和 UI

- Windows 10/11。
- C#、.NET 10、WPF。
- 使用 Wpf.Ui 4.x 提供 FluentWindow、NavigationView、图标、对话框、Snackbar 和主题能力。
- Windows 11 可使用 Mica；Windows 10 自动降级为普通主题背景。
- 第一版 x64。
- CommunityToolkit.Mvvm。
- 一级导航仅保留书库和设置；播放页与管理页均为上下文页或二级页。
- 删除底部全局播放器条，返回书库后播放可继续，并通过导航栏底部“正在播放”入口返回。
- 书库、TTS 规则和章节规则不使用 DataGrid；TTS 规则使用卡片/设置式列表与悬浮编辑弹窗，章节规则使用卡片/设置式列表与独立编辑页。
- 主题支持跟随系统、浅色和深色。

### 文件格式

- 第一版只支持 TXT。
- EPUB 等格式推迟。

### 在线 TTS

- 核心为 Legado 风格 HTTP TTS 规则。
- 不绑定固定云服务商。
- 第一版不需要自建后端。
- 第一版直接调用规则声明的 HTTP TTS 后端，不额外引入本地 Java 中转服务或代理层。
- 第一版以后端接口兼容为优先约束，不承诺所有规则都能零改动导入。
- 用户自行提供可用规则及其凭据。
- 完整段落音频下载后再播放。
- 不实现 WebSocket 和真正流式播放。
- 第一版承诺的是“常见 HTTP TTS 规则兼容子集”，而不是兼容所有社区规则。
- 第一版支持会话内 Cookie，不支持 Cookie 持久化。
- LoginInfo 作为只读输入参与规则求值。
- 第一版不包含 Windows 本地 TTS 回退。

### 播放和缓存

- NAudio。
- 默认预取后续两个段落。
- 缓存默认上限 2 GB。
- 缓存按规则、语速和最终语音文本区分；后续正则替换启用后，缓存键使用处理后的 `SpeechText` 哈希。
- 跳转和配置变化创建新播放会话。

### 数据

- SQLite 保存书籍、章节、进度、规则和缓存索引。
- JSON 保存非敏感设置。
- DPAPI 或 Credential Manager 保存敏感信息。

## 主要风险

### 1. Legado 规则兼容度不明确

风险：

- 社区规则可能依赖复杂 `java`、`source`、Cookie 或登录脚本。
- 一些规则可能依赖 Rhino 特性。
- 不同规则的 URL 附加配置格式可能存在边缘情况。

缓解：

- 明确发布兼容矩阵。
- 第一版只承诺常见 GET/POST 规则。
- 导入时显示不支持字段。
- 建立真实规则样本测试集。
- 解析和脚本层独立封装。

### 2. 不可信 JavaScript

风险：

- 无限循环。
- 资源消耗。
- 访问系统能力。
- 凭据泄露。

缓解：

- Jint 白名单环境。
- 禁止 CLR。
- 设置执行限制。
- 每条规则隔离。
- 日志脱敏。
- 不提供通用网络和文件 API。

### 3. 在线服务差异

风险：

- Content-Type 不准确。
- 返回 JSON 但状态为 200。
- 音频格式不统一。
- 限流语义不同。
- Token 频繁过期。

缓解：

- 响应验证。
- 音频解码验证。
- 可配置 Content-Type。
- 规则级限流。
- 清晰错误分类。
- 登录信息独立更新。

### 4. 播放状态竞争

风险：

- 用户快速切章。
- 旧请求晚到。
- 预取和当前段重复请求。
- 多个完成事件同时推进。

缓解：

- `PlaybackSessionId`。
- CancellationToken。
- 单一协调器。
- 状态变更串行化。
- In-flight 请求去重。
- 大量状态机测试。

### 5. TXT 格式混乱

风险：

- 编码误判。
- 章节规则误判。
- 超大文件。
- 无换行文本。

缓解：

- 编码预览。
- 多级回退。
- 无章节回退。
- 长段强制切分。
- 导入过程后台执行。
- 保留原始文件。

### 6. GPL 许可证

参考项目使用 GPL 类许可证。直接复制其代码可能带来开源义务。

缓解：

- 只参考公开行为、字段和交互思想。
- 独立编写 C# 实现。
- 不直接翻译或复制 Kotlin 源文件。
- 保存设计决策记录。
- 发布前进行许可证审查。

## 已知限制（第一版）

- 不保证兼容所有社区规则。
- 不支持 WebView 登录相关规则。
- 不支持 `jsLib`。
- 不支持复杂 `source.get/put` 可变状态语义。
- 不支持 Cookie 持久化。
- 不支持真正的流式边生成边播放。
- 不包含 Windows 本地 TTS 回退。

## 默认实现决策

为了避免阻塞开发，第一版直接采用：

- 暂停时最多继续预取 1 个段落。
- 当前段最终失败后暂停；播放页仅在故障时显示“再次尝试”和“切换规则”，不提供跳过。
- 保存段内音频时间。
- 第一版重点支持 MP3 和 WAV。
- 规则没有 Content-Type 时尝试按文件头和解码结果识别。
- 删除书籍时提供“同时删除音频缓存”，默认勾选；始终保留用户外部源文件。
- 单本书专属规则和语速推迟到第二阶段；播放页仅使用当前全局规则和当前会话语速。
- 发布形式先使用自包含便携 ZIP。

## UI/UX 已确定补充决策

- 应用启动进入书库，不自动进入播放页。
- 点击书籍恢复上次位置但保持暂停。
- 书架显示自动生成的稳定文字封面、当前章节、剩余章节和无数字比例进度条。
- 书库提供按书名/作者搜索，以及最近阅读/书名排序；章节目录第一版不提供搜索。
- 播放页不提供切换书籍、停止、常驻重试、跳过和正文字号设置。
- 播放页进度条表示当前段在本章总段落中的位置，可拖动并在松开后跳转。
- 播放中进行章节、段落、规则或语速跳转后继续播放；暂停中保持暂停。
- 手动滚动后，只有连续 4 秒没有任何滚动输入且未拖动滚动条时才恢复自动居中；旧计时任务不得抢滚动。
- 设置首页使用分组列表，仅提供二级页入口，不直接显示具体设置项，也不提供统一保存按钮。
- 设置二级页为播放设置、TTS 规则、导入与文本、章节规则、缓存与数据、外观、诊断与关于。
- 二级设置页内部不再额外显示设置项分组标题。
- TTS 规则试听使用卡片按钮打开小型对话框，不建立独立试听调试页。
- TTS 规则编辑使用悬浮弹窗，规则页提供规则编写帮助入口。
- 当前 TTS 规则禁用或删除前必须选择替代规则，或明确清除当前规则并进入无可用规则状态。
- 缓存与数据页提供全局缓存总览、可编辑缓存上限、按书籍缓存列表和全局清理；单书详情页仍保留当前书缓存管理。
- 日志级别放在诊断与关于页。
- 关闭窗口行为与托盘行为归属外观页，但第一版只规划，不实现 UI；后续不单独提供“显示托盘图标”开关，选择最小化到托盘时才显示托盘图标。
- 正则替换是后续功能，入口位于导入与文本页；它位于正文读取和内容消费之间，修改规则不要求重新导入。
