# 已完成 UI / 功能改造归档（2026-07-06）

本归档用于保存 `11_TASK_BACKLOG.md` 清理前已经完成的 UI 和功能改造背景。归档内容只作为历史参考，不再作为当前待办来源。最新产品行为以 `06_UI_AND_USER_FLOWS.md` 和 `06A_SETTINGS_PAGES.md` 为准；最新待办以 `11_TASK_BACKLOG.md` 为准。

## 已完成基线总结

### 基础能力与应用壳层

- 已建立 Wpf.Ui 4.x Fluent 视觉基础，支持浅色、深色和跟随系统主题。
- 主窗口已切换到 `FluentWindow` 和 `NavigationView`，一级入口只保留“书库”和“设置”。
- 已移除旧顶部四按钮导航和底部全局播放条。
- 已建立官方导航服务、强类型页面参数、正在播放入口、统一 ContentDialog / Snackbar / 异常投影服务。
- 已补齐主题持久化、响应式导航折叠和统一设计资源。

### 书库、导入与书籍管理旧基线

- 已实现稳定自动封面生成器、书籍卡片 ViewModel、响应式卡片网格、搜索排序、空状态和拖放入口。
- 已实现从书库打开书籍、保持暂停、切换书籍时保存旧进度并停止旧会话。
- 已实现书名 / 作者编辑、未保存修改保护、单书缓存清理和书籍删除。
- 旧导入基线包含 `ImportBookDialog`、编码检测、正文预览、手动编码、重新预览、确认导入和可取消进度。
- 旧书籍详情基线包含源文件名、文本编码、只读章节列表，并且不支持从详情页章节列表跳转播放。

以上两点已被 2026-07-06 新方案调整：导入改为直接导入；书籍详情页改为全局不滚动、章节虚拟列表，并支持章节跳转播放。

### 播放页

- 已完成单书上下文播放页，删除书籍下拉框和“开始所选书籍”。
- 已完成左右主布局、虚拟化章节目录、歌词式正文预览、五键播放控制、章节段落进度条、规则切换菜单、语速控件和无规则状态。
- 已完成手动滚动协调器：滚轮 / 键盘 / 触控进入手动浏览，滚动条拖动独立状态，连续 4 秒无输入后恢复自动居中，并隔离旧计时任务。
- 已完成返回书库后继续播放和播放错误页内错误条。

2026-07-06 新方案在此基础上新增：自动居中和用户主动跳转时的平滑滚动动画。

### 设置页与复杂管理页

- 设置首页已改为分组入口列表，不再直接放置具体设置项或统一保存按钮。
- 播放设置、导入与文本、外观、诊断与关于等二级页已建立。
- TTS 规则页已改为左右分栏工作台，支持新建、直接导入、右侧编辑、一键试听、当前规则保护、未保存保护和帮助浮层。
- 章节规则页已改为左右分栏工作台，支持左侧规则列表、启用、排序、新建、删除、默认规则导入 / 恢复、未保存保护和帮助浮层。
- 缓存与数据已建立二级页总览和三级页缓存管理：左侧选择书籍，右侧管理章节缓存。

2026-07-06 新方案在章节规则上调整：启用 / 禁用只保留在左侧列表，右侧编辑区不再显示启用字段；启用、排序与名称 / 正则表达式编辑进行字段级解耦。

## 旧待办清理原则

- 已完成但被新方案改变的内容不保留为完成项，而是在当前 backlog 中新增调整任务。
