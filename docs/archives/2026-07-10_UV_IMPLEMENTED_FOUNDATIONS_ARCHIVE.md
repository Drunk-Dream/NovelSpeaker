# Epic U / Epic V 已实现基础归档（2026-07-10）

本文件记录在重新拆分 Epic U、Epic V 时，源码中已经存在并可作为后续审计基础的实现。归档只说明这些纵向基础已经建立，不表示对应领域已经完成最终验收。

## Epic U 已实现基础

- [x] **UXF-001：建立统一 Snackbar 和对话框反馈服务。** 主窗口已提供 `SnackbarPresenter`，应用层通过统一反馈服务显示成功、警告和失败信息，并已有相关单元测试。
- [x] **UXF-002：建立主题运行时和 Mica 降级。** 已支持跟随系统、浅色和深色主题；主窗口尝试使用 Mica，失败时回退到普通窗口背景，并有降级测试。
- [x] **UXF-003：完成关键页面可访问性初始覆盖。** 返回、帮助、规则列表、播放控制、搜索清空、书籍卡片和“回到当前段”等关键控件已设置部分 Tooltip 与 `AutomationProperties.Name`，并有若干 UI 测试。
- [x] **UXF-004：为主要长列表建立虚拟化基础。** 播放正文、章节目录和缓存管理列表等已使用虚拟化或回收模式；播放正文明确采用 Pixel 滚动。
- [x] **UXF-005：完成主要旧 UI 流程替换。** 直接导入、固定工作台详情页、章节规则字段解耦和播放页平滑居中等独立 Epic 已完成，旧方案不再作为当前设计依据。

## Epic V 已实现基础

- [x] **SECF-001：建立 TTS 敏感信息脱敏工具。** `SensitiveDataRedactor` 已用于 URL、Header、表单、JSON 类请求体和 HTTP 错误摘要的安全投影。
- [x] **SECF-002：建立启动和崩溃兜底诊断。** 应用启动阶段、启动失败、UI 未处理异常、后台未处理异常和缓存维护失败可以写入本地 `startup.log`，并向用户显示可理解的错误提示。
- [x] **SECF-003：建立诊断与关于页面基础。** 页面已展示应用名称、版本、数据库版本、数据目录、日志目录和日志级别，并支持打开日志目录。
- [x] **RELF-001：接入应用品牌图标。** 项目已包含多尺寸应用图标资源，并用于应用程序、主窗口和导航图标。

## 仍需主线完成的内容

以下内容未因本归档而视为完成，继续保留在当前 Backlog：
