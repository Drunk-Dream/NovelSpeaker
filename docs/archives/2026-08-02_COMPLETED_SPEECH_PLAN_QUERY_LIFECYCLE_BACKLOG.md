## 2. 已确认边界

- 播放页目录、书籍详情目录和缓存管理页都只查询数据库中已经存在、且与当前 `TextProfileFingerprint` 一致的章节朗读清单。
- 页面查询不得读取章节正文、执行正则、创建清单、重建过期清单或向后台构建队列提交任务。
- 当前清单缺失或过期时，普通目录不显示百分比；缓存管理页显示中性“未计算”状态，不显示旧百分比，也不显示“计算中”。
- 目录中的真实 0% 继续不显示，这是既有用户体验。
- 音频缓存条目存在时，对应章节必须已经持久化朗读清单；朗读清单在当前进程内可以暂时没有缓存。
- 播放、预取、主动缓存和导出等真正消费章节内容的用例负责按需建立或更新清单；缓存写入必须在计划提交成功后进行。
- LRU、用户清理和缓存健康维护删除最后一个缓存条目时，不要求同步删除朗读清单；应用下次启动时统一清理。
- 启动维护只保留至少存在一个缓存索引条目的章节朗读清单；删除计划头时通过外键级联删除其段记录。
- 启动维护必须使用集合式 SQLite 删除，不读取正文、不执行正则、不扫描或解码音频文件，并且可重复执行。
- 不迁移旧缓存，不实现全局音频去重。

## [x] 1（P0）：固定朗读清单查询与生命周期合同

实现：

- 为章节清单状态定义清晰结果：`Current`、`Missing`、`Stale`、`NoPlayableSegments` 和规则不可用。
- 明确页面查询只能读取现有清单；`Missing`/`Stale` 不隐式转化为构建命令。
- 明确“缓存条目存在 ⇒ 对应章节清单存在”，反向不成立。
- 明确清单建立入口只属于播放、预取、主动缓存和导出等内容消费用例。

自动验收：

- 查询接口测试证明缺失或过期清单不会调用章节读取器、正则流水线或计划构建器。
- 状态模型不把真实 0%、缺失和过期混为同一业务状态。

## [x] 2（P0）：将完整度查询收口为现有清单只读聚合

前置：1。

实现：

- 普通目录和缓存管理页统一传入当前 `TextProfileFingerprint`。
- SQL 只关联指纹一致的现有 `ChapterSpeechPlans`、计划段和 `Ready` 缓存索引。
- 缺失或过期清单返回不可计算状态，不创建、不更新清单。
- 保持批量 SQL、常数级连接/查询次数和零文件/解码 I/O。

自动验收：

- 有旧指纹清单时不得返回旧百分比。
- 页面查询 2,000/10,000 段时计划构建调用次数为 0，文件探测和解码调用次数为 0。

## [x] 3（P0）：保证缓存写入前已经提交章节朗读清单

前置：1、2。

实现：

- 播放、预取、主动缓存和导出所需的计划获取统一经过 `EnsureCurrentPlan` 或等价边界。
- 音频缓存写入前验证对应章节计划已成功持久化，禁止形成只有 `AudioCacheEntries`、没有 `ChapterSpeechPlans` 的状态。
- 同一章节与文本指纹的并发计划构建共享同一 in-flight 任务，避免重复处理正文。
- 计划生成或提交失败时不得写入依赖该计划的正式缓存索引。

自动验收：

- 所有正式缓存写入路径均满足缓存到清单的存在性约束。
- 并发播放/预取/主动缓存不会重复建立同一计划或留下半套数据。

## [x] 4（P0）：新增启动时无缓存朗读清单回收

前置：3。

实现：

- 在数据库 migration、未完成操作恢复和轻量缓存索引整理之后，Shell/播放器初始化之前执行启动维护。
- 集合式删除没有任何 `AudioCacheEntries` 引用的 `ChapterSpeechPlans`；依靠 `ON DELETE CASCADE` 删除 `ChapterSpeechPlanSegments`。
- 同一维护阶段清理无任何缓存条目引用的 `SynthesisProfiles`。
- 维护使用短事务、幂等执行；失败记录脱敏诊断，并按启动维护策略决定重试或安全继续。
- 不访问正文文件，不逐项检查缓存文件，不执行音频解码。

建议 SQL 语义：

```sql
DELETE FROM ChapterSpeechPlans
WHERE NOT EXISTS (
    SELECT 1
    FROM AudioCacheEntries e
    WHERE e.ChapterId = ChapterSpeechPlans.ChapterId
);
```

自动验收：

- 有至少一条缓存索引的章节保留计划；零缓存章节的计划头和计划段被删除。
- 重复启动结果一致，清理规模随 SQL 集合操作完成，不逐章打开连接。
- 书籍删除、LRU、用户清理和健康维护后的下一次启动均不会留下无缓存计划。

## 6. 完成定义

- 普通目录与缓存管理页都只查询现有且当前的朗读清单。
