# 产品与范围

## 1. 产品定义

NovelSpeaker 是面向 Windows 10/11 x64 的轻量本地小说听书应用。用户导入 TXT 小说，通过可配置 HTTP TTS 规则持续收听，应用负责章节识别、文本处理、播放、预取、缓存、阅读进度和桌面媒体控制。

产品重点是：

```text
本地 TXT
  → 可控文本处理
  → HTTP TTS
  → 连续播放
  → 本地缓存
  → 可恢复阅读进度
```

NovelSpeaker 不是完整电子书阅读器、在线书源聚合器、云同步平台或插件市场。

## 2. 核心用户故事

> 用户导入一本 TXT 小说，选择并启用 HTTP TTS 规则后，可以像使用桌面媒体播放器一样持续收听；应用能够在切章、切页、托盘、迷你播放器和重启后保持正确的播放与阅读语义，并复用已经生成的音频。

## 3. 书籍与文本

- 导入本地 TXT。
- 识别/选择文本编码并规范化正文。
- 使用章节规则生成章节目录。
- 章节规则变化后可以重建章节结构，不直接改写用户源 TXT。
- 展示文本与朗读文本可以经过正则替换等可配置处理。
- 外部源文件始终视为用户数据，不由应用写回。

## 4. 规则

### 4.1 TTS 规则

- 支持导入、创建、编辑、启用/禁用、删除和试听 HTTP TTS 规则。
- 播放页只在已启用规则中选择当前 TTS 规则。
- 禁用或删除当前规则后清空当前选择，不隐式回退到另一规则。
- 规则脚本和模板属于不可信输入，必须遵守 `05_HTTP_TTS_COMPATIBILITY.md` 的安全边界。

### 4.2 章节规则

- 支持导入、编辑、启用/禁用、排序和删除。
- 规则用于从规范化文本识别章节。

### 4.3 正则替换

- 支持显示/朗读文本处理流水线。
- 规则执行、错误和与缓存身份的关系由 `06_REGEX_REPLACEMENT_PIPELINE.md` 定义。

## 5. 播放

- 支持 Play/Pause/Stop、上一/下一段、章节跳转、段落跳转和进度恢复。
- 当前活动书籍的即时 UI 位置以 `PlaybackSnapshot` 为运行时真值。
- SQLite `ReadingProgress` 是持久化 checkpoint 和非活动/重启恢复基线。
- 显式章节/段落跳转成功后及时 checkpoint 新逻辑位置。
- 播放会话不因普通页面切换、主窗口隐藏到托盘或进入迷你播放器而被错误销毁。

## 6. 缓存与预取

- 当前播放、播放预取、主动缓存复用同一套文本、TTS、缓存身份、限流和音频验证语义。
- 优先级固定：

```text
Current playback > Playback prefetch > Active cache
```

- 主动缓存以章节为用户选择粒度。
- 全应用最多一个主动缓存批次。
- 页面离开不取消已经提交的主动缓存批次。
- 缓存是可重建派生数据，不成为正文、规则或阅读进度的唯一来源。

## 7. 缓存管理与 MP3 导出

- 缓存管理页展示存在缓存的章节。
- 可多选章节并导出为每章一个 MP3。
- 只导出当前配置下可验证完整的章节；混合选择时允许用户确认跳过不可导出章节。
- 导出批次提交后由独立后台 owner 持有，不由缓存管理页面持有。
- 全应用最多一个章节导出批次。

## 8. 桌面体验

- Windows 系统媒体控制。
- 系统/耳机媒体键。
- 主窗口关闭策略：隐藏到托盘、退出或每次询问。
- 迷你播放器与主窗口共享同一播放会话，不创建第二套播放器。
- 定时停止只暂停当前播放，不取消后台缓存。
- 主题支持 Light / Dark / System，并提供频繁访问的 Light/Dark 快捷切换入口。

## 9. 导航

- 使用强类型 `AppRoute`。
- 不维护浏览器式 Back/Forward 历史。
- 普通页面由固定父级返回。
- Player 是唯一具有动态一次性 `ReturnRoute` 的页面。
- PageHeader、Alt+Left 和未被局部交互消费的 Esc 复用同一应用级返回语义。

## 10. 性能与规模目标

功能基本稳定后，架构必须按长期规模设计：

- 章节目录至少按 10,000 章连续列表设计。
- 用户不需要使用显式分页才能浏览长目录。
- WPF UI virtualization 不能替代 data/projection 规模控制。
- 大型页面的首个可交互帧不能依赖完整数据集的全部动态 enrichment 完成。
- UI Dispatcher 上不得执行无界、随完整数据集线性增长的重工作。

具体 UI 性能合同见 `04_UI_NAVIGATION_AND_PERFORMANCE.md`。

## 11. 数据兼容

必须长期保护：

- 已发布 SQLite migration 历史；
- Books / Chapters / ReadingProgress；
- 用户规则与设置；
- 外部 TXT；
- 当前核心用户交互语义。

内部 API、namespace、目录和未发布抽象不属于兼容承诺，项目未稳定期间允许直接破坏性重构并删除旧实现。

## 12. 当前非目标

- EPUB/漫画等多格式阅读器。
- 在线书源聚合。
- 云同步、账户体系。
- 跨平台客户端。
- 插件市场或通用脚本宿主。
- 专业音频编辑/后期。
- 为第三方提供稳定 SDK/API。
