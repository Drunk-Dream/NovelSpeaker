# 产品与范围

## 1. 产品定义

NovelSpeaker 是面向 Windows 10/11 x64 的轻量本地小说听书应用。用户导入本地 TXT 小说，通过可配置语音服务持续收听，应用负责章节识别、文本处理、连续播放、预取、缓存、阅读进度与桌面媒体控制。

核心链路：

```text
本地 TXT
→ 章节与文本处理
→ Speech Provider
→ 连续播放
→ 本地缓存
→ 可恢复阅读进度
```

NovelSpeaker 优先保持本地、轻量、可控，不追求完整电子书生态或通用插件平台。

## 2. 核心能力

### 书籍与章节

- 导入本地 TXT，并识别/选择文本编码。
- 使用章节规则生成章节目录。
- 章节规则变化后可以重建章节结构，不写回用户源 TXT。
- 支持书库、书籍详情和超长连续章节目录。

### 语音服务与文本处理

- 使用统一 Speech Provider 模型管理语音服务。
- HTTP Provider 支持用户创建、编辑、复制、导入、单条导出、删除、排序和试听。
- Microsoft Edge Provider 作为实验性内置单实例 Provider，仅在对应实验功能开启时可见。
- 不为未来 Local Provider 预先建立通用插件系统或万能配置 Schema。
- 支持显示文本与朗读文本的正则替换流水线。
- Provider 与 HTTP TTS 的精确合同见 `specs/HTTP_TTS.md`；正则规则合同见 `specs/REGEX_REPLACEMENT.md`。

### 播放

- 支持 Play/Pause/Stop、上一/下一段、章节跳转、段落跳转和阅读进度恢复。
- 播放页是主动切换当前 Provider 的唯一入口。
- 当前 Provider 可以为空，但不把 None 作为高频可选项展示。
- 切换 Provider 或保存 Provider 新配置不打断已经开始播放的当前语句；下一条尚未开始的语句使用最新有效配置。
- 不建立自动 Provider fallback。
- 播放会话可以在页面切换、主窗口隐藏到托盘和迷你播放器之间持续。
- 系统媒体控制与媒体键复用同一播放会话。

### 缓存与后台工作

- 当前播放、播放预取和主动缓存复用同一套文本/Provider/缓存语义。
- 主动缓存以章节为用户选择粒度，可在离开页面后继续；任务开始时冻结 Provider 和影响合成的配置快照。
- 缓存管理页展示已缓存章节并支持批量清理和每章 MP3 导出。
- 缓存属于可重建派生数据，不成为正文、Provider 配置或阅读进度的唯一来源。

### 桌面体验

- 支持 Light / Dark / System 主题。
- 提供高频 Light/Dark 快捷切换。
- 支持主窗口隐藏到托盘、退出或每次询问。
- 提供迷你播放器。
- 设置页保持轻量，不用状态面板堆叠技术信息。

### 可诊断性

- 生产环境具有低频结构化日志。
- 用户可以主动开启本地性能遥测并导出诊断信息。
- 用户遇到可复现问题时可以使用诊断会话记录问题现场，并可主动标记问题或截取当前 NovelSpeaker 窗口。
- 所有诊断能力默认本地保存，不自动上传。

## 3. 导航与页面体验

- 不维护浏览器式 Back/Forward 历史。
- 普通页面具有明确父级返回关系。
- 播放页可以返回进入播放页之前的来源页面。
- PageHeader、Alt+Left 和未被局部交互消费的 Esc 使用统一返回语义。
- 大型页面先提供可交互内容，再补充非关键 enrichment。

## 4. 规模与性能目标

长期架构至少按以下规模设计：

- 章节目录支持至少 10,000 章连续浏览。
- 用户不需要显式分页浏览长目录。
- UI virtualization 与数据/projection 规模控制同时成立。
- 首个可交互帧不等待完整数据集的动态 enrichment。
- UI Dispatcher 不执行无界、随完整数据集线性增长的重工作。

## 5. 用户数据与兼容

必须长期保护：

- 用户外部 TXT。
- 已发布 SQLite migration 与正式持久化数据。
- Books / Chapters / ReadingProgress。
- 已发布的 Provider 配置与设置。
- 已发布的用户可观察核心交互语义。

开发阶段允许对尚未形成正式外部合同的旧 TTS Rule 模型和导入格式做一次性迁移或移除，不为内部模型迁移长期保留双读、双写或 compatibility wrapper。

内部 namespace、目录、未发布抽象、诊断内部格式的未发布实现细节不属于兼容承诺；项目仍允许为清晰职责进行内部破坏性重构。

## 6. 当前非目标

- EPUB、漫画等完整多格式阅读器。
- 在线书源聚合的近期实现。
- 账号体系。
- 跨平台客户端。
- 插件市场或通用脚本宿主。
- 专业音频编辑/后期。
- Provider 自动 fallback 链。
- 为未来 Local Provider 预先设计通用插件/能力框架。
- 为第三方提供稳定 SDK/API。
- 自动远程上传日志或性能遥测。
- 默认录屏、自动截图、Crash Dump/Minidump。
